# 无 DEM、无 LMS 的 20 位逐码基线

制造 seed 100，固定两组 A/B 选片，主、子及桥电容失配在扫描中保持不变。粗级使用同一名义 Fig.11 码表。数字重构只相加名义粗码下门限和 ADC2 码仓中点电压。DEM、LMS 和 dither 均关闭，训练样本为零。实际失配电容只进入两节点余量模型。基线脚本不读取训练数据、拟合增益或开关权重。

理想 12 位 ADC2 的输入等效窗口为 ±100 mV，步长为 48.828125 μV。最终输出码宽为 20 位，10 V 输入跨度的标称 LSB20 为 9.536743 μV。以下三路结果按各自状态分布计算 20 位码密度，排除首尾饱和码，用内部平均码宽归一化 DNL，再累计得到端点 INL。固定 A/B 两状态等权，动态 Fig.21 按已有 512 个冻结状态等权。INL／DNL 的分母为 1,048,574 个内部码。

| 固定失配 σ | 路径 | 峰值端点 INL（LSB20） | DNL 范围（LSB20） | 零宽内码数 |
| :--- | :--- | ---: | ---: | ---: |
| 2% | 固定 A/B，无 DEM、无 LMS | 901.930 | [−1.000, +9.238] | 802,491 |
| 2% | 固定 A/B，无 DEM＋独立 LMS | 3.737 | [−1.000, +4.118] | 678,189 |
| 2% | 动态 Fig.21 DEM＋独立 LMS | 3.479 | [−1.000, +4.120] | 336 |
| 3% | 固定 A/B，无 DEM、无 LMS | 1,351.458 | [−1.000, +9.238] | 782,075 |
| 3% | 固定 A/B，无 DEM＋独立 LMS | 3.823 | [−1.000, +4.577] | 678,629 |
| 3% | 动态 Fig.21 DEM＋独立 LMS | 3.478 | [−1.000, +4.120] | 224 |

在这个虚拟制造样本中，LMS 大幅压低固定 A/B 的峰值 INL，随后启用跨段 DEM 使统计零宽码数进一步下降。12 位 ADC2 条件下，三路的最小 DNL 仍为 −1 LSB20。[两条独立 LMS 的原始结果与测法](../README.md)

不使用 DEM 和 LMS 时，2%／3% 的峰值端点 INL 输入等效值分别为 8.60／12.88 mV。全幅 ADC2 超窗输入宽度均为零，20 位导出编码在高端裁剪的输入宽度分别为 2.640／3.967 mV，进入端码后从内部码宽统计中剔除。同一 10 MS/s、4,096 点、998.53515625 kHz、峰值 10/3 V 的正弦留出，导出后 SNDR／SFDR 分别为 57.37／60.84 dB 和 53.85／57.32 dB。

## 理想 16 位 ADC2 诊断对照

在同一物理池、同一 ±100 mV 输入等效窗口内，仅将理想 ADC2 改为 16 位，细步长为 3.051758 μV。无 DEM、无 LMS 路径的峰值端点 INL 仍然很大，说明当前固定失配的主要静态偏差仍在。

| 固定失配 σ | 峰值端点 INL（LSB20） | DNL 范围（LSB20） | 零宽内码数 |
| :--- | ---: | ---: | ---: |
| 2% | 899.156 | [−1.000, +1.240] | 313 |
| 3% | 1,348.677 | [−1.000, +1.239] | 468 |

全幅 ADC2 超窗输入宽度均为零，高端导出裁剪宽度分别为 2.643／3.970 mV。[同口径两条独立 LMS 的 16 位 ADC2 结果](../adc2_16bit/summary.json)

## 独立核验与复现

全幅积分覆盖 512 个粗码区间，每个区间使用相同的两组固定选片。每档另外在粗码 0、1、255、256、511 的两个物理状态上各求 32,768 个输入中点，共 327,680 笔直接两节点仿真，逐码比较采样和积分码宽。四组的直接余量与区间仿射预测相差均小于 0.52 fV，逐码码宽差小于各自局部坡道的一个采样步长。

事后与已有固定 A/B＋LMS 的同一物理路径比对，12／16 位两种 ADC2、2%／3% 两档的 4,096 点留出输入、选片、粗码、主子开关、余量、ADC2 原码及名义重构均逐元素相同。比较使用两节点和理想量化行为模型，时偏和热噪声关闭。

```bash
PYTHONPATH=.:src OPENBLAS_NUM_THREADS=1 MPLBACKEND=Agg \
  python -m task1.experiments.uncalibrated_linearity \
  --out build/task1/uncalibrated
PYTHONPATH=.:src OPENBLAS_NUM_THREADS=1 MPLBACKEND=Agg \
  python -m task1.experiments.uncalibrated_linearity --adc2-bits 16 \
  --out build/task1/uncalibrated/adc2_16bit
```
