# 八片 dither 与 LMS 片上重构

`sar20_lms_recon` 接收同笔 ADC2 原码与八片实际底板掩码。配置端口在采样前顺序装入 396 个字，包含每片有效电荷权重和增益。转换时以实际转换主位、子阵列转换位减采样位计算补偿，输出 20 位有符号码后交给 CAAZ。训练可在片外进行，每颗芯片可独立装载系数。 [数值与时序合同](SPEC.md) · [整体流水](../task_integration/LMS_PIPELINE.md)

用 2%／3% 固定失配、dither OFF／ON 的 16,384 笔归档原码及实际掩码验证。RTL 与独立 Q28 整数参考全部相同。相对归档浮点行为，128 笔在输出阈值附近相差一位，最大绝对差为 1 LSB20。

| 失配 | Dither | −1 LSB20 | 相同 | +1 LSB20 |
| ---: | :--- | ---: | ---: | ---: |
| 2% | 关 | 33 | 4,058 | 5 |
| 2% | 开 | 30 | 4,062 | 4 |
| 3% | 关 | 15 | 4,076 | 5 |
| 3% | 开 | 19 | 4,060 | 17 |

额外测试覆盖全部 4,096 个 ADC2 中点、半开量程、负权重、同笔 ID、重复切片、错误配置、反压、清空和复位。正常 E0 入核后 E22 出结果。独立核接受间隔 13 拍的定向序列以及间隔 16 拍的连续归档样本。16 拍系统速率以宏时序与布线后 6.25 ns STA 为前提。 [实际观察收据](evidence/result.json) · [物理交付](../task2/physical/README.md)

在仓库根目录使用 Python 3.12、NumPy 与 Verilator 重跑。命令同时导出两套可加载的 26 位顺序配置数据。

```bash
python -m task_reconstruction.tools.run_checks --out /tmp/task2-recon-check-001
```
