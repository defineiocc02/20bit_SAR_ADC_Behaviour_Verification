## 一、电容单元与权重

### 1.1 假设的物理结构

```
差分 sDAC：每边 8 个 slice × 16 个主单元 + 4 个子单元
每个主单元 = 1 个 C_u（可接 ±VREF 或 0）
每个 slice 的 16 个主单元中，15 个参与温度计，1 个为"保留零位"
子阵列 4 个单元按二进制/温度计加权，权重为主单元的 1/8 量级
```

### 1.2 代码里实际用的权重

| 单元 | 权重（归一化） | 占总和比例 |
|:---|--:|--:|
| 主列（16 个/片） | 0.25 | — |
| 子阵列 4 个 | 0.0625 / 0.03125 / 0.015625 / 0.0078125 | 合计 0.1171875 |

**每片总和 = 16 × 0.25 + 0.1171875 = 4.1171875**
**8 片总和 = 32.9375**

`[?]` 但 `rdac_voltage()` 只用 16 个主列求和，**把子阵列丢掉了**——这是前向模型 L1 第一版的错误来源。

### 1.3 `[!]` 子阵列与主列的比例对不上

| 项 | 值 |
|:---|--:|
| 主列 1 个 LSB（= 1 列切换） | 0.25 |
| 子阵列 4 单元合计 | 0.1171875 |
| 比值 | **0.469** |
| 若子阵列要覆盖 1 个主列 LSB，应为 | 0.25（比值 1.0） |

**含义**：9 位码的最低 2 位只代表 0.47 个主列 LSB，
即码值不是均匀加权的 —— 在 k[1:0] 从 3 翻到 4 时会出现约 0.53 LSB 的跳变。

**这条要么是我的推导错，要么权重公式错。** 权重实际生成在 `tools/gen_vec_topw.py:build_weights`，
我没有读那一段（预算所限），需核对。

## 二、主/子阵列的桥接

### 2.1 我假设的桥接关系

```
主阵列：15 个 C_u 串/并混联，提供 4 位温度计（H = k[8:5]）
子阵列：4 个衰减电容（串 C_u/8 量级），提供 2 位（k[1:0]）
桥接电容：把子阵列的电平缩小 1/4 后叠加到主阵列 LSB 以下
```

### 2.2 实际情况

**代码里没有桥接电容这个物理对象**，只有权重的数值关系。
`[E]` 当前的"桥接"纯粹是权重表里的数，没有对应到任何电路元件。

**这是物理合同最缺的一环**：论文/专利只有框图，我没有任何依据说"桥接比应该是多少"。

## 三、mask → 开关命令

### 3.1 当前映射

```python
mask[s][j] = 1  →  该单元的底板接 -VREF
mask[s][j] = 0  →  该单元的底板接 +VREF
```

对差分对：输出电压 = `-Σ(±VFS · w) / Σw`

### 3.2 `[?]` 推导出的 DAC 传递函数

设 mask 中 1 的个数为 N（8 片 × 16 列 = 128 个单元中）：

```
V_out = VFS · (2N/128 − 1)
```

- N=0（全 0）→ −3 V
- N=128（全 1）→ +3 V
- 但 9 位码只用到 N 的**部分组合**（H 温度计 + M 纵向 + 子阵列），
  且最大可达 N 未必等于 128

`[!]` 按 `mask_from_k(k=511)` 计算：H=15、M=7，则
N = 8×15 + 7 = 127（子阵列另计），
对应 V = 3×(2×127/128 − 1) = **2.953 V**，不到 +3 V。

**即码的满量程端点与 ±VFS 之间有约 1.6% 的空隙**，需确认是有意设计还是漏洞。

### 3.3 缺什么

| 缺项 | 说明 |
|:---|:---|
| 开关级映射表 | 现在只到"单元接 ±VREF"，没有"哪个管子由哪个信号控制" |
| 采样相/转换相区分 | 采样时底板接 Vin，转换时接 VREF；当前模型没有相位区分 |
| 保留列的物理实现 | 代码里保留列恒 0，但物理上它是"固定接某一侧"还是"通过 MUX 换成零"，没定 |

## 四、ADC2 窗口与增益

| 参数 | 代码值 | 出处 |
|:---|:---|:---|
| 窗口 | `[0, 0.45] V` | `[E]` 工程假设，无论文/专利依据 |
| 增益 | 32× | `[E]` 工程假设 |
| LSB | 0.45/4096 = 109.9 µV | 由窗口推出 |
| 折算到输入 | 109.9/32 = 3.43 µV | — |

**这三条都没有出处。** 既有 `docs/RESIDUE_MARGIN.md` 记录了
真实余差 −10.0 ~ +22.1 mV、压力档有效率 80.69%，说明窗口是**被余差反向约束出来的**，
不是设计给定的。

`[?]` 若窗口改为 `[-0.45, +0.45]`（双极性），有效率和 LSB 都会变。

## 五、20 位码与量纲

| 项 | 定义 |
|:---|:---|
| 码制 | Offset binary，`2^19` = 零点 |
| 满量程 | 6 V 差分（±3 V） |
| LSB₂₀ | 6/2^20 = **5.72 µV** |
| 电压换算 | `V = (code/2^19 − 1) × 3` |

**这条是清楚的、可用的。**
