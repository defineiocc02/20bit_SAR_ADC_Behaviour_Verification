# D2 第二阶段：Follower → DEM → 8 片物理 mask

## 实现

| 环节 | 做法 |
|:---|:---|
| 事件码 | `follower_rt` 的 `ev_k_o`（协议 v2，已冻结） |
| 事务状态冻结 | `ev_start_i` 当拍锁存 `reserved / h_phase / v_phase`，事件期间只读锁存值 |
| DEM | 每事件把 `ev_k_o` 送 `dem_shuffle`（与整码路径**同一个模块**，非另写一套） |
| mask 组装 | `mask[s][j] = (j==res) ? y[s] : h[j]`，子阵列 `j18=k[1], j19=k[0]` |
| 输出 | `ev_mask_o[159:0]`（8 片 × 20 单元）+ `ev_ids_o[39:0]` + `ev_mask_valid_o` |

**mask 与 `ev_k_o` 同拍组合输出**，保证"事件码 ↔ 该码的 mask"一一对齐。
（最初做成寄存输出，结果比 `ev_k_o` 晚一拍，TB 报 `MASK c=1 n=8 不符`。）

## `prefix < Upper` 的越界处理（审阅第 4 条）

早期前缀小于 Upper **不等于最终粗码非法** —— 中间事件的前缀本来就可能很小。

采用的处理：

```
该事件不输出命令：ev_mask_valid_o = 0
码不钳零后当合法命令使用
同时 ev_err_o = 1 上报
```

即"**保持上一次合法命令 + 报事件异常**"，而不是把 `k=0` 当成有效开关命令。

## 验证

`tb/tb_follower_int.sv`，期望 mask **由 TB 独立计算**：
按 `_horizontal_columns` 的语义用"从起点起置 H 个 1"的循环重建，
不是照抄 RTL 的取模表达式，也不用最终码 `c_i` 预生成。

### 未覆盖

- DEM 不同相位（`h_phase/v_phase` 在 TB 里固定为 0）
- 9 种片组（TB 只用默认片组）
- 连续事务（每笔之间隔了 start，但没有背靠背）

## 两项验收

| 项 | 判定 | 说明 |
|:---|:---|:---|
| **D2 事件生成与 DEM 物理 mask 驱动** | **PASS** | 4968 事件逐事件 mask 全部对上 |
| **事件流与完整数字重构事务的集成** | **PARTIAL** | 事件路径已能出 mask，**但重构主数据路径仍直接用 `c_i` 生成 mask** |

**必须明确：这是"事件控制路径已实现、重构主数据路径尚未切换"。**
