# model_conventions — 统一节点、单位与量程口径

> **文档定位**：任务书 §3.1 要求的统一口径声明。所有模块、实验与报告引用
> 同一套定义；任何公式先过本文的量纲口径再谈数值。与 `mechanism_inventory.json`
> （机制清单）、`sources_manifest.json`（原文证据）配合使用。
> 变量名以 `src/adi_model/config.py` 的真实字段为准，本文不发明平行命名。

## 1. 电压：单端/差分、峰值/峰峰值/RMS

| 量 | 定义 | 代码锚点 | 备注 |
|:---|:---|:---|:---|
| 差分满幅峰值 | `v_fs = 3.0 V`（±3.0 V 差分，单端对中间共模 ±1.5 V） | `config.v_fs` | 全文"满幅"均指此值 |
| 输入峰峰值（差分） | `2·v_fs = 6.0 V` | — | 只在 FFT 满幅 dBFS 换算时出现，注明口径 |
| RMS（满幅正弦） | `v_fs/√2 ≈ 2.121 Vrms` | `config.py` 内 `vfs_rms = v_fs/√2` | DR/NSD 换算统一用此口径 |
| 披露自洽口径 | [00] NSD 8.8 nV/√Hz ↔ DR 94.6 dB（正文 94.2） | `engineering_vs_patents_papers.md` §5 | 模型取 94.6，理由：与 NSD 自洽；两披露值的差异保留不静默统一 |

**禁止**：同一变量在一个公式里当峰值、另一个公式里当峰峰值。凡出现 `2·` 差分系数，必须写明来源（差分信号两支路各贡献一份，还是量程定义翻倍），不得无解释写死。

## 2. 各级 LSB 与量化步长

| 量 | 定义 | 数值（默认配置） | 代码锚点 |
|:---|:---|:---|:---|
| 一级判决数 | `2^b1`，b1=7（ADR 0003 读法，ASSUMED） | 128 | `config`、`tests/audit/test_audit_findings.py::TestF1FirstStageReading` |
| 一级步长 Δ1 | `2·v_fs/2^b1` | 46.875 mV | `config.delta1` |
| RDAC 单位步长 | `2·v_fs/512` | 11.719 mV（= Δ1/4，dither 比粗量化细 2b 的载体） | `config` 注释行 31 |
| ADC2 步长 Δ2 | 由 ADC2 量程与位数推导 | 109.9 µV；折输入 Δ2/G0 = 0.6·LSB20 | `config.delta2`、validate 判据 1 |
| 20-bit LSB | `2·v_fs/2^20` | 5.722 µV | `config.lsb_target` 语义 |
| 20-bit LSB ↔ ppm | 1 LSB20 = 1/(2^20−1) ≈ 0.954 ppm（满幅比口径） | — | 换算显式写出，禁止含糊 |

**残差可恢复窗口**：`window = (ADC2 余量)/G0`，当前配置 = 0.15 V/32 = 4.6875 mV。
这是**配置条件推导值**，不是专利披露的固定容差（[09] §1.3 只披露机制）。
量程或增益一变，窗口联动——见 `mechanism_inventory.json` M02。

## 3. 电容：五个不可混用的量

任务书 §3.1 明确禁止用一个 `C_total` 代替所有节点含义。本工程区分：

| 量 | 物理含义 | 代码锚点 | 失配归属 |
|:---|:---|:---|:---|
| `c_total0` | 制造总采样电容（RDAC 全部单位阵列，cap_scale=1 时 20.5 pF） | `config.c_total0` | 器件，随芯片抽取、跨样本保持 |
| 实际输入负载 `c_sig(alloc)` | 当前转换组实际持有的电容（随 slice 调度变化） | `pipeline` 经 `SlicePool`/`chip.C_true` | 器件（同上，不随样本重新抽签） |
| 信号电荷系数 | 每单位接入信号支路的系数（差分/单端比在推导处显式写） | `chip.py` | — |
| 噪声等效电容 `C_n,eq` | 观测通路折算噪声的等效电容 = `C_sig²/(A+β²B)` | `noise_phase.py` | 推导量，非器件 |
| RA 反馈电容 `C_F_true` | 真实反馈电容（失配属于器件）；名义值 = `c_active_nom/G0` | `config` validate（`cf_expect` 校核） | 器件 |

**单一物理状态来源原则**（任务书 §3.2）：同一组实际被选中的物理元件必须同时
参与采样电荷、DAC 电荷、信号增益与噪声传递。失配绑定到物理选择
（`TestF2SliceCausality::test_mismatch_binds_to_the_physical_selection`），
禁止"调度一套数组、DAC 另一套、增益第三套常数"。

## 4. 时间与频率

| 量 | 定义 | 备注 |
|:---|:---|:---|
| 物理时间 `t` | 秒（SI） | 所有建立/带宽公式单位检查基准 |
| 周期索引 `n` | 样本序号（无量纲） | `t[n]` 由采样事件时间戳给出，禁止 `t = n/fs` 偷换（交织/多相调度下不成立） |
| 采样率 `fs` | 40 MS/s（[00]） | 子通道速率 = fs·(转换组周期关系决定)，不由 `fs/2` 默认 |
| 采样周期 `T` | 1/fs = 25 ns | [12] 标度律 `f_min=ln(1/ε)/(2πT)` 中的 T 即此 |
| ENBW | 等效噪声带宽，按具体传递函数积分定义 | 与 −3 dB 带宽、Nyquist 频率三者区分，报告引用时注明口径 |

**PSD/ASD 口径**：单边谱（噪声积分带宽 = 正频率轴积分）；ASD 单位 V/√Hz，
PSD 单位 V²/Hz。FFT 单 bin 噪声底与积分噪声在 metrics 中分开输出，
禁止混报（`metrics.py`）。

## 5. 码值与符号约定

- 差分输入 `x` 为正 → 粗码增大方向为正；RDAC 电荷关系 `C_F·v_R = Q_sample − Q_D`
  的符号以 `rdac.py`/`charge_ref.py` 的节点方程推导为准（M15），
  不把闭式公式当公理——独立参考求解器逐相位重推。
- dither 符号约定：注入为 +，数字扣除取同名反号（三要素配对，
  `TestF3DitherUnits`）；整数 dither 不进粗码（[10] §2.6）。
- ADC2 单极性窗口 [−0.15, +1.65] V（`config.adc2_v_min/max`）；
  观察器校正值**先量化后扣除**，不占模拟量程（ADR 0006）。

## 7. 量纲检查规则（门禁级）

1. 每个设计公式登记输入/输出单位；单位缩放等价测试（V↔mV、F↔pF、s↔ns）
   结果必须不变。
2. 相对建立误差（无量纲）与绝对输出误差（V 或 C）分开陈述；
   位数换算必须写明满幅口径（§1/§2）。
3. 电荷公式输出单位 C（库仑）；数值闭合阈值按问题尺度与浮点条件数制定，
   1e-25 C 只作为本规模下的一致性记录，不解释为亚电子电路精度（M15）。
4. 带宽/噪声换算禁止未经推导的"带宽比 = 电荷比"（v7.0.10 修复教训，
   `interleave_tracking.filter_bw_relative/absolute` 为正确口径）。
