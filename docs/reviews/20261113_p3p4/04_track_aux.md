# P3-4 TRACK 预置与 AUX 辅助输入：输入电荷记账

> **本文已按外部审查 A03/A05 修订**。两处结论被撤回：
> ① 旧的 6.36× 用了 lookback=1，在两相流水线里非因果；改为 lookback=2 后是 **3.20×**。
> ② "350 µA_pp 对应 0.907 MHz"整段删除——论文该曲线横轴是**直流差分输入电压**，不是频率。
> 详见 [09_audit_response](09_audit_response.md)。

> 论文（§9.8 p.2）："the input current is linear with 350 μA_PP magnitude, allowing
> low-power drivers, normally used for sub-10MS/s ADCs"；"the ADC input filter bandwidth is
> reduced by a factor of ~2.5× due to full-period input signal acquisition"。
> 专利：US10797889（交织/预跟踪）、US10541702（auxiliary input for ADC input charge）。

代码：`src/adi_model/track_aux.py`；测试：`tests/unit/test_track_aux.py`（7 项）；
证据：`data/p3_mechanisms.json` → `track`。

## 1. 机制定义（本模型实现的部分）

| 机制 | 电荷从哪来 | 本模型算什么 |
|:---|:---|:---|
| TRACK | 空闲片底板按上一笔已决码预置，电荷来自参考轨/预充缓冲 | `|C_i(x[n] − x[n−1])|` 的实际逐片电容求和 |
| AUX | 独立辅助输入副本承担大部分电荷 | 与 TRACK 同一电荷式，只是来源换成 aux 缓冲 |

两者都只做**电荷记账**：不建运放、不积分 RC、不声称建立时间。

## 2. 因果性

| 检查 | 结果 |
|:---|:---:|
| 有合法来源的笔数 | 4 094 / 4 096（前 2 笔无来源） |
| `future_sources`（来源 ≥ 目标） | **0** |
| `self_sources`（来源 = 目标） | **0** |
| `late_sources`（来源就绪晚于预置窗口） | **0** |
| 恒定直流输入（旧判据会误报） | ✅ 不再判为偷看 |

判据改成**时间**：来源判决在 `(source+1)/fs` 可用，预置在 `n/fs − lead` 开始，
要求 `ready < precharge`。旧版用"预测值等于目标值"判偷看，恒定直流输入合法地满足该等式，
会被误判（审查 A03 的最小反例）。前 2 笔 `valid=False`、预测值 NaN。

**回看必须是 2 笔**：两相流水线里第 n−1 笔的判决到本笔孔径才完成，没有预置窗口；
`lookback=1` 现在会被判 `late_sources>0`、`causal=False`（已有负例测试）。

## 3. 输入电荷实测（4096 笔 1 MHz 满幅正弦）

| 量 | 值 |
|:---|:---|
| 采样总电容（8 片合计） | **20.50 pF** |
| 无预置时平均 abs(dQ)/笔 | 39.05 pC |
| 有 TRACK 时（lookback=2，数字码本重建预测） | **12.2 pC** |
| 电荷降低倍数 | **3.20×** |
| 1 MHz 相邻差（峰值 / 峰峰值） | 0.4708 V / 0.9415 V |
| 对应电流（峰值 / 峰峰值） | 386 µA / **772 µA_pp** |
| 与论文 350 µA 的关系 | **不可比**：论文横轴是直流差分输入电压 |

读法（已修正）：论文 Fig.9.8.5 的输入电流横轴是**直流差分输入电压**，
不是正弦频率，因此"用 350 µA 反解频率"不成立，该结论已撤回。
本模型能给的只有电荷吞吐：`C_total × ΔV × fs`，以及正弦相邻差的峰值/峰峰值分列。

**必须区分峰值与峰峰值**：相邻样本差是 `2A·sin(πf/fs)`，这是**峰值**，峰峰值是它的两倍。
旧版把峰值标成 pp，导致电流差 2 倍（审查 A05）。线性近似 `2πfA/fs` 在 f/fs→0.5 时还会高估 57%。

## 4. 与论文 "input filter bandwidth ×2.5" 的关系

全周期采集把 `T_ACQ` 从 25% 提到 100% `T_CLK`，允许的抗混叠带宽按同样比例放宽。
本模型能算的是**电荷**（§3），不能算**滤波器带宽**——那需要外部 RC 与驱动网络参数。
所以本条只列机制、不列数字。

## 6. 不能声称

* 不能声称 TRACK/AUX 已进入主 `pipeline` 的逐笔循环——本轮只在电荷域完成记账与因果审计。
* 不能声称输入电流"复现"了 350 µA：论文横轴是直流差分输入，与正弦频率不构成同一口径。
* 不能声称驱动功耗：电荷×fs 是电流下界估计，不含缓冲静态电流与建立开销。
* 不能声称 AUX 的源阻抗/噪声已建模：那需要独立的 aux 支路参数，目前没有。
