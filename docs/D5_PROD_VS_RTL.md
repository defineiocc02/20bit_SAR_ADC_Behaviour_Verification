# 生产 Python ↔ RTL 对拍：19/420 失配的定位

基线 `c151672`。**结论：RTL 侧自洽，差异在 Python 生产路径。**

## 独立复算（用探针向量里的 wm/g/inv/adc/dither）

```
wm=4825363371  g=34340654825  inv=33573079  adc=2000  word=44

I 重算 = 33573079                      与向量一致
num    = 6Wm−3G = -74069784249
d      = num*I >> 36 = -36186986       与 RTL 探针一致
r̂      = ((2·2000+1)·144+2)/5 = 115229 与 RTL 一致
t      = 44 × 24576 = 1081344          与 RTL 一致（此前的 56 是我手算错）
x      = -34990413                     与 RTL 一致
q      = -364483                       与 RTL 一致
code   = 524288 - 364483 = 159805      与 RTL 一致
```

**所以 RTL 的每一级都能用纯整数从头算出来，且与探针值逐位相同。**
期望值给的是 159804，说明 Python 生产路径输出的不是 159805。

## 因此

- 不是 RTL 实现错
- 不是 dither 位权错（先前判断有误，已更正）
- 是 `run_transaction()` 内部某处与"用导出字段重算"不等价
