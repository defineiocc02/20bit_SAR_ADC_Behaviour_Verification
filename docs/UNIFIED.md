# 统一系统级闭环（单一入口）

入口：`tools/e2e.py`，函数 `convert(vin, rdac, coef, group, sample_id, ...)`。
链路：

```
V_IN → SADC（比较器逐位）→ Follower（逐事件驱动 RDAC）
     → RDAC（真实电容电荷）→ RA → ADC2 → D5 → D_OUT(20b)
```

## 一、此前 5 个脚本的分歧（统一入口如何消除）

| 脚本 | SADC 假设 | ADC2 假设 | RA 假设 | 主要分歧 |
|:---|:---|:---|:---|:---|
| `closed_loop.py` | 无（k 随机给定） | 单边 + floor | 理想 32× | k 不由输入产生 |
| `closed_loop2.py` | 解析式理想 SADC | 单边 + floor | 理想 32× | SADC 与 RDAC 解耦 |
| `dither_physical.py` | 解析式理想 SADC | 单边 + floor | `behavioral/ra.py` | 同上 |
| `dem_abcd.py` | 解析式理想 SADC | 单边 + floor | 无 RA | 同上 |
| `dem_ideal_sadc.py` | 解析式理想 SADC | 宽窗 | 无 RA | 同上 |

**共同问题：所有脚本的 SADC 都用解析式 `D_ideal(k)`，与真实 RDAC 是两套独立模型。**

统一入口的做法：**SADC 的比较器直接看真实 RDAC 的输出** `rdac.vout(k)`，
不再是理想的解析直线。这样 SADC 与 RDAC 之间没有"两套模型"的分歧。

## 二、关键发现：此前的溢出率是**混合假设的产物**

`multiseed.py` 报告压力档只有 81% 有效——那是**理想 SADC + 真实 RDAC** 的组合：

```
理想 SADC 给出 D_ideal(k) ≤ x < D_ideal(k+1)
真实 RDAC 的 D_real(k) 可高出 D_ideal(k) 最多 11.4 mV
=> 余差可能为负，落出窗口
```

但真实芯片里**比较器就接在 RDAC 上**，不会拿理想直线去比较。
统一入口用真实 SADC 后：

| 配置 | N | L1 宽窗 rms | L2 真实窗 有效 | L2 rms |
|:---|--:|---:|---:|---:|
| 压力 / 真系数 | 2000 | 0.0 µV | **2000/2000** | 27.0 µV |
| 压力 / 名义系数 | 2000 | 3609.6 µV | **2000/2000** | 3609.2 µV |
| 目标 / 真系数 | 2000 | 0.0 µV | **2000/2000** | 1.0 µV |
| 目标 / 名义系数 | 2000 | 360.8 µV | **2000/2000** | 360.8 µV |

**余差在真实闭环下恒为 `[0, step)`，天然落在窗口内。**

### 但不能就此宣布窗口没问题

余差上界是**该码的实台阶**，实测台阶最大 15.93 mV > 窗口 14.06 mV。
**当台阶超过 14.06 mV 时仍会溢出**，只是本轮 2000 点未命中。

**所以准确结论是：**
- 80.69% 那个数字**不是**真实架构的失效概率，是"理想 SADC 对真实 RDAC"的错配产物
- 真实闭环的溢出率取决于**台阶 > 14.06 mV 的码占比**，需专门统计（本轮未做）

## 二·补：SADC 与 RDAC 必须物理分离（审阅指出，已修正）

**此前的错误**：`e2e.py` 让 SADC 的比较器直接读 `rdac.vout(k)`，
等于**共用同一组电容实例**，人为消掉了"量化器与 RDAC 的失配"——
而这恰恰是论文强调要验证的关键非理想（量化器 sDAC 与 RDAC 匹配 > 11 位）。

**修正**：拆成两个对象

| 对象 | 内容 |
|:---|:---|
| `SADCModel` | **自己的** 512 项 LUT（独立失配 + 固定失调），比较器只查它 |
| `RDElement` | 18 片物理阵列，只接收 Follower 送来的已决码 |
| `follower_drive()` | 把 SADC 的判决序列逐事件送给 RDAC；**RDAC 不参与比较** |

## 二·补 2：分离后的真实数据（N=1500，amp 1.5 V，bin 211）

### 三条结论

1. **sDAC 失配（1e-4 ~ 1e-2）对结果几乎没有影响。**
   主导误差来自 RDAC 失配，不是量化器 sDAC。
2. **目标档 rms 0.99 µV = 半 LSB，已达量化底线**，有效 98.1%，clamp 为 0。
3. **压力档 rms 484 µV，不是之前耦合模型报的 27 µV。**
   耦合 SADC 把 RDAC 失配"吃掉"了，所以看起来只有 27 µV。
   另有 **60 笔 clamp**（余差顶到 14.06 mV 上沿被截断），
   这些样本仍标 `ok` 但解码值有 `step−14.06` 量级的误差，是 484 µV 的主要来源。

**因此此前"压力档 27 µV"的读数作废。**

## 三、三档验收状态

| 档位 | 内容 | 状态 |
|:---|:---|:---|
| **L1 理想架构** | 独立 SADC + 真实 RDAC + 理想 RA + 宽 ADC2 | **PASS**（数据流闭合） |
| **L2 真实窗口** | ADC2 恢复 0~0.45 V 单边 | **PARTIAL**：目标档 98.1% 有效 / 0.99 µV；压力档 82.9% / 484 µV + 60 clamp |
| **L3 完整非理想** | 参考建立 / RA 动态 / 噪声 / 时序交织 | **NOT_RUN** |

### L3 为什么没做

`behavioral/reference.py`、`ra.py` 的噪声与建立参数需要先确定物理值
（参考缓冲带宽、RA settling 时间常数、采样网络 RC），这些**论文未给出**。
若随意假设就是编数据。当前只把 `ResidueAmplifier` 接进来（未启用噪声）。

## 五、判定标准

- **L1 通过条件**：全样本 `status == ok`，且真系数下 rms ≤ 2× 半 LSB
- **L2 通过条件**：记录全部溢出样本；有效样本 rms 与 L1 同量级
- **L3 通过条件**：接入至少参考建立与 RA 有限带宽，指标可对照论文

## 六、当前能说与不能说

**能说**
- 端到端链路 `V_IN → D_OUT` 已闭合，粗码由比较器真实产生
- 真系数下重构精度 0.0 µV（L1）/ 1.0 µV（目标档 L2）

**不能说**
- 不能说"ADC2 窗口没有问题"——长台阶溢出未统计
- 不能说 80.69% 代表真实失效概率——那是错配产物
- 不能说 L3 完成——参考建立、噪声、时序交织均未接入

# P0：饱和与失效统计修正（2026-11-14）

## 修正内容

| 之前 | 之后 |
|:---|:---|
| `arr, _sat = ra.evaluate(...)`，**丢弃饱和标志** | 保留 `ra_sat`，饱和即判 `status="ra_sat"` |
| `a2 = min(a2_raw, 4095)`，截断样本仍算 `ok` | `a2_raw >= 4096` 直接判 `status="adc2_clip"` |
| 只统计 `ok` 的数量，误差把失效样本也算进去 | 分别给 `valid_only_rms` 与全样本残差 |

## 重跑结果（N=1500，amp 1.5 V，bin 211，sDAC 失配 6e-4）

### 压力失配 1% / 1.5% / 2.5%

| 状态 | 笔数 |
|:---|---:|
| ok | **1184** |
| adc2_overflow（RA 输出 < 0 或 > 0.45 V） | **256** |
| ra_sat（RA 限幅） | **60** |

- **有效转换率 78.93%**（不是之前报的 83%）
- **valid_only_rms 0.97 µV**（量化底线）
- 全样本残差 rms 3330 µV

典型失效样本：

```
adc2_overflow  r = −1.73 mV   ra = −55.4 mV   （余差为负）
ra_sat         r = +16.42 mV  ra = +450.0 mV  （RA 顶到 0.45 V）
adc2_overflow  r = −2.22 mV   ra = −71.2 mV
```

### 目标失配 0.1% / 0.15% / 0.25%

| 状态 | 笔数 |
|:---|---:|
| ok | **1472** |
| adc2_overflow | **28** |
| ra_sat | 0 |

- **有效转换率 98.13%**
- **valid_only_rms 0.99 µV**
- 全样本残差 rms 35.2 µV

## 484 µV 的真实来源（已查清）

**之前的 484 µV 是统计污染，不是重构精度。**

- 60 笔 RA 饱和 + 256 笔窗口溢出，这些样本**仍被当作 ok 参与误差统计**
- 它们解码出来的值偏差达毫伏级，把 rms 从 0.97 µV 拉到 484 µV

**剔除失效样本后，压力档的重构精度仍是 0.97 µV（半 LSB）。**

**所以正确的结论是：**
- 重构精度没有问题是 **0.97 µV**
- 问题是**有效转换率**：压力档 78.93%、目标档 98.13%
- 两者必须分开报告，不能用一个 rms 概括

## SADC 模型的局限（必须声明）

当前 `SADCModel` 是**512 码独立随机 LUT**（正态扰动 + 固定失调），
**不是物理电容失配模型**：

- 没有真实电容阵列结构，码间误差相互独立
- 没有考虑 sDAC 内部的分段/温度计结构导致的误差相关性
- `mismatch` 参数是"每码独立误差的相对量"，不对应任何物理电容失配 sigma

**因此：**
- 本文所有"SADC 失配"结论**只适用于该随机 LUT 模型与所扫参数范围**
- **不能据此推断**物理 sDAC 需要多少位匹配
- 从数据看 sDAC 失配在 1e-4~1e-2 之间几乎无影响，**这个"无影响"本身也可能是 LUT 模型的产物**
  （独立同分布误差在 9 次比较中被平均，而物理失配可能更相关）
