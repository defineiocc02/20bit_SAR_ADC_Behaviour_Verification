# 八片采样扰动数字合同 v1.0

基线 `b592ba8`。本顶层承接 [模块一调度及 Fig.21](../../task1/BRIDGE_SPEC.md)，交付八片采样扰动的控制、逐样本数字标记和 RDAC 最终开关命令。八片正注入是工程选择。讲稿第 17–18 页说明低路进 SADC、RDAC，高路进 RDAC，US10505561B2 Fig.6F 支持加码约定，Fig.19 的七片示例说明整数档和分数档的拆分。[原文索引](../ORIGINAL_SOURCES.md)

## 算术与控制

设 `m=D3:D1`、`U=4D6+D4`、`I=U+2D5`，`L8=16D5+m`、`T8=8I+m`。有序 slot 0 至 m−1 取档 I+1，其他取 I。档位 0 至 8 使用原生 8C、4C、2C、1C 子电容编码。每 slot 掩码 bit 0 至 bit 3 分别控制 8C、4C、2C、1C，bit 4 的 dummy 恒低。8 档仅使 8C 底板接高参考。SADC 辅助 DAC 接收 `L8` 的独立控制，模拟组验证其目标步长和建立时间。两个名义分子单位为 D/8，D 为一档原生注入步长。理想零寄生 Fig.11 几何的 D 为 `Vspan/544`，实际各片的采样注入由标定得出。

当 dither 关闭时该笔的扰动字和采样注入掩码均为零，PRBS31 保持。空拍或调度 stall 无新字。接受时发生器按现有多项式生成六位，并以采样描述符发布。最近两次实际发布的字按样本号匹配。采集组晋升和重载有序，旧样本继续用其已冻结的扰动字。重置优先于种子写入，种子写入优先于采集请求。一次调度接受可支持一组，连续接受不插泡，且采集字发布增加一个数字周期。

使用 10 位无符号加法 `k=c+U`，取低九位之前检查第十位。允许 `k=511`，拒绝 `k>=512`，无回绕、饱和或静默丢样。合法命令沿用模块一映射。新设计只接受最终粗码，转换掩码直接表示最终状态。名义重构按正注入扣除 T，实际权重重构使用同笔 `conv_sample_sub_high_o` 和转换掩码，避免重复计入扰动或桥补偿。模拟 ADC2 过载判断在外部残差路径完成。

## 验收

| 需求 | 验收 |
| :--- | :--- |
| REQ-D8-01 | 六位字全空间、八片档位、高参考位序及 SADC 分子与独立整数参考一致。 |
| REQ-D8-02 | 复位、禁用、种子重载与冲突、stall、连续接受及一次采集延迟与逐沿 oracle 一致。 |
| REQ-D8-03 | 当前转换组匹配最新或上一快照，旧组在空拍中保留，错 ID 和无组请求均拒绝。 |
| REQ-D8-04 | 合法 k 进入模块一 Fig.11/Fig.21 组合掩码及正桥补偿，越界拒绝清零。 |
| REQ-D8-05 | 用同一设计包和 6.25 ns 单域同步约束生成 SKY130HD 代理 GDS，记录 TT 角 setup 和 hold、独立 DRC/LVS 状态。 |

单域所有输入由外部按 `clk_i` 建立保持契约供给。跨域、孔径生成、真实模拟开关绑定、目标 180 nm BCD 和量产签核由上层负责。
