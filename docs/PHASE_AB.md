# 相位发生器 A/B：round-robin vs xorshift

时间：2026-11-15
工具：DC W-2024.09-SP3 + TSMC 28HPC+ `ssg0p81vm40c`，5 ns 约束
脚本：`tools/phase_ab.py`（统计）、`rtl/dem_phase_rr.sv` / `rtl/dem_phase_gen.sv`（RTL）

---

## 一、为什么要做这个对比

ISSCC 2024 §9.8 的 PPT（第 29–31 页）在 DEM 三维度里写的是：

```
3 dimensions of DEM
  · Selection of the slices - 8/18
  · 3b horizontal segmentation
  · Round robin shuffler
  · 3b vertical segmentation
  · Binary to unary bridging        （第 31 页追加）
```

原文写的是 **`Round robin shuffler`** —— 确定性轮转。
而仓库原有实现 `rtl/dem_phase_gen.sv` 用的是 **xorshift32 伪随机**。

这是语义偏离，不是风格差异。所以做了这一版 `dem_phase_rr.sv` 并实测对比，
用数据决定，而不是靠口味。

## 二、统计指标（`tools/phase_ab.py`，17280 拍）

| 指标 | round-robin | xorshift | 胜者 |
|:---|--:|--:|:---|
| 联合覆盖（共 1920） | **1920** | 1920 | 持平 |
| 覆盖百分比 | 100.0% | 100.0% | 持平 |
| χ² reserved (df15) | **0.00** | 9.25 | round-robin |
| χ² h_phase (df14) | **0.00** | 10.34 | round-robin |
| χ² v_phase (df7) | **0.00** | 8.40 | round-robin |
| MI(res, hp) | **0.0000** bit | 0.0079 bit | round-robin |
| MI(res, vp) | **0.0000** bit | 0.0053 bit | round-robin |
| MI(hp, vp) | **0.0000** bit | 0.0035 bit | round-robin |
| 一周期内重复数 | **0** | 710 | round-robin |
| 最小周期 | 1920 | >17280 | — |

**关键差异不是"谁覆盖更多"（都满），而是三项结构性优势：**

1. **χ² 恰好为 0**：1920 拍里每个值出现次数**完全相同**。这是构造保证，
   不是采样运气。xorshift 的 9.25 / 10.34 / 8.40 虽都远低于临界值
   （25.0 / 23.7 / 14.1），终归是概率性的大致均匀。
2. **三轴 MI 为 0.0000**：线性分解在完整周期上恰好使三轴统计独立。
   xorshift 的 MI 虽已很小（0.0035–0.0079 bit），仍不为零。
3. **一周期内零重复**：同一 (res,h,v) 三元组在一轮 1920 拍里只出现一次。
   xorshift 在 17280 拍里有 **710 次**三元组重复。

### 为什么 round-robin 能同时"确定"又"满覆盖"

这是本方案的关键，也是它和"三条独立计数器"的本质区别：

- **三条独立计数器**会退化成三轴同步推进，(res,h,v) 只在一条对角线上取值，
  联合覆盖永远只有 1920 中的一小部分 —— 这是错误的做法。
- **单一索引线性递增 + 混合进制分解**，等价于把 1920 个组合按混合进制
  排成一个环依次遍历。一个周期**恰好**覆盖全部 1920 组，每组一次。

即：`idx: 0,1,2,...,1919,0,...` → `(idx/120, (idx/8)%15, idx%8)`。

## 三、综合结果（5 ns 约束，TSMC 28HPC+ SS）

| 指标 | `dem_phase_gen`（xorshift） | `dem_phase_rr`（round-robin） | 改善 |
|:---|--:|--:|:---|
| 单元数 | 804 | **149** | **5.4×** |
| 时序单元 | 43 | **11** | 3.9× |
| 总面积 | 392.78 µm² | **77.71 µm²** | **5.1×** |
| 组合面积 | 309.19 µm² | **57.23 µm²** | **5.4×** |
| 关键路径延迟 | 4.38 ns | **0.57 ns** | **7.7×** |

**差距来源很清楚**：xorshift 版要算 `t3 % 1920`（32 位常数取模，
综合展开成大片组合逻辑，这是 146 级逻辑、7.91 ns 的主要来源）。
round-robin 版只需要"11 位比较 + 清零"——因为索引恒小于 1920，
`idx+1` 最多到 1920，加 1 后判断是否回 0 即可，**根本不需要取模运算器**。

顺带修正我之前的判断：我在 `docs/SYNTH_D3D4.md` §三 说"7.91 ns 是自然实现，
可以接受，因为 40 MS/s 有 3 倍余量"。现在看，那个决定是**可以更好**的——
不是"必须接受"，而是"当时没试 round-robin"。这条我承认。

## 四、代价：确定性周期 1920 拍

round-robin 的最小周期**恰为 1920 拍**（xorshift 在 17280 内无明显周期）。

**这个周期会不会在频谱上产生杂散？**

- 40 MS/s、每笔事务推进一格 → 1920 拍 ≈ **48 µs**，对应 **20.8 kHz**。
- 对 20b/40 MS/s 的 ADC，Nyquist 是 20 MHz；20.8 kHz 的周期性
  只会把失配残差能量集中到基频附近的几个边带，而不是折叠到带内。
- 更关键：**DEM 的作用是让失配误差与信号解相关**。确定性遍历
  排除了"某些码长期由同几个单元承担"这种最坏情况，这恰恰是 DEM 想要的。

不过必须诚实：**确定性周期在原理上不如伪随机"干净"**。
若后续实测发现 20.8 kHz 附近出现不可接受的杂散，可以：
- 加大 STEP（如 +7，与 1920 互质，周期不变但遍历顺序不同）
- 或回到 xorshift

这个判断需要频谱实验数据，本轮**没做**（见 §六）。

---

## 五、结论与选定

**选 round-robin（`rtl/dem_phase_rr.sv`）**，理由按权重排序：

1. **与原文一致**：PPT 明写 `Round robin shuffler`。这条权重最高——
   我们的目标是复现机制，不是优化机制。
2. **统计指标全面更优**：χ²=0、MI=0、零重复（三项都是构造保证）。
3. **面积降 5.1 倍、延迟降 7.7 倍**：这不是小优化，是 315 µm² 与 3.8 ns 的量级差。
4. **代价可控**：1920 拍 ≈ 48 µs 的确定性周期，对 20 MHz Nyquist 无威胁。

`dem_phase_gen.sv`（xorshift）**保留**，作为 A/B 对照与可回退路径，
但不再是 `d3d4_ip` 的默认实现。

---

## 六、本轮明确没做的

| 项 | 原因 |
|:---|:---|
| 频谱实验（杂散对比） | 需要接入完整 ADC 闭环与 FFT 工具链，超出本轮"数字 IP"范围 |
| 多 STEP 值扫描 | 只看 STEP=1；若将来发现周期风险，可扫 1/7/13…… |
| 与 dither 的联合分布 | 两者独立生成，联合覆盖未测 |

**因此本文能证明的是"统计与面积更优"，不能证明"频谱更优"。**
后者需要模拟侧闭环，本轮不在范围。
