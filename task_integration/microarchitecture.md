# 顶层微架构

`dither8_top` 接受分配请求，内部复用 `module1_bridge_top`。申请待决位保持到采样描述符发出，或由 stall／种子错误取消。转换占用位由调度发布和扰动字匹配建立，由同笔重构握手清除。占用期间模块一无法晋升新组，ADC2 晚到时已有转换组不会被覆盖。

CAAZ 在模块二采样描述符发布后的下一沿产生采样控制。模块二描述符保持至下一次发布，顶层以共同 ID 组合采样有效。错配抑制采样并锁存独立对齐故障。两笔 CAAZ 样本可使用不同的切片和不同扰动字，实际重构逐笔使用当前转换标签，宏确认两笔的 AZ 代一致。重构后才送 `caaz20_pair`。

合法粗码经模块二映射，顶层把命令、掩码与桥补偿登记到一拍输出。转换占用期间只登记一次命令。错 ID、下溢与早到请求保留当前事务供重试，正确 ID 的坏样本可终止并标记失效。各域从同步清除开始，所有端口契约假定由同一 `clk_i` 驱动。可跨域的模拟接口需由实际宏适配器另行验证。

回归逐沿核对 16 拍周期、随机调度组、实际扰动字与电容掩码、合法和异常事件。合成和布线的验收以 SKY130HD 可复现产物和 STA 为依据。
