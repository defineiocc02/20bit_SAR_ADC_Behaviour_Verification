# 八片扰动控制的独立随机复验

该复验用完整样本 ID 账本保存历史，不依赖 RTL 的两项快照结构。请求、种子和字发布各自按时钟沿记录，伪随机字逐位计算。独立检查的向量交给 Verilator 编译后的 `dither8_top` 逐沿核对。

| 检查 | 本次实测 |
| :--- | ---: |
| 模拟时钟沿 | 20,000 |
| 采集描述符 | 10,638 |
| 合法转换命令 | 3,885 |
| 调度 stall | 2,443 |
| 采集前合法种子重载 | 1,431 |
| 非法种子错误 | 2,216 |
| 合法 ID 的加码越界拒绝 | 608 |
| 转换侧命中当沿新字 | 5,812 |
| 转换侧命中较早发布的字 | 8,476 |
| 不一致 | 0 |

从交付树根目录运行。需要 Python 3.12 和 PATH 上的 Verilator，或用环境变量 `VERILATOR` 指定已安装的工具。输出目录必须尚不存在。

```sh
PYTHONPATH=.:src python task2/eight_rtl/independent_review/run.py --out /tmp/dither8-review-001
```

[机器收据](receipt.json)保留随机种子、工具版本、向量及输入源码哈希。复验覆盖数字控制边界。ADC2 延迟归属及模拟开关建立分别按上层接口验收。
