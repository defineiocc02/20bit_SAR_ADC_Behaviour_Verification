# 数字任务划分：资料复核、当前成果和优先级

> **后续更新：**本文保留 `ba874386` 的独立复核和当时优先级。结构对照的 bridge、参考事件、样本合同以及静态 plant 校准闭环现已更新，当前结果和限制以 [ADR 0021](adr/0021-structural-contract-calibration.md) 和 [首页](../README.md)为准；本文历史“急需解决”语句不代表当前状态。

本评估以仓库 `ba874386` 为代码基线，重新核对 AD4080 Rev. B 手册、ISSCC 2024 9.8 论文与讲稿，以及六项相关专利。保留首页的五块工作，**不把研究机制、行为验证、数字 RTL、产品接口和工艺签核混为同一完成状态**。

## 资料分别回答什么问题

| 资料 | 可用于本工程的证据 | 不能推导出的结论 |
|---|---|---|
| [ISSCC 2024 9.8 论文](https://doi.org/10.1109/ISSCC49657.2024.10454329)，第 182–184 页 | 两级结构、一级量化器与残差 DAC 分离；18 个 slice 中 8 个转换、8 个采样及 2 个备用；二维单元重排、dither；电容权重校正的系数片外求取、片上应用 | 没有给出全部网表、开关编码、训练输入和 RTL，不构成当前实现与芯片逐拍一致的证明 |
| [AD4080 手册 Rev. B](https://www.analog.com/media/en/technical-documentation/data-sheets/ad4080.pdf)，第 19、33、45–52、56–71 页 | 40 MS/s 连续采集、LVDS/SPI 数据接口、FIFO、数字滤波及面向系统信号链的增益/失调修正 | 手册是产品的外部功能和指标要求，不公开全部内部实现；不能据此证明本工程是产品内部电路 |
| [US10516408B2](https://patents.google.com/patent/US10516408B2/en) | 量化器与多 slice 残差形成、数字结果驱动其他 slice 的实施例 | 专利列出多种实施例，不证明工程中的 63+8 电容划分是论文唯一实现 |
| [US10511316B2](https://patents.google.com/patent/US10511316B2/en)；[US10505561B2](https://patents.google.com/patent/US10505561B2/en) | 单元地址重排，以及 dither 注入、跨级传递与数字移除的不同实施例 | DEM 本身不测量失配；dither 的注入点和数字抵消量不能只凭“随机”假定正确 |
| [US10707889B1](https://patents.google.com/patent/US10707889B1/en)；[US10541702B1](https://patents.google.com/patent/US10541702B1/en)；[US10826519B1](https://patents.google.com/patent/US10826519B1/en) | 交织采样与跟踪、辅助输入和参考切换的可选机制 | 不证明这些机制都属于同一个产品实施例，也不替代采样开关、参考和版图的电路验证 |

特别区分两种校正：论文描述的**阵列权重校正**服务于 ADC 核内部电容误差；AD4080 手册第 71 页的**系统增益/失调校正**作用于完整信号链的输出码。两者处理对象和系数来源不同，不能互相替代。

同样，性能数字应分别引用：论文报告 40 MS/s、94.2 dB 动态范围与 9.3 nV/√Hz 噪声密度；AD4080 Rev. B 首页给出的产品典型动态范围为 94.6 dBFS、INL 为 ±4 ppm。两份资料的对象、测试条件和指标口径不能因名称相似而直接互换，更不能把这两个数当成本工程的验证结果。

**文献编号核对。** [论文](https://doi.org/10.1109/ISSCC49657.2024.10454329)第 184 页参考文献 [12] 印作 US 10,797,889；同一条目给出的题名和作者与 [US 10,707,889 B1](https://patents.google.com/patent/US10707889B1/en) 一致，而 [US 10,797,889 B2](https://patents.google.com/patent/US10797889B2/en) 是另一项与 ADC 交织无关的专利。因此本项目按题名与作者选用 10,707,889；这是有依据的编号差异判断，**不是论文作者的正式勘误**。

## 五块工作如何评价

### 1. SAR 控制与转换时序

**意义。** 让量化器判决、残差 DAC 更新、另一组 slice 采样、共享 RA 和 ADC2 精确地属于同一次转换。论文中 quantizer 完成判决后，RDAC 使用已形成的结果更新；这样减少不必要的参考切换和输入扰动。

**现在有什么。** [`sar20_digital_core`](../rtl/top/sar20_digital_core.sv)、[`sar_structural_ctrl`](../rtl/core/sar_structural_ctrl.sv) 与 [`sar_trial_ctrl`](../rtl/core/sar_trial_ctrl.sv) 已有结构相位、3 位 Flash 前缀与后续 SAR 判决、控制输出和样本 ID；[`structural_adc_tb`](../sim/tb/structural_adc_tb.sv) 检查结构路径，Python 模型有采样、残差和 ADC2 行为链。

**急需解决。** Python 的参考负载模型按 trial/reject 构造事件，而结构 RTL 输出已决位事件；固定码 173 的已记录示例分别为 19 与 7 个状态，见[事件对照图和条件](paper_comparisons/README.md#4-建立过程与参考负载可用结果和待补接口)。它们不是同一事件定义，不能直接用前者推算后者的参考电流。应先明确每个事件的码、物理开关、rail、时间和样本归属，再以真实比较器 valid/完成时刻和模拟开关接口复核。

结构核每个样本使用 16 个数字相位；若每相位占 1 个时钟，目标 40 MS/s 对应 640 MHz 的理想时钟预算；这不是已达到目标工艺 640 MHz 的证据。输入/参考建立、TP 采样边沿、比较器和模拟异常仍需模拟设计者提供电路时序及后仿约束。

### 2. DEM、dither 与交织误差处理

**意义。** slice 选择和二维电容单元重排改变固定失配的使用方式，减轻某些与输入相关的集中杂散；dither 在指定位置引入已知扰动并在正确的数据路径中抵消，以配合线性化和激励。交织的失调、增益、时序和带宽差异还需要各自的观测或物理控制。把它们放在同一工作块便于统一调度和样本上下文，但它们不是同一种算法。

**现在有什么。** Python 使用固定物理池和切片选择；RTL 有 [`slice_alloc`](../rtl/core/slice_alloc.sv)、[`dem_state_gen`](../rtl/core/dem_state_gen.sv)、[`dem_addr_gen`](../rtl/core/dem_addr_gen.sv) 与 [`dither_gen`](../rtl/core/dither_gen.sv)。已有偏置、时序敏感性和调度实验；[10 ps 对照](paper_comparisons/README.md#1-10-ps-时序失配误差出现在哪里)显示特定杂散可下降而总 RMS 可能上升。这个 10 ps 是实验假设，随机调度不是时序校正。

**急需解决。** 本次重跑的 bridge 诊断在 **262144 组**项目参考码/状态组合中发现 **130560 组物理掩码不同**；测试比较的是当前 RTL 与项目中的全局 bridge 参考，不代表专利中只有一种正确开关方式。应先选定物理合同，以非等值单元逐状态比较，并把 slice ID、DEM 状态、开关掩码及 dither 与同一样本冻结。dither 的注入和数字移除分别由本块与重构块共同负责。

论文对时序失配的主要说明是共用和匹配采样时钟、开关及版图；对带宽失配主要通过足够高的采样带宽减小影响。**逐 slice 数字时序/带宽估计是本工程可研究的扩展，不应写成论文已经公开的数字闭环。** 若要估计各 slice，需明确已知激励或独立观测、调度矩阵秩及公共失调/相位参考；仅有最终输出和任意未知输入，不能保证各参数可唯一辨识。

### 3. 电容校准与数字重构

**意义。** 将可测数字观测和独立参考用于估计有效单元权重，再把冻结系数用于粗码、细码和已知注入量的重构。这对应论文“片外求系数、片内应用”的公开边界；它与下一块的系统级两点校正不同。

**现在有什么。** [`fit_unit_weights`](../src/adi_model/calibration/weight_calibration.py) 使用数字观测及外部参考做满秩检查和拟合，`FrozenCalibration` 冻结系数；[`weight_store`](../rtl/core/weight_store.sv)、[`calib_regs`](../rtl/core/calib_regs.sv)、[`recon_core`](../rtl/core/recon_core.sv) 支持载入与定点重构。[ADR 0019](adr/0019-fitted-weight-rtl-closure.md) 的固定例由 Python 行为训练产生系数，RTL 对 **128 个独立留出样本**与定点参考逐码比较。留出数据独立于训练，物理失配池相同；这不是结构 DUT 自行产生训练观测的闭环。

**急需解决。** 在桥接和参考事件合同明确后，串起**真实结构 DUT 数字观测 → 片外拟合 → 系数加载/冻结 → 独立 DUT 留出验证**；覆盖 dither 去除、饱和/溢出、错误系数、噪声和动态条件。当前静态有效权重模型不等于 ADC2 本身的电容非线性校准，也不能校掉未建模的建立、参考或开关误差。

### 4. 系统校正、DSP 与数据输出

**意义。** ADC 内部重构之后，对系统信号链进行可选增益/失调修正、滤波、缓存和对外传输。AD4080 手册提供 SINC1、SINC5、补偿滤波、FIFO 和 LVDS/SPI 数据选项，可作为功能接口参考；当前子系统是工程原型，不是器件逐寄存器兼容声明。

**现在有什么。** [`sar20_system_top`](../ad4080_dsp/rtl/sar20_system_top.sv) 已连接 SAR 结构核和 DSP 入口；[`sys_error_corr`](../ad4080_dsp/rtl/sys_error_corr.sv)、滤波、FIFO、SPI 与事件/帧模块已有 RTL 和测试。输入侧有接受/拒收事件及 ID，模拟粘滞异常触发保守停流。

**急需解决。** [`cal_two_point`](../ad4080_dsp/rtl/cal_two_point.sv) 在固定已知输入、可变实测码的常见测量方式下求的是正向关系；本次真实 RTL 反例中，目标码 300000、原码 303100，经直接应用后变为 306234。应按手册的“原码 → 目标码”方向求逆、量化并在独立留出数据验证。SINC5 补偿默认系数仍为占位；FIFO 输出与串行路径尚未接通，滤波/FIFO 输出也没有逐结果元数据。

当前单 lane 数字发送器每帧需 20 次使能，而结构核以 16 时钟/样本供数；本次 12 样本诊断中有 3 个输入未出现在输出，且 `bit_en` 恒高时 DCO 不翻转。手册中的单 lane 400 MHz DDR 或双 lane 200 MHz DDR 是**外部数据接口时钟示例**，与工程内部 640 MHz 相位时钟不是同一个时钟。实现具体产品接口需要明确帧、时钟域、缓冲、CRC/数据格式及 DDR/差分 PHY，不应把现有 SDR 原型称为 40 MS/s 无损 LVDS。

### 5. 集成与验证

**意义。** 给上述四块提供可重复且互相一致的证据：同一个样本、同一组开关、系数和错误标志，能从输入观测走到输出；行为模型、数字 RTL 和真实工艺分别验收。

**现在有什么。** 仓库有 Python 回归、RTL 仿真、定点参考和已知限制诊断；本次针对权重、物理路径、整数重构与参考事件运行 **38 项通过、1 项预期失败**。预期失败记录的是已知参考事件合同差异，不能计为要求通过；三个 RTL 诊断的成功标记表示反例仍可复现，不表示设计已达标。本次还重跑了 `calibration_fit_tb`（128 个留出样本）、`structural_adc_tb`（438 个输出、7680 次检查）和 `sar20_system_top_tb`（77 个匹配样本、3 类模拟异常注入）；这些是功能仿真，不是目标工艺签核。完整诊断入口见[已知限制](rtl/KNOWN_LIMITS_20261104.md)。

**急需解决。** 建立贯穿所有阶段的样本 ID、valid、错误、复位和 FIFO/滤波窗口语义；补齐结构 DUT 闭环、边界/异常和独立参考。然后在目标环境取得约束一致的综合、形式等价、CDC/RDC、STA 和模拟后仿/PEX；没有这些证据时，只能说目标采样率或行为条件下通过，而不能称 40 MS/s、20 位精度或产品兼容已签核。

## 建议推进顺序

1. **先统一合同。** 定义 bridge 物理掩码、RDAC 事件、dither 注入/移除以及 sample ID/错误语义；它们是训练观测和输出对拍的共同前提。
2. **再关闭权重校准链。** 从结构 DUT 导出真实数字观测，用独立参考训练，装载冻结系数，并用独立样本验证；同一条件比较溢出与未裁剪样本。
3. **并行处理交织误差与模拟约束。** 针对失调、增益、时序和带宽分别规定可观测性与验收；时钟匹配、采样/参考建立须由模拟/版图和电路仿真提供证据。
4. **最后按明确的产品接口目标收口 DSP。** 先修正两点系数方向、数据通路和元数据，再按选定模式验证滤波/FIFO/串行吞吐及芯片手册差异；目标工艺与 CDC/STA 证据贯穿此阶段。

本文是工程功能分工和证据评价，不提供专利法律判断，也不把资料中的芯片实测结果当成当前模型或 RTL 的测量值。
