# Uncached P5 synthesis timeout

Vivado 2018.3 on xc7vx690tffg1761-2 was asked to synthesize the frozen uncached P5 RTL with a 25 ns period. The runner terminated its own process tree after 7200 seconds. No complete synthesis status, utilization/timing reports or DCP were produced. This is a runtime failure, not timing-not-met evidence or a valid PPA baseline. Original logs, source archive, status and command bytes are preserved; archive_index.json gives their exact hashes.
