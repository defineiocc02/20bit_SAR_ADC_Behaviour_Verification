## 二、逐项对照

### D1 18 片调度

| | |
|:---|:---|
| **原文要求** | 18 个物理 sDAC 切片，8 个采样、8 个残差转换、2 个备用轮换；两组相邻周期交换角色，使采样占满 25 ns 全周期 |
| **Python** | `round_robin_plan(s)`：`acq(k)={(8k+i) mod 18}`，`conv(k)=acq(k−1)`（因果）。相邻窗互斥、每笔 8 个不同 ID，已验 |
| **RTL** | `slice_pool.sv`：`sid[i]=(8+8s+i) mod 18`，64 组对拍 0 失配 |
| **效果** | 与原文"采样窗互不重叠、整周期轮转"一致 |
| **差距** | 启动/排空阶段的备用片接入未实现，只做了稳态 |

### D2 Follower

| | |
|:---|:---|
| **原文要求** | 量化结果不是一次给完，而是随逐位判决**逐步**加载到 RDAC；已决前缀之外的位不影响当前事件 |
| **Python** | `ResolvedPrefixes.from_final`：7 个事件，第 i 个只用 `(c>>(6−i))<<(6−i)`。粗码 281 得到前缀 `256,256,272,280,280,280,281` |
| **RTL** | `follower.sv`：同一公式，200 组对拍 0 失配 |
| **效果** | 同一前缀下不同最终码的早期 mask 完全一致——这正是原文要求的行为 |
| **差距** | 入口仍按最终码反推前缀；真实芯片应由逐位判决驱动 |

### D3 二维 DEM

| | |
|:---|:---|
| **原文要求** | 二维 DEM：一个固定零输入形成**保留列**，该列交给纵向结果控制；其余列用共享横向数据；片选、横向、纵向三维独立打乱（接法与图号**待核对**，手头原图为 FIG.2，展示的是二进制阵列与开关组） |
| **Python** | 16 逻辑列，保留列为固定 0；其余按 H 做温度计，横向相位旋转、纵向相位选片。恒等式 `4(8H+M)+L=k` 在 8192 组上 0 违反 |
| **RTL** | `cdac_decode.sv` + `dem_shuffle.sv`：512 + 8192 组对拍 0 失配 |
| **效果** | 码权守恒成立；MUX 结构为自行设计的"保留列 + 共享横向"实现，**与专利原图的逐管对应关系未核** |
| **差距 1** | 相位是**工程排程**（`q=sid//9` 推进三维，周期 17280），不是专利原序列。覆盖已修到 16/16，但打乱质量未做频域验证 |
| **差距 2** | 不是专利的两级 shuffler 网络 |

### D4 Dither

| | |
|:---|:---|
| **原文要求** | 人为注入已知扰动，让残差跨越多个非线性区，再在数字域精确相消。手头原图（FIGURE 3）给出的是**单路**结构：PRNG → DAC → 与 AIN 求和 → ADC → SUBTRACT |
| **Python** | 6 位 dither 字 `D6..D1`，拆成 `U=4D6+D3`（粗码偏移）、`L=8D6+16D4+4D2+2D1+D0`（子阵列）、`T`（时间项）。384 组（6 输入 × 64 字）去扰后最大误差 0.30 LSB20 |
| **RTL** | `dither_split.sv`：纯拼接，64 组对拍 0 失配；`recon_d5` 内做补偿 |
| **效果** | 理想等距 DAC 下八路扰动闭合 |
| **差距** | 手头原图是**单路** dither，没有 7 片/8 片的分路细节；8 片分路是我方工程适配。**"原文是 7 片"这一说法待核对**，在核对前不能声称复现原芯片控制序列 |

### D5 权重重构

| | |
|:---|:---|
| **原文要求** | 权重系数**片外提取**、片上执行 DAC 权重修正 |
| **Python** | `x̂=(y−b−K)/G`，`G=Σw·a`（只含 16 个采样列）、`K=Σw·t`（逐单元 t：主阵列 m=1→−3/m=0→+3；子阵列 a=0、m=1→−6/m=0→0） |
| **RTL** | `recon_d5_w2.sv`：`D_eff=6·(Wm·inv_g>>36)−3·2^24`，倒数乘替代除法 |
| **效果（关键证据）** | 相容观测下（由真权重生成观测）：**真系数恢复输入 1.3 µV**；名义系数留 **3284 µV（574 LSB20）**。这才是"校正起作用"，不是"改系数输出变了" |
| **时序** | 综合后 S1 **24.46 ns，slack +0.002 MET**，面积 166,799 µm²，`DW_div` 计数 0 |
| **差距** | 倒数乘使 D_eff 与精确除法差 2 个 Q24 单位（0.02 LSB20），**偏差随 G 增大**（G=5.5e11 时 13 单位）——标定流程必须卡住 G 量级 |

### D6 顶层事务

| | |
|:---|:---|
| **Python** | `accepted == retired + cancelled + pending` 且 `pending==0`，四场景实测守恒；`k∉[0,511]` 拒收 `ERR_K_RANGE` |
| **RTL** | **未实现**。`recon_d5_w2` 只有时钟和复位，没有 valid/ready、没有事务计数、没有 reset 取消语义 |
| **判定** | Python 完成，RTL 部分落地 |

## 三、论文指标 vs 我们能说的

| 论文指标 | 论文值 | 本仓库 | 能否声称 |
|:---|:---|:---|:---|

**核心结论：数字功能复现完成，性能指标一个都不能声称。** 因为性能取决于模拟前端（RA、参考、输入驱动），本仓库只覆盖数字链。

## 四、Python 与 RTL 的分工

| | Python | RTL |
|:---|:---|:---|
| **角色** | 行为参考（golden） | 可综合实现 |
| **覆盖** | D1–D6 全部，含浮点验证 | D1–D5 组合/流水，D6 未做 |
| **精度** | 双精度浮点 + Q24 定点两套 | 纯整数 Q24/Q30 |
| **一致性** | — | **11619 + 400 组向量逐位一致**（VCS） |
| **时序** | 无概念 | 24.46 ns MET（权重路径） |
| **不行的地方** | 不模拟模拟域、不做噪声 | 无事务层、无门级/布线 |

**分工的价值**：Python 定"算什么"，RTL 定"怎么算"，两者用同一批向量锁死。
一旦 Python 改了定点定义（如 r̂ 的二次舍入），RTL 立刻对不上——这轮 400 组里
就抓到过一次（差 2 码 → 根因是 Python 加了两次舍入偏置）。
