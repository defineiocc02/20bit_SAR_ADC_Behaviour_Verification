# D5 校正有效性验收（第 4 项）

基线 `3f1bf99`。工具：`tools/cal_effectiveness.py`，可复现。

## 1. 制造实例

一颗固定失配实例（seed 2026），包含四类非理想：

| 项 | 分布 | 说明 |
|:---|:---|:---|
| 片增益 | N(0, 1%) | **使各片行和不同**，G 随活动片组变化 |
| 主单元 | N(0, 1.5%) | 片内单元失配 |
| 子阵列 | N(0, 2.5%) | 有效权重失配 |
| DEM 相位 | 随机 sample_id | 不同状态选不同物理单元 |

**未采用"循环旋转但行和相等"的做法**——那样 G 恒定，掩盖单倒数问题。

## 2. 相容观测

用**真权重**经生产链自己算出的 `dac_hw_q24` 生成：
`x = (dac_true + TΔ) + 余差`，余差经 ADC2 窗口量化。
A/B 两侧喂**完全相同**的粗码、ADC2、DEM 状态、dither 字，只换系数。

数字 DUT 不读真实制造参数——真值只经观测和预加载系数体现。

## 5. 片组 G 差异 —— 单倒数不成立

9 个活动片组的 G：

```
34444934884 / 34342110780 / 34453238887 / 34357343616 / 34446550135
34403616348 / 34346857185 / 34456336155 / 34337908862
极差 118427293 = 0.344%
```

0.344% × 6 V = 20.6 mV ≈ 3600 LSB20 —— **远超 20 位精度**。

**结论：单个冻结 `inv_G` 只适用于"各片行和相等"的特殊情形。**
一般失配必须按**活动片组索引的预计算倒数**（9 组，每组 26 bit，共 234 bit），
或在校准阶段按组切换。

当前 `digital_top_w` 只有单个 `inv_reg`，**这是已知缺口**，已列入未完成项。
Python 生产链不受影响：它每笔按实际 G 现算 `inv_g_q60`，所以 A/B 结果成立。

## 6. 判定

| 项 | 判定 |
|:---|:---|
| 校正有效性（输入恢复） | **PASS** |
| 片 ID / mask 变化后寻址 | **PASS** |
| 子阵列非零参考贡献 | **PASS**（子阵列权重参与 Wm，a=0 只进分子） |
| dither 在相容观测下消除 | **PASS**（163 组含 64 字随机覆盖） |
| 无隐藏名义回退 | **PASS**（code20 走 `x_q24_w`，`x_formula` 仅参考） |

### ADC2 编码修正（2026-11-14）

原实现 `round(ra/LSB)` 与 D5 的**箱中心解码** `r̂=(code+0.5)·LSB` 不匹配，
存在系统性半箱偏移，且 `ra=0.45` 时 floor 会得到 4096（非法码）。

改为 **floor 分箱**：

```
code = floor(ra / LSB)          ra ∈ [0, 0.45]
ra = 0.45  ->  floor = 4096  ->  归入最后一个箱 4095
ra < 0 或 > 0.45  ->  None（报非法，不静默夹紧）
```

理想量化误差上限 = **半 LSB = 1.717 µV**（输入折算），另计 D5 定点误差。

修正前 3.4 µV 是因编码/解码错位导致的约 2 倍半 LSB，**当时不能称为量化极限**；
修正后 1.7 µV 才是真正的半 LSB 底线，此时才可称之为量化极限。

## 验收结论（分级，不得混淆）

**已完成：独立电荷前向 → ADC2 → D5 重构 闭合 — PASS。**

**未完成：完整 ADC 系统闭环 — PARTIAL。** `closed_loop.py` 尚未覆盖：

| 未覆盖项 | 说明 |
|:---|:---|
