- 交付顺序：统一时序与样本归属 → 统一物理量来源 → 受控扰动验收 →
  重新生成动态实验基线（附新旧差异解释，不要求与 v7.0.5 一致）。

  隔离测试中要求；引入参考恢复与跨样本状态后，真实物理作用不可
  为测试方便而禁止。

  仍在建立——它是分配参考缓冲与 RA 指标的依据）。
