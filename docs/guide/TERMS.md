# 术语与符号

同一符号在不同文档里不得无提示地改变含义。新文档引用这里，不复制定义。

| 术语 | 含义 | 不要和什么混 |
|:---|:---|:---|
| **SADC** | 前级 9 位量化器（3b flash + 6b SAR），只判决 | 不是 RDAC，不驱动大盘 |
| **RDAC / sDAC** | **17/5** 的电容阵列（主阵列 15×2C + B4 + S4；子阵列装配 4 列），跟着已决码走 | 不是量化器 |
| **physical slice** | 18 片物理电容组之一，编号 0..17，失配跟着它 | 不是 slot |
| **active slot** | 本笔 8 片活动组里的位置（0..7） | 换一笔，同一 slot 可能是另一片 |
| **sample / event / transaction** | 一笔采样 / 一次 RDAC 更新 / 一次可退休的完整事务 | 3 个不是同义词 |
| **粗码 `c`** | SADC 的 9 位判决，0..511 | 不是最终 20 位码 |
| **RDAC 码 `k`** | 实际送进阵列的码（v1 拓扑里 `k=c−U`） | 不是粗码，也不是输出码 |
| **ADC2 原码** | 12 位后端原始码 | 不是解码后的电压 |
| **最终输出码** | 20 位 offset-binary，mid-rise | 不是 LSB 数 |
| **输入折算电压** | 除以 C_norm 后折算到输入端的等效量 | 不是真实节点电压 |
| **真实节点电压** | 电容顶板/子节点的物理电压 | 与输入折算差一个 C_norm |
| **C_norm** | 全 Signal 连接时的归一化电容 | 不是 C_noise，也不是物理电容和 |
| **C_noise（Ceq）** | `Cnorm²/Σ(Cm+β²Cs)`，kT/C 用的等效电容 | 不是 C_norm |
| **β** | 桥接衰减 `Cb/(Cb+ΣCs+Cp_sub)` | 不是增益 |
| **Cf** | RA 反馈电容 | 不是 C_norm |
| **名义参数** | 模型假设值（如 σ=0.1%） | 不是制造真值 |
| **制造真值** | 由 seed 生成的 chip 实际电容 | 只给 plant 和 oracle |
| **校准估计** | 从观测拟合出的权值 | 不是真值，也不能反推真值 |
| **普通 AZ** | 逐笔自零，主链内 | 不是 CAAZ |
| **CAAZ** | 斩波 + 两笔共享 AZ + 数字配对，`extensions/caaz/` | 不进主链 |
| **原理演示 / 模块验证 / 主链验证 / 性能验证** | 四种不同强度的证据 | 不能互相替代 |
| **LSB20** | 20 位码的一个码宽 = 6V/2²⁰ = 5.72 µV | 不是 ppm FS |
| **ppm FS** | 相对满幅的百万分之一；6 Vpp 时 1 ppm = 6 µV | 与 LSB20 差 1.05× |
| **平均传输非线性** | 固定电平上的平均误差，去直线后的残差 | 不是逐码 INL |
| **INL / DNL（严格口径）** | 基于转换阈值或码密度 | 本项目 DNL 目前**不是**这个口径 |
| **SNR / SNDR** | 前者扣掉谐波，后者含谐波 | 本仓库两者都报，不要只引一个 |
