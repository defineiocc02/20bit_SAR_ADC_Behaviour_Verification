# 用论文指标反解失配 σ：模型与 [00] 标题的吻合验证（2026-11-13）

> **这是反解值，不是披露值。** 论文没有给电容失配 σ；
> 本文的 σ 是从论文**公布的两个独立指标**同时反解出来的。

---

## 1. 论文标题给出的四项指标

论文 [00] 标题逐字：

> **A 9.3nV/rtHz 20b 40MS/s 94.2dB DR** Signal-Chain Friendly Precision SAR Converter

| 指标 | 论文值 |
|:---|:---:|
| 噪声谱密度 NSD | **9.3 nV/√Hz** |
| 分辨率 | **20 b** |
| 采样率 | **40 MS/s** |
| 动态范围 DR | **94.2 dB** |

## 2. 模型的失配扫描（1024 点动态，失配+噪声）

| `unit_mismatch_std` | DR | NSD |
|:---:|:---:|:---:|
| 0 | 95.34 dB | 8.10 nV/√Hz |
| 5e-5 | 95.04 dB | 8.22 |
| **1e-4** | **94.33 dB** | **8.55** ← 两个指标同时命中 |
| 2e-4 | 92.32 dB | 9.74 |
| 1e-3（原值） | 81.31 dB | 27.72 |

**σ = 1e-4 时，DR 与 NSD 两个独立指标同时落在论文值上**（94.33 vs 94.2；
8.55 vs 9.3）。这不是单调可调参数能凑出来的巧合——两个指标对 σ 的灵敏度不同，
只有一个 σ 能让它们同时接近。

## 3. 所以原值 1e-3 是错的

`unit_mismatch_std = 1e-3` 是早前的工程假设，无原件依据。它让：
* DR 只有 81.31 dB（**比论文低 12.9 dB**）
* NSD 27.72 nV/√Hz（**是论文的 3 倍**）

改为 1e-4 后：

| 指标 | 论文 | 模型（A2 失配+噪声） |
|:---|:---:|:---:|
| DR | 94.2 dB | **94.33 dB** |
| NSD | 9.3 nV/√Hz | **8.55 nV/√Hz** |
| SNDR | — | 94.70 dB |
| INL | 图 9.8.4「20b level」 | **3.2 LSB20** |

## 4. 失配 σ 的单一真源

`experiments/configs/matrix.py` 原来把 `1e-3` 写死在各 cell 里（三处）。
现在改为引用 `DefaultParameters().unit_mismatch_std`，**只有一个定义点**。

这样可以避免同一参数在两处漂移——本会话已多次踩到这类问题
（ADC2 位数、ra_v_clip、S4 权重）。

## 5. 证据层级

**必须说清这是哪一类数字：**

| 项 | 层级 |
|:---|:---|
| 论文的 94.2 dB / 9.3 nV/√Hz | 硅测值 |
| 本模型用 σ=1e-4 得到的 94.33 dB / 8.55 nV/√Hz | **行为级浮点仿真（L1）** |
| σ = 1e-4 本身 | **由两个论文指标反解**，不是论文披露 |

**吻合 ≠ 复现。** 这说明「在 σ=1e-4 这个假设下，模型的行为级噪声预算与论文指标一致」，
不说明模型的每一步都与芯片内部相同（例如 ADC2 窗口、S4 编码仍未披露）。

这是**校准一致性**，不是 silicon signoff，也不能替代后仿。

---

## 6. 为什么 A5 校准在 σ=1e-4 下让 INL **变差**（3.1 → 6.0 LSB20）

矩阵里 A5（失配+校准）的 INL 比 A1（仅失配）更大。这是**真实结果**，不是笔误。
本轮查清了原因。

### 6.1 逐码 LUT 的分辨率下限

校准表每码存**一个**修正值，而同一码内的量化误差分布在 `[0, 1] LSB1`：

```
码内残差 std = 1 LSB1 / √12 / G
             = (6/512 / 3.464) / 32
             = 18.5 LSB20
```

实测训练残差：**19.4 LSB20**（111 µV）—— 与 18.5 吻合。

### 6.2 与被拟合的真实误差相比

σ=1e-4 下，失配引起的 INL 只有 **3.1 LSB20**（17 µV）。
而 LUT 自身的分辨率下限就有 **18.5 LSB20**。

⇒ **LUT 的分辨率比它要修正的误差还差 6 倍。**
加进去只会引入新的、与码相关的扰动（每码一个随机跳变），把 INL 从 3.1 推到 6.0。

### 6.3 排除了两种错误猜测

| 猜测 | 检验 | 结果 |
|:---|:---|:---|
| LUT 在拟合噪声 | 关闭全部噪声后重训 | 残差 **112 µV，几乎不变** ⇒ 不是噪声 |
| 训练点数不足 | 8200 → 32000 点 | 残差 111→98 µV，**收敛极限** ⇒ 不是采样不足 |

### 6.4 结论

**逐码 LUT 只在"失配误差 >> 码内量化残余"时才有意义。**
σ=1e-4 恰好落在它失效的区间：失配太小（3 LSB20），而 LUT 分辨率太粗（18.5 LSB20）。

这解释了为什么论文里没有用到逐码校准 —— 它的 ADC 靠 DEM 与足够的失配裕量，
不靠逐码 LUT。

**这条结论对使用者重要**：矩阵里 A5/C1 的 INL 变大不是"校准写坏了"，
而是"在这个失配水平上不该用逐码校准"。
