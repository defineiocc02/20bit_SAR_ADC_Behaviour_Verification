# Binary-to-unary bridge：它解决什么，模型做到哪里

## 为什么需要这个 bridge

[ISSCC 2024 9.8](https://doi.org/10.1109/ISSCC49657.2024.10454329) 讲稿第 31 页把一组标为 8 的 DEM 元素和标为 4、2、1 的二进制/dither 元素放在一起，并在两组之间标注 `P=50%`。它要处理的是：**大权重温度计码单元与低权重二进制单元的等效权重、选择和误差如何衔接**。如果这些物理单元的有效电容比例有偏差，码跨越分段边界时，同样的名义码步会产生不同的实际电荷步，形成 DNL/INL 或输入相关杂散。

binary-to-unary bridge 不只是把一个二进制数翻译为温度计码。能作为桥接替代的物理开关组合，需要在约定参考与初始状态下满足名义电荷守恒；然后再利用不同单元/切片的选择改变失配误差的使用方式。[US10511316B2](https://patents.google.com/patent/US10511316B2/en) 的图 16–21 给出分段、横向/纵向 shuffle 和跨权重单元的实施例。讲稿并未公开该处完整真值表、选择时序或晶体管连接，因此不能把某个候选实现声称为原芯片的逐位复现。

### 用 7 → 8 的码边界理解误差

把理想的二进制低位看作 `4+2+1=7`，下一码用一个名义权重为 8 的温度计码单元。理想电荷步是 `8−7=1` 个单位。如果仅为演示设 8、4、2、1 四个等效权重分别为 `8.16、3.96、2.01、0.99`，则 7 码为 `6.96`、8 码为 `8.16`，跨界步变成 `1.20`，比理想值多 `0.20` 个单位；在其他码位的差异则取决于对应单元误差。这个数字是人为设置的示例，不是芯片数据，也不是本库 63+8 物理阵列的测量。

## 仓库中的具体候选：名义零和交换

本工程选择 63 个主单元和 8 个子单元；名义上每个主单元为 8 个子单位当量，所以粗码可写成 `k = 8 × main_count + sub_count`。这是项目参数选择，不是论文公开的电容清单。启用 DEM 与 bridge 后，本工程以冻结的 `sid[8]` 决定是否进行逐 slice 的零和交换；遍历 512 个 sid 时，其中 256 个状态开启。这个 50% 状态占比是**工程假设**，不能与讲稿箭头直接等同。

以目标 RDAC 码 `k=176`、dither 关闭为例，`176 = 22×8 + 0`：

| 状态 | 8 个活动 slice 的名义码 | 合计 |
|---|---|---:|
| `sid=0`：本候选不交换 | 8 个均为 176 | 1408 |
| `sid=256`：本候选交换 | 前 4 个为 177，后 4 个为 175 | 1408 |

177 对应 `22×8+1`，175 对应 `21×8+7`；后者越过了主/子码边界。这种跨 slice 的零和交换只是一个桥接相关的工程代理，并未建立讲稿中具体二进制 4/2/1 电容与 unary 单元之间的完整互换电路。两组只保证**名义总码**相同；如果各物理电容有失配，四个 `+1` 与四个 `−1` 的实际电荷不一定相互抵消。它会改变误差的使用方式和频谱，不是已测得权重、更不是自动校准。端点码 0 和 511 不执行 ±1 交换，避免越界；sid 还控制实际单元的地址旋转，不能只比较总码而忽略物理掩码。

修订后的 Python 与两条 RTL 路径对该候选使用相同激活规则；独立参考对结构 DUT 的 **512 个 sid × 512 个码**逐物理掩码比较，零差异。这个结果证明的是**本工程合同一致**，不证明候选等于讲稿电路，也不证明 analog mismatch 已被消除。

## 另一个名字相似的东西：物理桥接电容

分裂 CDAC 的 `C_bridge` 是主、子阵列之间的电容器件。对于本模型的浮动子节点，子单元的有效权重含近似比例

```text
beta = C_bridge / (C_bridge + sum(C_sub) + C_parasitic)
```

因此桥接电容和子节点寄生失配会改变子阵列的有效权重。Python 的物理池与电荷模型计算这一效应；外部拟合得到的是有效 `C/Cf` 权重，可以吸收其**静态等效影响**，但不能仅凭输出把 `C_bridge`、子电容、寄生和反馈电容各自唯一分离。这一物理电容与上面的二进制/温度计码选择机制是两件不同的事。

## dither 和校准如何配合

结构对照模式下，采样 dither 的子单元扰动 `d` 作为已知码加到 RDAC 命令；量化器 dither 模式则在量化器决策中引入扰动，并从 RDAC 命令中减去同一单位量。两种模式互斥，真实掩码、轨、dither 码、slice ID 与 ADC2 原码在同一结构样本上冻结。若命令越界，会标记异常，训练不能把该样本静默当作正常记录。

真实结构数字 DUT 的观测已用于片外拟合并重新加载冻结权重；两组**静态行为失配夹具**的 512 个独立留出样本，误差标准差分别从约 55.75/59.38 µV 降至 2.08/2.15 µV。该结果验证的是已声明夹具及定点重构路径；当前 RTL 尚未实现论文描述的双端口 dither 范围增强，也没有目标工艺、模拟后仿或硅片结果。
