## 1. DEM 与跨段编码（US10511316B2 FIG.19 / FIG.20）

### 1.1 这个模块解决什么问题，做到哪一步

元件失配让每个物理单元的权重偏离名义值。若每次转换都用同一组单元，
失配表现为固定的传递非线性（INL/DNL 台阶）。DEM 通过逐笔改变"哪些单元参与"
把固定误差变成随样本变化的误差，再用平均压下去。

**当前状态**：15×2C+2×1C 的掩码映射已实现并在 `fig11_masks` 里可调用；
**保留位置与跨片分配未实现**；主链已统一到 `fig11_masks`（17/5），旧的 63+8
掩码路径已删除。子阵列的哑元端接**尚未进网络**，因此 β 仍按 1/16 计算，
应为 1/17——这是当前最明确的已知物理偏差，见 §1.7。

### 1.2 原图逐块（FIG.19，Sheet 17/29）

```
[15 × 2C]   B4=C   S4=C  ──桥 C──  8C   4C   2C   C
  B0-B3                            B5   B6   B7  B8
        ↘ UNARY ENCODER 306 → shuffler 350 ┐
                     shuffler 352（15×2C）→ 元件 362 → DS1…DS8
```

| 原图编号 | 原文中的含义 | 输入 | 输出／连接 | 工作阶段 | 本工程对应 |
|:---|:---|:---|:---|:---|:---|
| B0–B3 | 15 个 2C 一元电容 | 一元码 `thermal` | 底板接高/低参考 | 转换 | `MAIN_WEIGHTS[:15]` |
| B4 | 1C，独立控制位 | 码位 | 底板 | 转换 | `MAIN_WEIGHTS[15]` |
| S4 | 第二个 1C | 码位 | 底板 | 转换 | `MAIN_WEIGHTS[16]` |
| 桥 C | 跨段衰减 | 主节点 | 子节点 | 全程 | `BRIDGE_CAP_UNITS` |
| B5–B8 | 8C/4C/2C/1C 二进制 | 低 4 位 | 子节点底板 | 转换 | `SUB_WEIGHTS` |
| 306 | 一元编码器 | 二进制码 | 一元码 | 转换前 | `map_fig11` 内 |
| 350 / 352 | 两级 shuffler | 一元码 | 打乱后的列 | 转换前 | **未实现**（现为逐片旋转） |
| 362 | **信号门** | 两 shuffler 输出 | 送到 DS 列 | 转换前 | **未实现** |

所以不能按图形外观要求"任意互连"。这是本轮对上一版说法的修正。

### 1.3 保留位置（FIG.20，Sheet 18/29）

FIG.20 里 `352` 有一个**独立的 `0` 输入**（预留位置），其输出经
**MX1–MX4** 与 `350` 的跨片数据配合；MUX 旁的 `0/1` 是**选择控制位，不是数据**。

【已撤回】上一版写的"MX1 的一个输入是 `−1`，把某列接到负轨"**不成立**，
原文没有"永久接负轨的列"这种说法。

【本工程实现】没有实现该机制。`fig11_masks` 里 `horizontal_phase=15` 映射到 0
只是**相位别名**，不等于保留位置。【工程假设／未确认】保留位置最终承载什么，
正文对应段落本轮未定位到。

### 1.4 核心关系与成立条件

【依据原文推导】名义驱动权重按图上结构：

```
main  = 15×2C + 1C(B4) + 1C(S4) = 32C
sub   = 8C + 4C + 2C + 1C       = 15C
bridge= 1C
beta  = C/(C+15C) = 1/16
LSB   = 1/16 C,  512 × 1/16 C = 32C = main   (整除)
unit_cap = 20.5 pF / [8×(32 + 15/16)] = 77.80 fF
```

校验：`group_cnorm = 8×(32+15/16) = 263.5000 C`，
`group_drive(511) = 8×32 + (1/16)×8×15 = 263.5000 C`，**比值 1.000000**。
端点落在 ±v_fs，说明这套读数是自洽的。

**修正记录**：`topology/capacitors.py` 原有 `SUB_WEIGHTS=[8,4,2,1,1]`，
末位那个 1C 是**把桥接电容误当成了子阵列单元**，导致 β 被算成 1/17、端点差 0.33%。
本轮已核对原图确认应为四项。**代码尚未改**（见 §1.7）。

## 2. 分路 dither 与数字去扰（US10505561B2 FIG.19）

### 2.1 解决什么问题，做到哪一步

小信号时前级量化器的码分布集中，权重误差与量化台阶混在一起无法平均掉。
dither 在采样/判决路径上注入已知扰动，把码"打散"，再在数字域扣掉已知量。

**当前状态**：两组实现并存——`v1`（code-shift，`Fig19DitherProgram`）与
`v2`（独立电荷口，`DitherPort`）。v1 已进主链并有因果测试；v2 已进主链但
**分路因果未验证**。

### 2.2 原图逐端口（FIG.19，Sheet 20/21）

| 原图元件 | 接的是什么 | 本工程对应 | 一致？ |
|:---|:---|:---|:---|
| 400 DITHER GENERATOR | 输出 `D_A…D_1`（A 为可取位数） | 6 位字 | **部分**：正文讨论 A=6 |
| 300 加法器 → ADC 200 | **D5,D3,D2,D1** | `lower_v`（L 支路） | **分组一致** |
| 224 减法器 → DAC 220 控制 | **D6,D4** | `upper_code`（U 支路） | **分组一致** |
| 222 加法器 → DAC 220 输入 | 全字 | `x_rdac_input` | **分组一致** |

**极性必须逐端口读**：300 与 222 是加法、224 是减法，三者不在同一坐标。
【本工程实现】统一用 `subtract`，代码里标为 `ASSUMED_SUBTRACTIVE`——
**这是假设，不是原文披露**。不能因为看到 300 是"+"就批量把模型改成加法。

### 2.3 时序与阶段

| 阶段 | 动作 | 保存/释放 | 何时有效 |
|:---|:---|:---|:---|
| 采样 | 222 把全字加到采样 DAC 输入 | 采样电荷含 T | 采样结束 |
| 量化 | 300 把 L 加到量化器输入 | 无状态 | 判决瞬间 |
| 码生成 | 224 从 SAR 码减去 U | 码 `k=c−U` | 逐事件 |
| 数字 | 重构扣掉已知 T/L | 无状态 | 退休 |

### 2.4 核心关系

【依据原文推导】以粗码 LSB 为单位：`U = 4·D6 + D4`，`L = 2·D5 + (4·D3+2·D2+D1)/7`，
`T = U + L`；`x_SADC = x − L·Δ`、`k = c − U`、`r = x − T·Δ − B(c−U) = x − L·Δ − B(c)`。

【工程假设／未确认】分母 **7** 与"七切片示例"来自说明书正文，**正文为扫描件不可读，
本轮未核对**。八片活动组不能直接套 `/7`，也不能机械改 `/8`——这条没有解决。

### 2.5 代码定位

| 原文动作 | Python | 字段 | RTL | 主链 |
|:---|:---|:---|:---|:---|
| 字→U/L/T | `Fig19DitherProgram.upper_code/lower_v/total_v` | `words[6]` | 无 | 是 |
| 采样侧注入 | `sampler.capture(..., injected)` | `injected[V]` | 无 | 是（v1） |

# 附：算法原理（原图 → 机制 → 公式 → 实例 → 代码）

标签：**【论文明确披露】/【PPT明确披露】/【专利明确披露】/【依据原文推导】/【当前工程假设】/【当前代码实现】/【尚未核实】**。

## A. SADC/RDAC 分离与 Follower

**原始问题**：若前级量化器与残差 DAC 共用一条控制，会出现"试探—撤销"式切换，
参考要为一个最终不用的中间状态供电荷，且判决等待时间被拉长。

**原文依据**：论文 Fig.9.8.1【论文明确披露】——Quantizer 与 RDAC 是管芯上分开的两块。

**机制**：SADC 只产生判决；RDAC 按**已决前缀**逐事件加载，最终码在最后一拍才完整。

**数学**：设已决前缀为 `p_i`，则事件 `i` 的 RDAC 状态只依赖 `{p_0..p_i}`。
因果不变式：`mask_i |_{p_{i+1..n} 任意} == mask_i`（前缀截断不变性）。

**计算实例**（3b flash + 6b SAR）：粗码 `c = 0b101_100101` 时，
flash 一拍已给出高三位 `101`，RDAC 在这一拍只能按 `101` 加载，
不能等 6 次 SAR 全部完成后一次性写 `101100101`。

**代码**：`control/follower.py`（**主链 import 计数 = 0，需核实是否经 dem3d 间接调用**）。

**效果/代价**：减少无效切换与参考负担；代价是逐事件控制与流水延迟。

**尚未确认**：参考的**逐事件峰值负载**未验证（只验过净电荷）。

## B. 模拟交织（18 片）

**原始问题**：单个转换器在 40 MS/s 下无法留出足够建立时间。

**原文依据**：论文 Fig.9.8.1、PPT p9–12【论文/PPT明确披露】。

**机制**：18 个物理 residue sDAC，每周期 **8 ACQ + 8 CONV/RA + 2 SPARE**，
两 bank 互换；同一物理片不得同时出现在两个组。

**数学**：`N_accepted = N_retired + N_cancelled + N_pending`（计数守恒）。

**实例**：第 n 笔的采集组 = 第 n−2 笔的转换组（因果）。
当前 `dem3d.round_robin_plan` 实现该约束。

**尚未确认**：共享 RA 的**跨笔状态**未建模；采样孔径未验证。

## C. DEM

**原始问题**：元件失配使每个单元的实际权重偏离名义值；固定使用同一组单元时，
失配表现为**固定的**传递非线性。

**原文依据**【专利明确披露】US10511316B2：
Fig.11（阵列）、Fig.14（S4 跨片编码）、Fig.19–21（两级 shuffler + 保留列）。

### C.1 结构

```
15 × 2C (B0..B3) + B4(1C) + S4(1C)  ──串联桥 C──  8C, 4C, 2C, C, C
                                                  └ B5 B6 B7 B8 + 哑元
```

主阵列标称 32C；子阵列几何标称和 16C（含哑元）。

### C.2 步骤

1. 二进制码 → 一元码：`N_H = 8B0 + 4B1 + 2B2 + B3`，要求 `Σ u_j = N_H`
2. 横向 shuffler：只改物理索引，保持 `Σu = N_H`、无重复、无丢失
3. 保留列：**恰好一列**，由 controller353 定位置，该列 MUX 选 shuffler350
4. 纵向：在 8 片之间分配权重

### C.3 两个实施例分开写（不得混合）

**Fig.14（跨片 S4 编码，静态）**

| 项 | 内容 |
|:---|:---|
| 输入 | B5, B6, B7 |
| 控制律 | `DS1=0, DS2=B7, DS3=DS4=B6, DS5..DS8=B5` |
| 物理 mask | 8 片各自的 S4 位 |
| 不变式 | `Σ_s S4[s] = 4·B5 + 2·B6 + B7` |
| 实例 | B5=1,B6=0,B7=0 → ΣS4 = 4（DS5..DS8 四片导通） |
| 验收 | 8 种输入组合全部满足上式 |

**Fig.19–21（两级 shuffler + 保留列，随机化）**

| 项 | 内容 |
|:---|:---|
| 输入 | B4, B5, B6 + 固定零 |
| 控制律 | shuffler350 给纵向向量；352 做列置换；controller353 定保留列位置 |
| 物理 mask | 该列来自 350，其余列来自 352 |
| 不变式 | `2·Σy = 8B4+4B5+2B6` ⇒ `Σy = 4B4+2B5+B6 ≤ 7`；保留列恰好一列 |
| 实例 | B4=1,B5=1,B6=0 → Σy=6 → **12C**；保留列 1 列 |
| 验收 | 全部组合满足纵向不变式；保留列数恒为 1；无双重驱动 |

**不得用同一组计算声称两个实施例都已实现**：它们各自需要独立的样本、反例与开/关对照。

### C.5 效果与代价

把固定失配变为随样本变化的误差，可用平均压低。**代价**：开关活动、参考负担、

## D. 分路 Dither

**原始问题**：小信号下码分布集中，权重误差与量化台阶混在一起无法平均。

**原文依据**【专利明确披露】US10505561B2 Fig.19。

### D.1 分组与注入点

| 位 | 去哪里 | 符号 |
|:---|:---|:---|
| D5, D3, D2, D1 | 300 → 量化器输入 | 加 |
| D6, D4 | 224 → SAR 码 | 减 |
| 全部 D6..D1 | 222 → 采样 DAC 输入 | 加 |

**三处不在同一坐标**，不能只改一个加减号。

### D.2 数学（本工程约定）

`U = 4·D6 + D4`，`L = 2·D5 + (4·D3 + 2·D2 + D1)/7`，`T = U + L`

`x_SADC = x − L·Δ1`；`k = c − U`；`r = x − T·Δ1 − V_D(k)`

### D.3 计算实例（word = 33 = 1,0,0,0,0,1）

```
U = 4·D6 + D4 = 4·1 + 0 = 4
L = 2·D5 + (4·D3+2·D2+D1)/7 = 0 + (0+0+1)/7 = 1/7
T = 4 + 1/7
**参数**：`step_q = 0x7FFFFFFF >> 2`（Q32 粗 LSB）、`v_fs = 3.0 V`、
`Δ1 = 2·v_fs/512 = 11.71875 mV`，模式 = v1 code-shift（`k = c − U`）。
取 x = 0.3 V：
  x_SADC = 0.3 − (1/7)·0.01171875 = 0.298326 V
  k = c − 4
```

这个字的**两条支路都非零**，所以能真正检验分路（旧示例 21 的 upper=0，退化）。

### D.4 代码与未决

`control/dither.Fig19DitherProgram`（v1）与 `dither_port.DitherPort`（v2）。
**实测**：v1 上 upper 不动 SADC 判决、lower 动（`test_dither_split_causality.py`）。

**【尚未核实】** `/7` 来自七片示例，与论文八片工作组等效性**未证明**；
上段幅度与 ADC2 窗口的"冲突"**尚未成立**——需先换算到同一节点同一单位。
