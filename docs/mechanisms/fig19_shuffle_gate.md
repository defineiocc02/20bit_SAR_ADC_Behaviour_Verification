## 2. 三条语义 → 三条判据

### ① 两级分配（B0-B3 与 B5-B7 走不同路径）

主段的 30C 由 352 承担（定值），子阵列的 8/4/2 由 306→350 承担，
两条路径**汇聚在 362**。所以一次转换里"同一片的电容"来自两个不同的 shuffler。

```python
verify_two_stage_allocation()
# {'shuffler_352_total_c': 30, 'shuffler_350_total_c': 14,
#  'combined_c': 44, 'main_segment_c': 30, 'sub_switchable_c': 15, ...}
```

### ② B8 不经过 unary encoder

306 图上**只有 8x/4x/2x 三路**，没有 1x。因此最地位的 B8 直通、不加扰。

```python
unary_encoder_excludes_lsb()   # True
```

**用途**：若某实现把 B8 也做 DEM 旋转，就与 FIG.19 不符 —— 这条判据可以拦下来。

### ③ 362 是"选通"而不是"加权"

图上 362 画成开关阵列（对角交叉符号），输入来自 352/350、输出到各片。
开关的语义是"把同一批单元送到不同片"，因此**门前后总权重必须不变**：

```python
gate_preserves_weight_sum(weights_before=before, weights_after=after)  # True
gate_is_permutation(mapping=np.arange(16), n_slots=16)                 # True
gate_is_permutation(mapping=np.array([0,0,1,2]), n_slots=4)            # False（重复取源）
```

## 3. 与 `reserved_column` 的互证

352 与 350 **各有一个标 `0` 的方框** ⇒ 两条路径各自留 1 个空位。
这与 `control/reserved_column.py`（FIG.20 的"16 选 15"）是同一机制的两种画法，
两张图互相印证。

## 4. 顺带确认的一件重要事：DS1 的虚线框内是 `C C`

FIG.19 的 DS1 内部，紧挨 `2C…2C` 之后有一个**虚线框，里面画了两个 `C`**，
再往右是一个实线桥接 `C`。这与 FIG.11 子阵列"第 5 个 C 在虚线框内"完全一致，
**两图共同支持"虚线 = 可选/未装配"**的读法 —— 也正是本轮之前把子阵列改成
4 列（ΣB=15C、β=1/16）的依据。
