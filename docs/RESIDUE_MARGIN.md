# ADC2 余差裕量审计（P0）

工具 `tools/residue_margin.py`。扫描 **9 个物理片组 × 5 组 DEM 相位 × 512 粗码**，
共 45 个组合、22,995 个相邻码对。只测量，不改 D5 / DEM 任何公式。

## 1. `D_real(k) − D_ideal(k)` 偏移分布

| 指标 | 值 |
|:---|---:|
| 最小 | **−10.659 mV** |
| 最大 | **+8.360 mV** |
| 均值 | −0.088 mV |
| 标准差 | 3.157 mV |
| 负偏移占比 | 49.1% |
| 正偏移占比 | 50.7% |

**偏移近似对称，正负各占一半。**

## 2. 相邻台阶 `D(k+1) − D(k)`

| 指标 | 值 |
|:---|---:|
| 理想台阶 | 11.719 mV |
| 实测最小 | **+4.478 mV** |
| 实测最大 | **+15.926 mV** |
| 均值 | 11.719 mV |
| **`≤0` 的台阶数** | **0 / 22,995（0.000%）** |

**在本轮扫描的 45 个组合内，DAC 全局单调。**
台阶最小 4.478 mV 仍为正，只是比理想小 62%。

> 更正：此前把 D 组失效归因为"非单调"是错的。
> 但**也不能据此宣称所有片组/所有相位下全局单调** —— 只覆盖了 45 个组合。

## 3. 余差需求（关键结论）

ADC2 当前是**单边**窗口 `0 ~ 14.0625 mV`（0.45 V / 32）。

| 需求 | 值 |
|:---|---:|
| 负向余量 | **≥ 10.659 mV** |
| 正向余量 | **≥ 8.360 mV** |
| 合计动态范围 | **19.019 mV** |
| 当前单边窗口 | 14.0625 mV |
| **缺口** | **+4.956 mV** |

**单边窗口在结构上不够。** 输入落在理想码边界附近时，
约一半的码会使 `D_real(k) > x`，余差为负，直接掉出窗口下界。

## 4. 结构性判断

这不是调 SAR 搜索或改 DEM 能解决的，属于**量化器与 RDAC 的码边界不匹配**：

```
理想 SADC 给出 D_ideal(k) ≤ x < D_ideal(k+1)
真实 RDAC 的 D_real(k) 可高出 D_ideal(k) 达 10.66 mV
=> 余差可能为负 10.66 mV，超出单边窗口下界 0
```

**可行的架构方向（待定，未实施）：**

| 选项 | 说明 | 代价 |
|:---|:---|:---|
| A. 双极窗口 | ADC2 改 ±11 mV（总 22 mV） | 需 1 位符号位或平移共模 |
| B. 余差平移 | 在 RA 前加固定 −10.7 mV 偏置 | 占用正向裕量，需重新分配 |
| C. 前级冗余 | 粗码增加 1 位冗余，吸收边界误差 | 改码本与 Follower 事件数 |
| D. 缩小失配 | 靠版图/校准把 std 从 3.16 压到 <1 mV | 受工艺限制 |

**当前未做任何修改**——按指示先给需求，再定方案。

## 5. 与论文的差异（必须说明）

论文未公开 ADC2 采用"单边 0~0.45 V"这一具体窗口；**该窗口是本工程的模型参数。**

因此本结论的准确表述是：

> **在本工程采用的单边窗口假设下，真实失配使约一半的码产生负余差，
> 窗口动态范围缺口 4.96 mV。**
>
> 不等于"ADI 原芯片有同样问题"——原芯片的余差动态范围与冗余设计未公开。

## 6. 对 D3 的影响

D3 的 PARTIAL 现在有了更根本的原因：

- 不只是"DEM 收益未证明"
- 而是**前级余差窗口本身就与真实失配不匹配**，DEM 在这种条件下无法评估其线性化作用

**先修窗口，再评 DEM。**
