> → 看是否有测试失败。**没失败不等于实现正确**，只说明"这一处没被覆盖"。

## 2. 两类"没抓到"必须区分

### 2.1 真实缺口

参数被代码使用、但从没被断言。σ 的案例：
* 真实生效（改 σ 会改变制造电容）
* 但既有测试要么**显式传入** σ、要么用 `unit_mismatch_std=0` 关闭它（为确定性）
  ⇒ "默认值本身"从未被检查

处理：补一个直接断言默认值的测试。

### 2.2 等价变异

参数存在、但当前参数组合下**永远不会触发**。`ra_clip` 的案例：
* ±3 V / 0 V / ±2.99 V 各 8 笔，两种 clip 设置下 `ra_sat` 都是 0
* `vra` 最大仅 0.340862 V，远未达 0.45 阈值

处理：**不补"假测试"**，而是写一个测试把这个"现在不触发"的事实固定住。
若将来噪声/失配变大让它开始触发，测试会失败并提醒重新审视。

---

## 3. 教训

**"变异没被抓到"不等于"测试有缺口"。**

把等价变异当成缺口去补测试，只能写出一个永远通过、什么也没验证的测试——
那比没有测试更糟，因为它会让人以为这块被覆盖了。

唯一的区分方法：**查证变异是否真的改变了行为**（打印输出、对比数值）。
