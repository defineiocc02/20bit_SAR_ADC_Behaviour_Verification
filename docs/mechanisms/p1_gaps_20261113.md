## 1. 保留列（US10511316B2 FIG.20）→ `control/reserved_column.py`

### 图面计数（300 dpi 原件逐档读出）

| 元件 | 输入 | 输出 |
|:---|:---|:---|
| shuffler **350** | `D6:2x`、`D5:2x`、`D4:4x`、`D3:8x`、**保留:0** | `16x` |
| shuffler **352** | `D2:16x`、`D1:32x`、来自 350 的 `16x` | `8x2` 与 `8x30` |

### 计数自洽（可复算）

* 350 输入权重和 `2+2+4+8+0 = 16` **恰等于**输出 16 ⇒ 标 `0` 的方框**不承载权重**；
* 352 输出 `8×2 + 8×30 = 256 = 8 片 × 32C` ⇒ 正好**一个完整主阵列**。

**结论**：保留列是"16 个槽位里常驻一个哑位"的填充项（16 选 15），不是数据位。
`verify_figure20_counts()` 就是这条自洽性检查——若把 `0` 误读成数据位，输入和会与输出不等，立刻失败。

### 明确未定的

图上只有一个 `0` 方框、**没有编号**，因此"保留位随相位轮转"是本实现的
**工程假设 `ASSUMED_ROTATING`**，不是披露。`reserved_slot_mask()` 的 docstring 已标注。

## 2. AUX 输入（US10541702B1 FIG.1/FIG.2）→ `control/aux_input.py`

### 图面结构

```
V_IN ──[2]──┬──[4]──[6 自举开关]── 采样节点 16 ──[8]──[10]── (后端)
            │
V_IN_AUX ──[2]──[开关 22]── 同一节点
AUX 支路另有：[14 辅助电容] + [18/20 开关]  ——自举/预充
```

**关键结构事实**：AUX 不是第二条独立采样通路，而是**与主输入在采样节点并联的第二个源**；
两者各有一路开关（22），AUX 支路另有自己的辅助电容与复位开关。

### 三条核算不变式（由 `tests/unit/test_aux_input.py` 钉住）

1. 开关 22 断开 ⇒ AUX 源电荷与支路电荷**严格为 0**（不是"很小"）；
2. AUX 与主输入同电位 ⇒ 辅助电容两端无压差 ⇒ **支路搬运电荷为 0**；
3. 复位阶段放掉的电荷**不进信号**，节点净电荷要减去它。
