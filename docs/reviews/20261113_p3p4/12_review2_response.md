## 1. DEM 子阵列 3:2 偏置（属实，已修）

审查用 `v=(11i)%16` 再 `%7` 复算出 `[756,756,504,504,504,504,504]`。我复核成立：  
$16=2\times7+2$，前两个余数在每个 16 相位周期里多出现一次，比值正好 3:2。

**复现**：按审查口径（码 1、**单个物理片**、联合周期 9072）我得到  
`[756, 756, 504, 504, 504, 504, 504, 0]`——与审查给的数字**逐位相同**。

**改法**：`Dem3State.sequence` 的纵向周期改成**被旋转的子单元数本身**（默认池 7，Fig.11 显式传 16）。  
修复后同一口径下 7 个单元各 **36** 次（567 笔周期内单片被激活 252 次，252/7=36），严格相等。

**同时暴露了我审计方法的一个洞**：若按"所有片求和"统计，旧代码给出  
`[648, 661, 661, 662, 646, 629, 629]`——3:2 被平均成了 ±2.5%，看起来"还行"。  
这正是审查说的"聚合计数不能证明逐片覆盖"。所以 `usage_uniformity` 现在必须逐片报。

同时按审查第 1 条补上**逐物理片**统计：`usage_uniformity` 现在额外报  
`per_slice_units_covered` 与 `per_slice_coverage_min`——审查构造的"每片只用 21/63 但聚合均匀"  
的假通过现在会被 `per_slice_coverage_min=21` 直接暴露。

回归：`tests/unit/test_dem3d.py::test_sub_array_phases_are_uniform`。

## 2. "不可辨识"是我错了（撤回）

审查的独立实验给出 rank 1279/1279、cond 2458、无噪声残差 8.7e-15、  
加 1 mV RA 噪声 + 12 位 ADC2 后残差 0.947 mV 且权重全正、留出 10.4 µV。

我在本仓库数据上用同一形式（$F=x-V_{bottom}$，$w=C/C_f$）复核：

| 量    |    审查独立模型    |            本仓库全节点模型            |
| :--- | :----------: | :----------------------------: |
| 秩    |   1279/1279  | **1262/1262**（18 个恒不切换单元并入一列后） |
| 条件数  |     2458     |            **2956**            |
| 残差   | 8.7e-15（无噪声） |       **991 µV**（有噪声、有量化）      |
| 权重符号 |      全正      |        **18 个恒不切换单元为负**        |

**结论**：审查对"这不是原理性不可辨识"的判断成立，我上一版把它写成"不可辨识"是错的，  
**已撤回**（`07_calibration.md` 与 PR 评论都会改）。但两条实验的残差差 3 个数量级，  
说明差异不在条件数，在**模型形式**。

## 3. 新发现：线性化 β 与全节点电荷之差

审查的 plant 用线性化权重 $W=[C_{main}/C_f,\ \beta C_{sub}/C_f]$；  
本仓库的 `charge_from_masks` 用的是**两节点全电荷**（主节点 + 子节点 + 桥）。  
用真实电容（含 β）代入全节点数据，残差仍有 **1235 µV（max 3160 µV）**，而信号只有 ~12 mV。

| 拟合形式                     |         残差         |
| :----------------------- | :----------------: |
| 全 1278 列 + 失调（含恒不切换列的合并） |       991 µV       |
| 去掉恒不切换列                  | 92 mV（更差：它们承载真实电荷） |
| 只用主阵列 1134 列             |    92 mV（子阵列不可省）   |
| 真权重 + 线性化 β（不拟合）         |     **1235 µV**    |

所以**不是拟合坏了，是线性化本身不精确**：子节点电压随码变化，$\beta$ 只在子节点  
"交流接地"的假设下成立。要在这颗 plant 上做逐单元校准，设计矩阵必须写成两节点方程  
（或用记录里的 $V_{top}$/$V_{subnode}$），而不是 $A+\beta B$。

**这一步没做完**，是下一轮的第一件事。

## 4. 统计口径：32 次仍不够，我接受

审查算的：$\sigma=17.8$ LSB20、$R=32$ 时单点 SE 3.15、95% 半宽 6.17；  
256 点 Bonferroni 同时覆盖半宽 **11.7 LSB20**；要 0.5 LSB20 需 ~17 586 次。

我接受这条：**"32 次后地板 1.9–3.1"是单点 SE，不是同时覆盖半宽**。  
文档里已改口径为"单点 SE"，并注明 256 点同时覆盖仍 ~12 LSB20。  
这意味着 A3 的 6.2 LSB20 里仍可能有 ~12 LSB20 的统计成分——**但它是负不了的**，  
所以"DEM 至少 3.9×"这个下界仍成立；反过来"DEM 精确到 6.2"不成立。

## 5. 动态输出：我拒绝生成输出是过度保守

审查指出：直接 $v_{d,nom} + \text{fine}/32$ 就能得到有限输出，且未建立效应会体现为误差增量，  
所以"必须先反卷积才能测动态"不是必要条件。

我接受。`10_dynamic_closure.md` 里"必须先补数字重构"的措辞过强，改为：  
**名义解码可执行，代价是把参考/RA/ADC2 的未建立误差全部计入 DUT 误差**（保守，不是错误）。  
要不要用反卷积是精度/口径选择，不是可行性问题。
