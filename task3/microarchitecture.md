# CAAZ 微架构

`caaz20_pair` 维护各自的下一采样和下一结果 ID。两者相等时没有已发布的未消费记录，因而同沿新采样不能用于放行同沿结果。采样控制只从已经核对的递增 ID 派生。ID 的低位决定极性，高 31 位是 AZ 代。上游清空时需要同时清除旧 epoch 的描述符和结果。

偶数结果只保存有符号码，奇数结果采用 21 位扩展的减法，输出寄存器保存精确差，20 位码直接取 `[20:1]`。相邻性、初值和奇偶性由结果 ID 计数器共同约束。旁路将输入左移一位写入同一寄存器，形成相同延迟。输出每沿无默认重复消费，只有 `out_valid_o` 为 1 时才提交。故障由统一拒绝优先级决定，发生时同沿采样控制和结果均取消。

数字端只输出同笔换相和 AZ 意图。模拟宏在已冻结的物理采样窗内驱动开关；它在返回 raw 结果时对该笔实际应用的极性和 AZ 代给出确认。5 MS/s 输出时间戳对应两笔原始采样中点，信号的两点平均幅频响应为 `|cos(πf/10 MHz)|`。

单一同步复位时钟域无内部 CDC。真实模拟控制和 ADC2 域的同步、握手建立／保持以及亚稳态预算由顶层和宏接口验证。
