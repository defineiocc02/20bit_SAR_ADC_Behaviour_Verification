# 本轮交叉审阅及来源纠错记录

集成审查以原始页图、实际源码和有身份的原始日志为准，独立审查的建议也必须重新核证。本轮生产 RTL 未改。

已经纳入集成文档的修正：

- sampling/quantizer dither 来源为 PPT17–18；PPT24–26 是参考切换，34–35 是 RA/AZ 和 ADC2 动态带宽，避免页码混用。
- `auxiliary_precharge` 不是当前符号，正确端口为 `aux_charge_enable`。
- MAC 仅生成 A1/any_ovf；错误完成事件、ID/flags 和保留旧 word 属于 recon/output 阶段。
- Q30 量化界的 G≥32 是附加物理条件；名义 sampling G=31.75 时界须重算。
- 568/71拍仅指逐项直接读取的朴素 SRAM 方案，不是所有 bank/cache/预计算架构的不可突破下界。
- MCP 要核最晚数据变化→最早合法捕获及下一变化的 hold，不能只选最长时间间隔。
- 顶层58个具名端口为21输入/37输出，含兼容接口，不是物理引脚数。

一项建议经过原文复核后撤回：把 Flash 3-bit 归为工程选择。论文 [00] PDF p1右栏最上方的采样NFET段明确提到3-bit Flash，和左栏3-bit round-robin shuffler是两个结构。因此集成报告保持3-bit Flash属于原文明示；固定高位seed与六次同步比较的握手安排仍属工程选择。封存独立控制报告中“3-bit seed+六步”的工程实现措辞应按此理解。

本轮复现清楚地区分9例ADC2、6例MAC、16项模拟诊断、有限控制wrapper、独立整数计算与历史P5真实实现，没有把这些计数相加为全核/模拟/形式覆盖。书目[12]的10,797,889与实际附件10,707,889差异继续保留。
