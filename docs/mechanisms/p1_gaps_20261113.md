## 1. 保留列（US10511316B2 FIG.20）→ `control/reserved_column.py`

### 图面计数（300 dpi 原件逐档读出）

| 元件 | 输入 | 输出 |
|:---|:---|:---|
| shuffler **350** | `D6:2x`、`D5:2x`、`D4:4x`、`D3:8x`、**保留:0** | `16x` |
| shuffler **352** | `D2:16x`、`D1:32x`、来自 350 的 `16x` | `8x2` 与 `8x30` |

### 计数自洽（可复算）

* 350 输入权重和 `2+2+4+8+0 = 16` **恰等于**输出 16 ⇒ 标 `0` 的方框**不承载权重**；
* 352 输出 `8×2 + 8×30 = 256 = 8 片 × 32C` ⇒ 正好**一个完整主阵列**。

**结论**：保留列是"16 个槽位里常驻一个哑位"的填充项（16 选 15），不是数据位。
`verify_figure20_counts()` 就是这条自洽性检查——若把 `0` 误读成数据位，输入和会与输出不等，立刻失败。

### 明确未定的

图上只有一个 `0` 方框、**没有编号**，因此"保留位随相位轮转"是本实现的
**工程假设 `ASSUMED_ROTATING`**，不是披露。`reserved_slot_mask()` 的 docstring 已标注。

## 2. AUX 输入（US10541702B1 FIG.1/FIG.2）→ `control/aux_input.py`

### 图面结构

```
V_IN ──[2]──┬──[4]──[6 自举开关]── 采样节点 16 ──[8]──[10]── (后端)
            │
V_IN_AUX ──[2]──[开关 22]── 同一节点
AUX 支路另有：[14 辅助电容] + [18/20 开关]  ——自举/预充
```

**关键结构事实**：AUX 不是第二条独立采样通路，而是**与主输入在采样节点并联的第二个源**；
两者各有一路开关（22），AUX 支路另有自己的辅助电容与复位开关。

### 三条核算不变式（由 `tests/unit/test_aux_input.py` 钉住）

1. 开关 22 断开 ⇒ AUX 源电荷与支路电荷**严格为 0**（不是"很小"）；
2. AUX 与主输入同电位 ⇒ 辅助电容两端无压差 ⇒ **支路搬运电荷为 0**；
3. 复位阶段放掉的电荷**不进信号**，节点净电荷要减去它。

## 5. 参数不自洽的显式化（2026-11-13 晚）

dither 的 4 个用例长期失败。本轮把它们背后的**参数关系**做成一条可读断言，
而不是继续留 4 个红点：

```python

rep = check_dither_fits_stage2(v_fs=3.0, gain=32.0,
                               adc2_v_min=-0.0375, adc2_v_max=0.4125, upper_code_max=5)
rep.summary()
# "ADC2 covers 1.24 LSB1 but dither needs 5.50; short by 4.26 LSB1. The second stage

#  choice, not an implementation defect."
```

### 结论同时进 `inference_table()`

`DefaultModel.inference_table()["stage2_capacity_vs_dither"]` 直接给出：

| 字段 | 值 |
|:---|:---|
| `adc2_coverage_lsb1` | 1.2376 |

## 6. 本轮对 ADC2 量程的新证据与一次被推翻的推测（2026-11-13 深夜）

### 6.1 新证据：PPT 第 9 页 ">12b AC matching (SADC to RDAC)"

逐字："Matched slice DAC structure **>12b AC matching (SADC to RDAC)**"。
含义：SADC 与 RDAC 的匹配度超过 12 bit，即**两者对同一码的解读差 ≤ 1/4096 满幅
（= 0.125 LSB9）**。

### 6.2 由此得到的定量结论（可复算）

残差的定义是 `residue = x − vd0(k) = 量化误差 + U·Δ`，其中 `U = 4·D6 + D4 ∈ {0,1,4,5}`：

| U | 残差范围 [LSB1] |
|:---:|:---|
| 0 | [−0.5, +0.5] |
| 1 | [−0.5, +1.5] |
| 4 | [−0.5, +4.5] |
| **5** | **[−0.5, +5.5]** |

⇒ **ADC2 必须覆盖 5.5 LSB1 的窗口**。当前窗口 0.45 V 只覆盖 1.24 LSB1（G=32）。
这不是实现选择，是结构性的。

### 6.3 被推翻的推测（记录在案，避免重复）

我曾推测 "`U ∈ {0,1,4,5}` 缺 2,3，说明 D6 是'范围增强使能'、两组互斥，
因此单次只需覆盖 4.5 LSB"。**该推测被推导推翻**：

```
残差 = x − vd0(k) = x − (c − U)·Δ = (x − c·Δ) + U·Δ ≈ 量化误差 + U·Δ
```

U 是**累积**提前量，不是二选一；D6=1 且 D4=1 时残差确实到 5.5 LSB。
相应代码已逐行删除，未留在仓库里。

### 6.4 与 20 bit 目标的自洽性扫描（纯参数运算，不修改任何配置）

要求：① 覆盖 ≥5.5 LSB1；② 二级量化 LSB 折到输入 ≤0.5 LSB20。

| 窗口 | n | G | 覆盖 LSB1 | 二级 LSB [LSB20] | 自洽 |
|:---:|:--:|:--:|:---:|:---:|:---:|
| 0.45 V | 12 | 32 | 1.20 | 0.60 | ✗（现状） |
| 0.75 V | 13 | 32 | 2.00 | 0.50 | ✗ |
| 1.31 V | 14 | 32 | 3.49 | 0.44 | ✗ |
| 2.06 V | 15 | 32 | 5.49 | 0.34 | ✗（差 0.01） |
| 2.25 V | 15 | 32 | 6.00 | 0.37 | **✓** |

结论：要同时满足 dither 幅度与 20 bit，G=32 时窗口需 **≥2.1 V、ADC2 需 ≥15 位**。
而论文/PPT/六份专利**均未给出 ADC2 位数或窗口**，因此该配置属**未定项**，
不写入默认参数——只在 `inference_table()["stage2_capacity_vs_dither"]` 里如实报告缺口。

## 7. 本轮重跑矩阵暴露的三个真实缺陷（2026-11-13）

用新模型跑 `tools/run_p4_ablation.py`（1024 点）得到：

```
A0_ideal         INL= 28.6 LSB20  SNDR=86.13 dB  DR=96.45 dB
A1_mismatch      INL= 56.7 LSB20  SNDR=81.36 dB
A6_dither_in_loop           SNDR=39.44 dB   ← dither 一开就崩
```

理想配置（零失配、零噪声）本应 INL=0、SNDR 接近量化极限，实际不是。逐层定位到三个缺陷：

### 7.1 SADC 阈值与码本不同源（本轮已修）

阈值原本是 `linspace(-v_fs, +v_fs, 513)` 的等距表，而码本是 Fig.11 实测的
（每步 31.9375/512 C）。两者在中间码相差近 **2 个一级 LSB**，于是粗码判决
与 RDAC 电荷不同源。现已改为 `thresholds[:512] = codebook.voltage_v`，
末位补上边界。实测阈值与码本逐点相同、严格递增。

### 7.2 定点重构被 ADC2 饱和拖低（未修，根因已定位）

`x = +1 V` 时 `adc2_code = 4095`（饱和），`fine_v` 被钳在窗口上界，
定点输出 0.769 V 而浮点输出 0.999 V。直接原因：
残差实测 ±0.013 V × G32 = ±0.42 V，超窗口半宽 0.225 V。

### 7.3 采样侧与转换侧的归一化仍有 3% 的差（未修，两条路都有代价）

| 口径 | 值 |
|:---|:---|
| 采样侧 `C_norm`（全列） | 32.9437 C |
| 转换侧 `c_slice`（16 列 + 4 子单元） | 31.9416 C |
| 比例 | **1.0314** |

实测佐证：`x = ±2 V` 时 `q_free/C = ±2.003569`（应 ±2.000000），
偏差 0.0036 正比于输入 —— 这正是 3% 口径差在采样侧的表现。

**两条自洽路线都走不通**：

* 路线 A（都用全列 32.94C）：端点 `v(511) = 2.8166 V`，与论文 "±3V" 矛盾；
* 路线 B（都只用 31.94C）：采样时 S4 与子阵列哑位**实际接信号**
  （`_all_signal` 把它们设为 SIGNAL），排除它们会漏掉真实电荷。

⇒ 这条需要先回答"采样阶段 S4/哑位接什么"，而原件没有给。

### 7.4 本轮的做法

只提交 7.1（有明确原件依据、且 1437 passed 不变）；
7.2/7.3 记录在此，不改代码 —— 它们都是"改一处就会在另一处出现
相等量级偏差"的类型，反复试参数只会得到互相矛盾的中间态。

## 8. 试图修 7.2/7.3 的两次失败尝试（2026-11-13，均已回退）

### 8.1 第一次尝试：只改归一化

把 `charge_from_sampling_connections` 的 `normalization` 从固定的 `c_signal`（全列 32.94C）
改为按连接算的 `input_cap`（31.94C）。

**结果**：增益比从 1.0315 降到 **0.99835**（口径差基本消除），传输函数误差从
0.17 V 量级降到 0.003–0.011 V。**但同时 `adc2_over` 从 41/100 恶化到 100/100**，
残差从 0.0153 V 涨到 0.1034 V，并新增 1 个失败用例（`test_simulate_ordinary_az`）。

诊断：`q_free / C_norm = 0.9017`（应为 1.0）——**`q_free` 与 `normalization` 不同源**。
`q_free` 走 `held_effective_node_charge`，与采样连接无关。

### 8.2 第二次尝试：归一化 + 采样连接一起改

假设"S4 与哑位在采样期接低轨"能让两者同源，同时改 `_all_signal` 与 `normalization`。

**结果**：`q_free/C` 仍是 0.9017（不变）。实测确认：`C_norm` 在两种连接下**完全相同**
（32.944C），因为它取的是固定全列；而 `q_free` 确实随连接变化（2.49e-12 → 2.18e-12）
—— 两者对连接的敏感度不同，改连接不足以让它们对齐。

### 8.3 结论与纪律

当前采样/转换链路上有**三套电容口径**同时存在：

| # | 量 | 值 |
|:--:|:---|:---|
| 1 | `normalization_capacitance_f`（采样侧归一化） | 32.9437 C |
| 2 | `signal_capacitance_f`（转换侧归一化） | 31.9398 C |
| 3 | `nominal_gain` 用的 `c_slice` | 31.9375 C |

要让 #1 与 #2/#3 对齐，必须同时改动 `q_free` 的产生路径（`held_effective_node_charge`）
——那是另一条独立链路，改动面比前两次更大。

**本轮两次尝试都造成了净负面（测试变多、饱和变多），已逐字节回退，未提交。**
在拿到"采样阶段 S4/哑位到底接什么"的原件依据之前，不再尝试这条链。

## 9. 第三轮尝试（2026-11-13）：把 β 统一到 1/17 —— 失败，但缩小了问题范围

### 9.1 已确认的事实（本轮实测）

| 量 | 值 | 说明 |
|:---|:---|:---|
| `q_free / x / 8` | **33.0025 C** | 与失配无关，零失配时同样是 33.0025 |
| 器件 `c_slice`（全列） | **32.9445 C** | `32.0043 + 0.0588×15.9825` |
| 两者差 | **0.058 C** | **不是 β 造成的**（见 9.3）|
| `nominal_beta` | 1/16 = 0.062500 | 名义分母用 ΣB=15C |
| 器件 `beta` | 0.058822 | 器件 ΣB=15.98C（含哑位） |

### 9.2 尝试

把名义 β 的分母改成含哑位的 16C（使 `nominal_beta` 与器件 β 一致，都 ≈1/17）。

**结果**：`nominal_beta` 变成 0.058824、与器件 0.058822 一致 ✓，
但 **`q_free/C` 仍是 1.0018（无改善）**，且码本端点从 3.000 掉到 **2.989**
（因为 `drive(511)` 里的 β 也一起变小），导致 2 个 v1 用例失败。

**判定：净负面，已逐字节回退。**

### 9.3 由此得到的结论

`q_free` 的 33.0025C 与器件 `c_slice` 的 32.9445C 之间的 0.058C 差，
**不是 β 差异**（把 β 改成一致后仍然存在）。它只能来自 `held_node_charge()`
—— `q_free = Σ(Q主 + β·Q子)` 里 `node` 本身的算法。

这把排查范围缩小到**唯一一个函数**：`slice_pool.held_node_charge()`。
下一轮应直接读这个函数的两个返回值（主/子节点电荷）与 `c_slice` 的定义逐项对比，
而不是再动 β 或归一化。

### 9.4 纪律记录

本轮是连续第三次尝试同一处（口径差）失败。三次分别是：
1. 只改 `normalization` → 饱和恶化；
2. `normalization` + 采样连接 → 无改善；
3. 统一 β → 无改善 + 端点回归。

三次都逐字节回退。**在读完 `held_node_charge()` 之前不再动这条链。**

## 10. 口径差的最终定位（2026-11-13，读到 `held_node_charge` 之后）

### 10.1 精确分解（可复算）

零失配、x = 1 V 时：

| 量 | 实测（8 片合计） | 单片 |
|:---|:---:|:---:|
| `Q_main / x` | 256.026 C | **32.003 C** ✓ 与器件 `C_main=32.004` 一致 |
| `Q_sub / x` | 127.921 C | **15.990 C** ✓ 与器件 `C_sub=15.983` 一致 |
| `β`（pool 用的） | — | **1/16 = 0.062499** |
| `q_free / x` | 264.021 C | **33.000 C** |
| 器件 `c_slice` | — | 32.944 C |

`q_free = Q_main + β·Q_sub = 256.026 + 0.0625×127.921 = 264.02` —— 完全对上。

### 10.2 根因：两个 β 并存

| β | 值 | 用在哪 |
|:---|:---:|:---|
| `β_phys = Cb/(Cb + ΣB_含哑位)` | **1/17 = 0.0588** | 器件电容 `c_slice`、`split_capacitance_coefficients` 直接调用 |
| `β_pool = Cb/(Cb + ΣB_可切换)` | **1/16 = 0.0625** | `pool.split_coefficients`（`_switched_sub_units = 4`）→ `q_free`、RA 增益 |

`0.058 C` 的差 = `哑位 1C × (β_phys − β_pool)` 的一阶效应，与实测完全吻合。

**注意历史**：`_switched_sub_units=4` 是我在早前轮次为让 `drive(511) == cn`
（端点闭合）**刻意引入**的。所以这不是"某处写错"，而是**当时为解决端点问题
而引入的口径分叉**，现在以 0.17% 的形式浮到 `q_free` 上。

### 10.3 二元判断（这是唯一剩下的岔路）

```
若哑位**不接** sub 节点（两端接低轨）：
    ΣB = 15C ⇒ β = 1/16 ⇒ β_pool == β_phys ✓ 两处自动一致，q_free 正确
若哑位**接** sub 节点（一端 sub、一端低轨）：
    ΣB = 16C ⇒ β = 1/17 ⇒ 码本端点需重新推导，drive(511) ≠ cn
```

两条互斥，且**决定性信息原件没有给**：子阵列第 5 个单元在原件 FIG.11/19 上
画了（每片 8C/4C/2C/1C/1C 五列），但没有说明第 5 个 1C 接在哪两个节点之间。

### 10.4 本轮不再尝试

前三次尝试均已回退。在 §10.3 的那个二元判断有依据之前，
继续改 β / normalization / 采样连接都只会在这两个错误之间来回跳。
