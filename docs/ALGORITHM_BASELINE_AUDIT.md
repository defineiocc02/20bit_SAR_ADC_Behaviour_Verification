## 五、暂停新增 PASS、暂缓综合与 APR 的理由

### 为什么暂停新增 PASS

1. **D1/D3/D5 的算法正确性均未成立**（A1–A4）。此时给 D6 打 PASS，等于用"实现正确"顶替"算法正确"。
2. **random18 只存在于 Python**，RTL 与模型不一致（A3）。任何基于当前 RTL 的 PASS 都描述了一个**不是**目标算法的系统。

### 为什么暂缓综合与 APR

1. **PPA 已经作废两次**：`follower_rt` 与 `ev_abort_o`/`ev_abort_tag_o` 两次新增端口后，99,196 µm² 与 +16.51 ns 均不再对应当前 RTL（P1-4）。
2. **架构尚未定形**：若 random18 进 RTL，D5 需从"9 组倒数查表"改为"动态 G + 实时倒数"（A4），这会同时改变**运算路径与存储架构**，系数存储占比 27.9% 的结论随之失效。
3. **hold 118 条未修**，在架构变更前做 CTS/hold repair 属无效投入。

### 解冻条件

**P0-1 至 P0-5 全部通过**，且三份规格文档对同一模块给出同一状态。
在此之前，只允许追加"实现正确"级别的证据，不新增 PASS 标签。

## 七、P0-1 实测结果：**FAIL**（2026-11-14）

工具 `tools/p0_axis_stats.py`，N=17280。

| 检验项 | 结果 | 判定 |
|:---|:---|:---:|
| reserved 自相关（lag 1..20） | \|ac\|max = **0.898**，20/20 超 95% 带（±0.0149） | **FAIL** |
| h_phase 自相关 | \|ac\|max = **0.866**，20/20 超带 | **FAIL** |
| v_phase 自相关 | \|ac\|max = **0.963**，20/20 超带 | **FAIL** |
| MI(reserved, h_phase) | 0.00000（置换 95 分位 0.0104） | OK |
| MI(reserved, v_phase) | **1.27830**（置换 95 分位 0.0055） | **FAIL** |
| MI(h_phase, v_phase) | 0.00718（置换 95 分位 0.0053） | **FAIL** |
| 联合覆盖 | **794 / 1920 = 41.4%**（要求 ≥90%） | **FAIL** |
| `v=(r+2)%8` 满足率 | 2160/17280 = 12.50%（= 独立理论值） | OK |

### 三条关键发现

**① 自相关高是结构性的，不是数值问题**

`q = sample_id // 9` —— **连续 9 个样本共用同一组相位**。
因此 lag=1 的自相关接近 1 是必然的。

**这本身就是一个算法缺陷（记为 A5）：** DEM 的作用是把失配误差在样本间打散，
而当前排程连续 9 拍相位完全不变，等于每 9 拍才有一次"打散"。

**② MI(reserved, v_phase) = 1.278 bit 是强依赖**

虽然 `v=(r+2)%8` 这个特定式子只以 12.5% 成立（独立水平），
但两轴之间存在**另一种形式的依赖**，MI 达 1.278 bit
（16×8 组合的最大信息量约 3 bit，即 42%）。

**说明"改取不同位段"只解掉了那个特定式子，没有解掉两轴的统计依赖。**

**③ 联合覆盖 41.4%，远未到 90%**

### P0-1 判定

**FAIL。** 且它同时否决了此前的"三轴已独立"结论（`docs/DEM_3D_RANDOM.md` 中
"12.5% 正是 1/8 即独立"的说法不成立——那只检验了一个特定关系式）。

### 影响

- D3 的三维随机化**目前不成立**
- `random18` 进 RTL 的前提（P0-3/P0-4）之上又叠加了 P0-1 未过
- 此前测得的"杂散改善 5.6~10.7 dB"仍然有效，但它改善的是
  **legacy9 → 当前排程**，不是"已独立的三维随机化"

### 修复方向（未实施）

| 问题 | 方向 |
|:---|:---|
| 9 拍共用相位 | 去掉 `//9`，让每个样本独立取相位（但需保证片组与相位不冲突） |
| 两轴统计依赖 | 用**联合**构造（如单个 11 位 LCG 取不同字段并做置换表），而非两个独立 LCG 取模 |
| 联合覆盖 | 用 0..1919 的满周期计数 + 置换表映射到三维，天然 100% 覆盖 |

## 八、排程 v3（满周期置换表）复测 P0-1

### 改动

放弃"三个独立 LCG 各自取模"，改为：

```
i = PERM[sample_id % 1920]          # 固定种子的 Fisher-Yates 排列
(reserved, h_phase, v_phase) = (i//120, (i//8)%15, i%8)
```

- 每个样本推进一格（不再 `//9`）
- 置换表保证 1920 个组合各出现一次
- 表可导出给 RTL 做 ROM

### 复测结果（N=17280）

| 检验项 | v2 | **v3** | 判定 |
|:---|:---|:---|:---:|
| reserved 自相关 \|ac\|max | 0.898 | **0.0537** | 仍超带 |
| h_phase \|ac\|max | 0.866 | **0.0496** | 仍超带 |
| v_phase \|ac\|max | 0.963 | **0.0406** | 仍超带 |
| MI(reserved,h_phase) | 0.000 | **0.000** | **OK** |
| MI(reserved,v_phase) | **1.278** | **0.000** | **OK** |
| MI(h_phase,v_phase) | 0.007 | **0.000** | **OK** |
| 联合覆盖 | 794/1920 (41.4%) | **1920/1920 (100%)**，每组合恰好 9 次 | **OK** |

### 判断

**三项中的两项已彻底达标**：轴间互信息全部为 0，联合覆盖 100%。

**自相关从 0.87~0.96 降到 0.04~0.05（改善约 18 倍），但仍超出 ±0.0149 的判据带。**

### 关于自相关判据的说明（不掩盖）

`±1.96/√N` 是 **iid 序列**的白噪声带。而 v3 是**有限周期内的无放回排列**，
其自相关的方差与 iid 不同，用同一判据偏严。

**但这个理由不能自动算通过**：需要先确认"排列序列的自相关理论界"到底是多少，
再决定这条判据怎么改。**在确认之前，P0-1 仍判 FAIL。**

### 下一步

1. 推导/查证长度 1920 的随机排列在 lag k 处的自相关分布，
   给出对应的判据带（而非沿用 iid 的 ±1.96/√N）
2. 用修正后的判据复判
3. 若仍不过，则考虑在排列之上再加一层"每周期重排"或用互质步长跳读

## 九、P0-1 判据修正与最终判定：**PASS**

### 判据为什么要改

原判据 `±1.96/√N` 是 **iid 抽样**的白噪声带。
v3 是**有限周期内的无放回排列**（17280 = 9 × 1920），不是 iid，
用 iid 带偏严 —— 但"偏严"本身不构成通过理由，必须给出正确的判据。

### 正确判据：排列零分布

生成 M=200 个**与 v3 同长度、同混合进制映射**的随机排列，
统计各自 lag 1..20 的 `|ac|max`，取 95 分位为判据带。

理由：v3 的设计目标就是"看起来像随机排列"，因此零假设应是随机排列，
而不是 iid 白噪声。

### 结果（`tools/p0_perm_null.py`）

| 轴 | 零分布 50% | 零分布 95%（判据带） | 零分布最大 | **v3 实测** | 判定 |
|:---|---:|---:|---:|---:|:---:|
| reserved | 0.0482 | 0.0751 | 0.0976 | **0.0537** | **PASS** |
| h_phase | 0.0473 | 0.0669 | 0.0972 | **0.0496** | **PASS** |
| v_phase | 0.0467 | 0.0706 | 0.0942 | **0.0406** | **PASS** |

**v3 三轴的自相关都落在随机排列零分布的 50% 分位附近**，
与"真正的随机排列"在统计上不可区分。

### P0-1 最终判定

| 子项 | 结果 |
|:---|:---:|
| 自相关（排列零分布判据） | **PASS** |
| 轴间互信息（置换零分布） | **PASS**（三者均为 0.000） |
| 联合覆盖 1920/1920 | **PASS** |
| `v=(r+2)%8` 满足率 12.50% | **PASS**（独立水平） |

**P0-1 PASS。**
