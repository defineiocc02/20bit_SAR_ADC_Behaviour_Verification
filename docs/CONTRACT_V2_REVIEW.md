# 合同 v2 评审意见（请合同制定者修改）

评审对象：`ISSCC2024_ONCHIP_CONTRACT_v2.md`
评审方式：按 §3/§6 实现 G1 检查器（`tools/contract_v2.py`），以实现中遇到的阻塞点反推合同缺项。
结论：**G1 名义映射可跑通（66,560 组偏差 0），但合同有 9 处需修订，其中 3 处会阻塞 G2 及以后。**

---

## 一、阻塞级（不修订无法进入 G2）

### B1. SADC 的结构与其 D(k) 未定义 ★最严重

§3.3 写：

> 其主阵列用 **7×8Cu 及 4Cu、2Cu、1Cu、1Cu** 构成；后三个工作位提供 9-bit 码的中间三位……子阵列普通细分 4/2/1Cu

而 RDAC（§3.1）是 **8 个宏单元 × 8Cu + 子阵列 4/2/1/1**。

**问题**：SADC 用 7 个宏单元、RDAC 用 8 个，两者都声称产生 9-bit 码。合同没有给出：

1. SADC 自己的 `D_sadc(k)` 是什么（7 宏 + 4 子 → 56+8 = 64Cu，与 512Cu 满量程的关系）
2. 若 SADC 与 RDAC 的 `D(k)` 不同，余差 `y = x - D_rdac(k)` 就不再落在 `[0, 6/512)`，§8.1 的 ADC2 窗口推导失效
3. "后三个工作位提供中间三位"与 `k = 64H+8V+L` 的对应关系

**请补充**：SADC 的完整码权表，并给出 `D_sadc(k)` 与 `D_rdac(k)` 的差值上界（这直接决定 ADC2 窗口是否要加宽）。

### B2. `1 LSB = 1 Cu` 未显式写明

我在 G1 里假设：满量程 512 Cu、1 LSB = 1 Cu、`8N+L == k` 成立。§3.1 只写了"8片主采样阵列总电容512Cu，名义输入增益512/16=32"。

**请补充一句**：`D(k) = k · Cu`，即 1 LSB 对应 1 Cu 的等效采样电容切换，满量程 512 Cu。

### B3. guard 码 512–519 的 `D(k)` 与开关表未给

§5 写"RDAC 普通范围 0..511；512..519 采用 8×8 宏单元全部选中，加子阵列 0..7；**520 使用子阵列 4+2+1+1 全部选中**"。

**问题**：

1. `k = 64H + 8V + L` 无法表达 k ≥ 512（H 会是 8，超出 [0,7]）
2. 码 520 的物理含义是 `D(520) = 520 Cu`，**超过 512 Cu 满量程**。那 §1 的 "±3 V 满量程" 与 §8 的 `y = G·x + 3G - ...` 是否还成立？
3. 码范围到底是 0..519 还是 0..520？合同附件写 66,688 = **521**×8×8×2，我按 520 实现得 66,560，差 128

**请补充**：guard 区完整码表（512/516/520 各码的 H/V/L 与开关状态），并明确码范围是 0..519 还是 0..520。

## 二、定义缺失（会导致实现各写一套）

### B4. 保留列的判定规则

§6 写"横向：[thermometer7(H),0]……保留列随同轮转"，但没说保留列**是哪一个位置**。

我按"保留列 = 热码字中那个固定 0 位"实现，即 `reserved = (7 + h_phase) % 8`。
第一版误写成 `h_phase % 8`，结果 k=64 时选中的列正好是保留列，电荷算成 0。

**请明确**：保留列索引是否就是 `(7 + h_phase) mod 8`。

### B5. `bridge_coin` 的交换对象与 mask 表示

§6.1 写：

> 交换"选中主半单元的转换控制位"和"全部 8 片子 4Cu 支路的转换控制位"

**三个未定义**：

1. "选中主半单元"是哪个？8 个宏 × 2 半 × 8 片 = 128 个候选中如何选？
2. 交换后 post-mask 怎么表示？一边是 1 个物理单元（4Cu），另一边是 8 个物理单元（各 4Cu/8 有效）。**单元个数不同**，`Wm` 的求和范围随之变化
3. coin=1 时，D5 用的是交换后的 mask——那 `G`（活动主采样单元）是否也随之变？

我在 G1 里对 coin=1 只写了 `pass`（不改电荷），**这不是验证**。

**请补充**：交换对象的选择规则 + coin=0/1 两种 post-mask 的完整定义。

### B6. `Wp` 的符号与求和范围

§8 定义 `Wp = sum(actual sub-array sample pre-mask * physical weights)`，公式 `y = G·x + 3G − 6Wm + 6Wp + b`。

§7.2 定义 pre-mask 为"f 片预置 J+1，其他片预置 J"，每片整数 0..8 用 4/2/1 编码。

**未定义**：

1. `Wp` 是对 8 片求和，还是只对子阵列（j=16..19）求和？
2. pre-mask 的权重经 β=1/8 后是否已含在 `w` 里？（§3.2 表里 j=16..19 的 `w = 1/32, 1/64, 1/128, 1/128` 已经是 β 后的值）
3. `+6Wp` 的符号：预置使余差**增大**还是减小？

### B7. `b` 与 `alpha` 的标定方法

§8 写"b 为声明并标定的输出坐标偏置；名义为 0"，"若另外建模了独立 RA 增益 alpha…"。

**未定义**：

1. `b` 由谁标定、标定数据从哪来、允许范围
2. `alpha` 是全局一个值，还是每片组一个？

### B8. DEM 的 `h` / `v` 推进时机

§6 写"h 按每笔**接受的新采样事务**加 1 模 8；v 由独立状态的固定种子 PRNG 提供"。

**未明确**：

1. "接受的新采样事务"是 `launch_accept` 还是 `acq_sel` 冻结那一拍？
2. `v` 的 PRNG 是否与 D1 片池 PRNG 共用状态？（若共用，两者会相关）
3. `h` 在 reset / stall / 被拒 start 时是否推进？

### B9. 双 SADC 与 18 片池的资源关系

§1 明确"18 个物理 slice，**仅指 RDAC 池**，不包括两个独立 SADC"，§2 又说模拟环境有"两个相互独立的 SADC 物理实例"。

**未说明**：

1. 两个 SADC 各自的采样电容从哪来？是否也要采样 Vin（会叠加输入负载）？
2. SADC 采样与 RDAC 的 8 片 ACQ 是同一时刻吗？
3. qid 轮换遇到"一个 qid 正在转换、另一个空闲"时如何仲裁？
