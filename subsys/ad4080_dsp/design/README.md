# SINC5 补偿 FIR 工程设计

本设计用 **35 抽头、signed24 Q22 对称 FIR** 补偿并配合二倍抽取。每档直流系数总和精确为 `2^22`。8 个档位通过量化后的通带、带宽和分段阻带验收。系数由公开响应约束独立求解，验证范围是本工程数值模型及查表源码。[生成器](generate_sinc5_comp.py) · [系数与数值回执](sinc5_comp_coefficients.json) · [合成半表](../rtl/sinc5_comp_coeff_lut.svh)

## 从原件到优化

已有 SINC5 以 $N=2,4,\ldots,256$ 抽取并按 $N^5$ 归一。以原 ADC 采样频率 $F_s$ 定义 $f/F_s$，中间率的归一频率为 $u=Nf/F_s$，最终采样率为 $F_{out}=F_s/(2N)$。图 105 和图 106 题注的 “Decimate by 2” 对应第一级 $N=2$，图 107 和表 28/29 的最小总倍率为 4。模型按原始 Nyquist 范围评价输入单音经两级抽取的幅度，包括最终 Nyquist 之外会混入输出的频率。[图 96、表 28](https://www.analog.com/media/en/technical-documentation/data-sheets/ad4080.pdf#page=64) · [表 29](https://www.analog.com/media/en/technical-documentation/data-sheets/ad4080.pdf#page=66) · [图 105–107](https://www.analog.com/media/en/technical-documentation/data-sheets/ad4080.pdf#page=70)

复合幅值用归一 SINC5 $|\operatorname{sinc}(u)/\operatorname{sinc}(u/N)|^5$ 乘 FIR 去线性相位的 18 项余弦多项式，最后取绝对值。LP 保证 DC 为一，表 28 打印中心的幅度精确取 $10^{-3.000/20}$，并限制过渡段下降。在图 105 的各阻带窗同时夹住有符号幅值的正负两侧。其在 $f/F_s\simeq0.125167$ 的笔画有一段垂线，因此从 $f/F_s=0.13$ 开始单列稳定阻带，前导窗作为过渡守门。[原件表及向量锚点](../../ad4080_peripherals/interfaces/dsp_review/manual_filter_targets.csv)

图 106 的细刻度形状用于 N=2。按实测图墨上下界对训练点的幅度偏差归一，极小极大求出同一 35 抽头的形状。对其余档位，以 $u=0.176130302$ 作为工程通带端点并优化单位幅度的最大偏差。图 107 约束八档同一个代表窗 `f/Fout=0.57…0.75`，包括左边界的幅值锚点及全窗峰。幅值图未给出符号，分别解锚点的正负两个 Type-I FIR 候选，采用目标较小的可行解。频域求解的阻带网格留 0.02 dB 守门余量，再做独立密扫。

每档量化使用最近整数，舍入后仅调整中心系数以恢复 DC，同时保留镜像对称。若滤波已被限幅到 20 位的 SINC5 输出，所有档的乘加加半步最少需要 44 位有符号累加器来覆盖实际系数的绝对和界。两次未饱和半步舍入各自最多半码，使用实际最大系数绝对和 2.1272，SINC5 舍入经 FIR 传播加上 FIR 输出舍入的界约为 1.564 码。样本实际处理顺序、饱和和有效相位由消费 RTL 验收。

B 第 70 页。以 PyMuPDF 1.26.5 的 `document[69].get_drawings()` 读取 `seqno=793` 折线，边框 `seqno=794` 将横坐标映射到 `0…0.1 f/Fs`，纵坐标映射到 `+0.5…−0.5 dB`。在 `k×0.001 f/Fs` 取折线插值，`k=1…92`，偶数训练、奇数留出。曲线宽 1.175313 pt、坐标框宽 0.587656 pt，合计半宽 0.8814845 pt 对应横向 ±0.00050、纵向 ±0.00625 dB。每点上下界先取横向范围内中心线极值，再加入纵向裕量。图 105 和图 107 的读图容差与窗口细节保留在 [原件提取 CSV](../../ad4080_peripherals/interfaces/dsp_review/manual_filter_targets.csv)。这些是图的数字化范围，实际器件容差、原厂相位和内部系数须由独立证据确定。

工程冲激支持长为 `5(N−1)+1+34N = 39N−4` 个原始样本，另有 RTL 流水时延。第 69 页印刷 `2+35D+10`，在 COMP 建立式的 $D$ 口径存在歧义。工程系统按其 FIFO 计数字面一致的总倍率 `D=2N` 安排开始输出，滤波稳定性用产品回归核对。[建立时间公式](https://www.analog.com/media/en/technical-documentation/data-sheets/ad4080.pdf#page=69)

## 复跑与接入

从仓库根在固定环境运行。当前实测 NumPy 2.5.3、SciPy 1.18.1。同环境两次生成的 JSON 与半表逐字相同。用 `--out-json` 和 `--out-svh` 可改写到临时目录比较而保留工作树。

```sh
OPENBLAS_NUM_THREADS=1 python -B subsys/ad4080_dsp/design/generate_sinc5_comp.py
```

`sinc5_comp_coeff_lut.svh` 在模块内部包含。使用 `PMODE_COMP_TAPS`、`PMODE_COMP_COEF_W`、`PMODE_COMP_COEF_FRAC`。`sinc5_comp_coeff(rate, tap)` 的 `rate=0…7` 对应 $N=2\ll rate$，`tap=0…17` 从 FIR 两端至中心。对称对 `tap<17` 加 `x[n−tap]` 和 `x[n−(34−tap)]` 后乘系数，中心抽头只用 `x[n−17]`。抽取率、历史及输出有效在 `FILTER_SYNC` 的合同内由消费端重设。实际 Verilator 读取的 144 个半表有符号值逐字与 JSON 相同。
