## 2. 结构深度排序（估算）

按寄存器到寄存器的组合深度，从深到浅：

| 排序 | 路径 | 主要算子 | 说明 |
|:--:|:---|:---|:---|
| 1 | `adc2 → code20` | `×144` → `÷5` → 两次加法 → `÷96` → 舍入 → 饱和 | `recon_d5`，**两级整数除法** |
| 2 | `sample_id → sid[0..7]` | `×8` → `%18` → 8 路 `+i` → `%18` | `slice_pool`，模 18 是减法链 |
| 3 | `k → h[0..15]` | `÷15` 求余 → 比较 → 16 路并行 | `dem_shuffle`，模 15 |
| 4 | `c → k_ev[0..6]` | 移位 + 减 | `follower`，最浅 |
| 5 | `word → U/L/T` | 纯拼接 | `dither_split`，**几乎零深度** |

## 3. 三个长杆子（都可消除）

**① `÷96`**：`96 = 32 × 3`。除以 32 是移位，除以 3 可用
`x/3 = (x + (x>>2) + …)` 的移位加链，或直接 `(x * 21845) >> 16`（16 位精度）。

**② `÷5`**：`((2a+1)*144+2)/5 = (2a+1)*28.8`。可改成
`(2a+1)*14745 >> 9`（14745/512 = 28.8008，11 位内误差 < 1 LSB），免除法器。

**③ `%15` / `%18`**：相位是**递增计数器**，不必每拍求余；把
`(idx + 15 - h_phase) % 15` 改成「比较 + 条件减 15」两次即可（值域 < 30）。

## 4. 结论与边界

- **能说**：按结构，最长的组合路径在 `recon_d5` 的两级除法上；`dither_split` 几乎不占深度。
- **不能说**：具体多少 ns、能跑多少 MHz、是否满足 40 MS/s。
  这些必须有目标库 + SDC + `report_timing` 才成立。
