# 20 位八片 LMS 重构核 v1.0

> **负注入合同**：控制、浮点模型与整数重构统一采用 `k=c−U`、子特征
> `conv_sub+sample_sub`（同位两次使能计 2）。独立节点参考使用显式受控电荷源；
> 真实底板接轨尚未绑定。旧正注入图和 GDS 只属于各自归档版本，不能证明本版。


`sar20_lms_recon` 把每笔 ADC2 12 位原码、八片实际转换与采样底板位图、已训练增益和有效权重变成同一笔 20 位有符号码。训练仍在片外；配置序列允许流片后重写系数。输入使用斩波坐标系，输出在 CAAZ 配对前逐笔去扰。电路定义和权重顺序来自 [八片行为模型](../task2/eight/model.py) 和 [实验](../task2/eight/experiment.py)。本版公式替代历史正注入合同，验收入口见 [负注入交付](../task2/evidence/eight_negative/README.md)。

## 电荷和数值规则

设 `Vspan=10 V`，`Q=2^28`。所有电压整数按 `v/Vspan × Q`。装入 `21` 个物理有效权重，前 `17` 个为主阵列转换系数，后 `4` 个按 `8C/4C/2C/1C`。每个有效权重等于名义电荷权重加 LMS 差量，按最近整数舍入。主名义权重为相对电容 `2/256` 或 `1/256`，子名义权重为 `8/4352,4/4352,2/4352,1/4352`，最后的 dummy 恒低。`g_s` 是片外从增益对训练得到的第 `s` 片无量纲有效增益，按 `g_s×Q` 量化。

每笔使用八个物理片号和实际位图，主阵列特征为 `conv_main`，子阵列特征为 `conv_sub+sample_sub`。按物理片号加权并相加，受控负注入由采样项的正号补回；两掩码同时置位时计两倍权重。实际转换位图已含 Fig.21 跨段映射，所以不额外叠加桥校正或名义总扰动。ADC2 midpoint 在归一化 Q28 下为 `round((2*adc2+1−4096)×16384/25)`，正负对称最近整数舍入。令 `N` 为权重项与 midpoint 之和，`G` 为八片已配置的增益之和。只对 `0≤N<G` 输出 `floor(N×2^20/G)−2^19`，其他情况标记 `bad`，保留样本 ID。接受端点 `N=0`，拒绝 `N=G`。

| 端口 | 位宽 | 上升沿合同 |
| :--- | :---: | :--- |
| `clk_i`, `rst_ni`, `clear_i` | 入 1/1/1 | 所有端口同域；低有效同步复位取消在途和配置有效性。`clear_i` 取消在途和未完成装载，保留完整配置。 |
| `cfg_start_i`, `cfg_start_ready_o` | 入／出 1/1 | 空闲且无在途时新装载握手，立即使旧配置失效；若同沿有采样请求，配置优先。 |
| `cfg_valid_i`, `cfg_ready_o`, `cfg_data_i` | 入 1、出 1、入 26 | 握手顺序为物理片 0…17，每片 21 个权重再一项增益，共 396 字。权重须按 signed24 符号扩展，增益范围 `[2^24,3×2^24]`。 |
| `configured_o`, `cfg_error_o` | 出 1/1 | 全部成功后置已配置；坏字终止装载，错误保持到下次配置启动或清除。 |
| `in_valid_i`, `in_ready_o`, `in_sample_id_i`, `in_bad_i` | 入 1、出 1、入 32/1 | 握手时快照；输入 bad 表示宏超窗或外部 ID 合同错误。 |
| `in_slice_ids_i`, `in_main_i`, `in_conv_sub_i`, `in_sample_sub_i`, `in_adc2_i` | 入 40/136/40/40/12 | slot 0 在最低位，片号 5 位，主 17 位、子 5 位每 slot。ADC2 为 ±100 mV 输入折算 offset-binary 原码。 |
| `out_valid_o`, `out_ready_i`, `out_sample_id_o`, `out_code_o`, `out_bad_o` | 出 1、入 1、出 32/20s/1 | 同 ID 顺序结果，反压时整包保持。`bad=1` 时码为 0。 |

正常样本在 E0 握手，E22 后输出有效，未反压的稳态请求间隔最短 13 拍。标记为 bad 的输入仍按顺序返回。非法物理片号、重复片、非零 dummy 和超窗均不能发布有效数值。两阶段可重叠，在最后一级反压时由输入 ready 反传。外部适配器在提交本核前核对 ADC2 ID 与掩码所属样本。

| 编号 | 验收 |
| :--- | :--- |
| REQ-RECON-01 | 两组独立训练系数逐项装载，所有 `2%/3% × dither OFF/ON` 正弦样本与独立大整数模型逐码一致。 |
| REQ-RECON-02 | 验证 21 物理特征的顺序与采样加法、ADC2 解码、端点以及 20 位有符号输出。报告相对浮点的码差。 |
| REQ-RECON-03 | 验证装载中断、非法字、配置优先、复位和清除、错片号/重复片/dummy、反压稳定及输出顺序。 |
| REQ-RECON-04 | 验证 16 拍一笔可持续受理的功能吞吐与单笔延迟，单独报告集成和物理时序状态。 |

设计为单时钟同步逻辑。整体 `sar20_digital_lms_top` 在 ADC2 握手时释放转换组，并保留两笔在途的 AZ 上下文，让 E22 重构与下一笔重叠。宏须在 N+15 前提交 ADC2 才可维持每 16 拍一笔。功能节拍、SKY130HD 6.25 ns 布线后时序和 180 nm BCD 目标验证分别验收。见 [整体流水合同](../task_integration/LMS_PIPELINE.md)。
