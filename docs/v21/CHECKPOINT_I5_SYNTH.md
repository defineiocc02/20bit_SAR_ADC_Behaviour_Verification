## 下一轮的唯一方向

`I = RND(2^60, G)` 必须换成倒数迭代，否则综合无法收敛。

已证明的等价关系（本轮完成）：

```
floor(2^60/G) + 一次余数修正  ==  RND(2^60, G)
   其中修正 = (2*r >= G) ? +1 : +0，r = 2^60 - q*G
抽样 50000 个合法 G，失配 0
```

所以只要硬件给出**精确的** `floor(2^60/G)` 与余数，RND 就精确。

**但 `rtl/recip_q60.sv` 当前不可用**：它的 TB 实测 3 个 `valid_o` 错误
（握手时序，不是数值），需要先修好才能引用。这是下一轮的第一件事。

可行性判断：
- G 的合法域是 `[16×2^30, 64×2^30]`，只有 49 个不同的 2^30 倍数区间
- 若接受"G 的 22 个低位视为扰动"，可用 LUT + 一次 Newton
- 但方案 §9.3 要求"无法证明差值界时采用精确除法基线"

所以下一轮必须先回答：**倒数方案能否给出精确 floor？**
能 → 换掉除法器，综合可收敛；不能 → 保留精确除法，
但要在 DC 里用 `set_optimize_registers` 或拆流水解决时序，成本更高。
