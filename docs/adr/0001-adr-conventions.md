# 架构决策记录（ADR）

本目录记录**为什么**这样写，而不是**写了什么**。代码说"是什么"；ADR 说
"当时有哪些选择、为什么选了这个、代价是什么、什么条件下应该重开这个决定"。

每一份 ADR 都是**不可变**的：决定变了，就新写一份并把旧的标为
`已取代（Superseded by ADR-XXXX）`，不回头改写历史。

## 何时需要写一份 ADR

满足以下任意一条就要写：

1. **改变了物理口径**（单位系统、极性、参考点、码值 ↔ 电压的换算）。
2. **改变了"谁的数说了算"**（引入或取消一个唯一真相源）。
3. **把一个假设变成机制，或反过来**（例如 KTC 从"已公开"降为
   `RESEARCH_EXTENSION`）。
4. **判据的阈值来源发生变化**（从写死的常数改为解析推导）。
5. **决定了一个**不**做的事**，且这个"不做"会影响别人读结果的方式
   （例如"不实现 bridging 校正"必须写下来，否则 base 行 INL 会被误读）。

## 每份 ADR 必须回答的问题

| 小节 | 要回答的问题 |
|:---|:---|
| 问题 | 现在的做法错在哪？有没有**可复现的数值证据**？ |
| 决定 | 具体改成什么？给出可读的代码或公式。 |
| 后果 | 哪些下游判据会失效？**未闭合**的部分是什么？ |
| 复核方式 | 一条能跑的 `pytest` 或一段能跑的脚本。 |

## 硬性约定

- **引用审计条目必须可定位**（`A01`…`A07`、`F1`…`F10`、`B16`），
  不能写"审计说……"。
- **数值必须有出处**：要么是脚本算出来的，要么是论文/PPT 的页码。
  估着写的数字必须标成 `约` 或 `[假设]`。
- **必须写"未闭合的部分"。** 一份只讲成绩的 ADR 是没有信息量的。
- 代码块里的命令必须**可以原样粘贴执行**。
