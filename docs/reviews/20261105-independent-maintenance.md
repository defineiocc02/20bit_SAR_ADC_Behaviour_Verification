- ISSCC 目标公开的是片外导出系数、片内应用 DAC 权重校正。其他论文的内部逐位测量或重复比较学习，需要各自的观测、强制开关和时序，不能由现有 SVD 拟合的存在推导为已实现。

- LTC2387、ADC358x 和 AD4080 的位宽、接口、延迟及滤波条件分别使用。传输扰码器与 DEM 物理单元重排也属于不同对象。

## 命名、注释和维护方式

[工程标准](../ENGINEERING_STANDARDS.md)明确输入输出单位、数组形状、码制、定点格式、复位、同沿优先级、异常及来源等级。公共字段、RTL 端口、寄存器地址和向量格式保持兼容。数学局部符号在定义清楚时保留，不以批量改长名字代替工程质量。

41 个 RTL 模块的头部和必要注释已统一。39 个模块仅有注释变更，并以非注释 token、预处理指令和语义 pragma 对照确认；功能差异限定于上述 CNV 与 SPI 模块。Python 清理过期、口语化和误导性的合同说明，数值改变单独登记。

来源门禁还新增错误来源 ID、错误验证枚举、路径越界、测试符号前缀混淆及 RTL 合同字段的反向测试。静态引用 PASS 不代表对应测试被执行，也不代表原文语义、模拟电路或物理性能通过。
