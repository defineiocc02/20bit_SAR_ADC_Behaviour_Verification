# 边沿字适配的装配约定

```text
并行结果提交端                      DIO 软接口                           实际 PHY
sample[19:0] + 帧身份 ──> ad4080_ddr_edge_words ──> DA/DB 两组边沿字 ──> 同笔装载 / DDR 宏 / Pad TX
控制提交端 ────────────> 已生效 lane/check 模式 ──> 每帧有效槽数         ↑ CLK RX、时钟转发、OE
```

`sample` 是位串。DUT 内部一层 `intf_check_i` 选择样本或固定字，再由静态位选和 `dual_lane_i` 选择 DA 出口。DB 只有双 lane 的前五槽有数据。没有时序级，计算延迟来自组合逻辑。映射无需等待上次帧退役，接收宏端锁存帧字或边沿字及其生效模式。接收侧对数据和帧身份设共同接受条件。串化宏若配对的是“上升沿到下一下降沿”，需在宏装载端明确重排该跨周期关系，并用首/末边沿测试关住差一沿的错误。

合格的上游状态顺序建议为 `输出禁用 → 配置提交并确认 → 载入有效字 → 按帧发出 → 本帧完成`。稳定配置下可连续进下一帧。改变接口、lane、CNV 类型或 DCO 设置时采用 `待旧帧完成 → 停止送帧 → 撤销输出使能 → 跨域提交新模式及电源状态 → 模式稳定确认 → 从下一新帧复起`。重新开始前若 RX/时钟停摆，控制端保持输出禁用并等待域恢复。DUT 的逻辑零输出没有驱动 Pad 高阻和停钟的语义。

外围同沿优先级建议为复位/隔离优先，其次已授予的退役和切换握手，最后才允许新接受。测试检查主张固定字在数据选择器上优先，实际进入和退出检查模式在空闲或明确定义的帧边界提交。跨域策略、握手延迟、停止时钟下复位释放和数据保持按 [IO_PLAN.md](IO_PLAN.md) 冻结。

验证端把输出按时序字符串重组为原字，单 lane 下降后上升，双 lane 每沿先 A 后 B；用模式独立的重组判据核对位串、尾槽与 lane 禁用槽。通用综合及 SAT 的范围是本组合映射；PLL、I/O 宏延迟、CDC/RDC、时钟偏斜、模拟噪声、完整链路吞吐均取决于外围装配和目标工艺模型。
