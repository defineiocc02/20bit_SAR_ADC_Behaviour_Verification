# 怎样装载和更换片上权重

每个物理片有 16 个主单元和 4 个子单元。上电后需要写满 18 片共 **360 个不同地址**，然后用单独一个时钟沿提交。`w_cfg_valid` 拉高后，顶层才能受理第一笔采样。权重的物理单位是 `Ceff/Cf`，以 Q30 存储。装载协议、位宽和范围均由本工程确定。[权重 RTL](../../rtl/sar_core/wsum_v21.sv) · [配置状态图](../algorithms/digital.md#config)

## 1. 外部接口

| 顶层引脚 | 宽度 | 外部如何使用 |
| --- | ---: | --- |
| `w_cfg_we`, `w_cfg_sel` | 各 1 位 | 写使能。`sel=0` 选主表，`sel=1` 选子表。 |
| `w_cfg_sid`, `w_cfg_idx` | 各 5 位 | 物理片号 0…17。主表索引 0…15，子表索引 0…3。 |
| `w_cfg_data` | 40 位 | 无符号权重。以上五个写入字段合计 52 位。 |
| `w_cfg_commit`, `w_cfg_reload` | 各 1 位 | 提交完整表，或开始重装。两者都在上升沿采样。 |
| `w_cfg_valid`, `w_cfg_busy`, `w_cfg_range_err` | 各 1 位 | 已生效；已写至少一个地址且尚未生效；自复位或上次重装以来出现过越界子权重。 |
| `cfg_epoch`, `b_q24_cfg` | 8 位、带符号 27 位 | 分别是外部提供的系数代号和偏置。系统在排空后切换，并在新一批事务期间保持稳定。[顶层接线](../../rtl/sar_core/adc_digital_ip_v21.sv) |

## 2. 状态与受理

| 观察到的状态 | `valid` | `busy` | 对写操作和采样的影响 |
| --- | ---: | ---: | --- |
| 复位或重装后，位图全零 | 0 | 0 | 可写第一字，`prepare_ready=0`。 |
| 已写入至少一个地址，尚未提交 | 0 | 1 | 可写、可覆盖原地址。重复地址只占一位。 |
| 已提交并锁定 | 1 | 0 | 权重保持，写入被忽略。顶层还会检查停收、事务标识和槽位，再受理采样。 |

## 3. 运行中换表

先置 `stop_i=1` 停收新请求，继续为已受理样本提供采样、逐位判决、hold 和 ADC2 返回。外部用 `prepare_valid && prepare_ready` 登记 tag，用 `out_valid/out_tag` 核销；确认全部样本已输出后才脉冲 `w_cfg_reload`。`w_cfg_reload` 直达权重模块，顶层没有单独的排空完成引脚。完成 360 字装载、提交并确认 `w_cfg_valid` 后，再带着新配置恢复受理。[事务交接与排空](../algorithms/digital.md#ownership)

## 4. 复位、写入与提交的同沿优先级

1. **复位或重装。** 复位清除写入位图、锁和范围错误。`reload` 优先于写和 `commit`，效果相同。数据阵列可以保留旧值，下一次生效仍须覆盖全部地址。
2. **提交。** `commit` 检查沿前的 360 位写入位图。最后一个缺字与提交同沿时只写该字，需在下一沿再次提交。写满后提交成功的判据是 `w_cfg_valid=1`。曾出现的范围错误保持到重装或复位；纠正错字并补齐全表后仍可提交。

## 5. 地址与单字数据范围

未锁定且地址合法时检查数据。主权重接受任意 40 位无符号数。子权重上限为 `32 × 4 × 2³⁰ = 137438953472`，边界本身可写。越界数据被丢弃，同时置 `w_cfg_range_err`。非法地址直接丢弃。两种拒收都保留该地址原有的数据和位图状态。

## 6. 每笔重构的算术范围

从同笔实际片号与开关计算 `G/Wm/Wp`。重构入口逐笔要求 `16×2³⁰ ≤ G ≤ 64×2³⁰`、`Wp ≤ 128×2³⁰`、`Wm ≤ G+128×2³⁰`。捕获时随 ADC2 所有者保存的 `epoch` 必须等于重构入口看到的 `cfg_epoch`。越域或代号错配的已受理事务按原 tag 输出 `out_valid=1, out_err=1`。配置无效时，新的 prepare 等待，不建立 tag。[受理门控](../../rtl/sar_core/acq_conv_ctx.sv) · [ADC2 归属](../../rtl/sar_core/adc2_capture.sv) · [定点重构](../../rtl/sar_core/recon_v21.sv)
