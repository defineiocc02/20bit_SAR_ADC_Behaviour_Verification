# 从裸片分区到物理实现

`plan.json` 是规划几何输入。坐标单位为 µm，原点在左下，北对应原图上沿。照片取左上像素坐标。矩形 die 1500 × 1500 µm、Pad 环宽 120 µm，是本项目送审假设。2.25 mm² 来自 ISSCC 原型和原项目 MPW 计划；AD4080 的 5 × 5 mm 是封装尺寸。[手册第 95 页](https://www.analog.com/media/en/technical-documentation/data-sheets/ad4080.pdf#page=95) · [原型论文](https://doi.org/10.1109/ISSCC49657.2024.10454329)

总裸片 2.250000 mm²，Pad 环与四角 0.662400 mm²，环内 1.587600 mm²。各分区合计 1.280657 mm²，独立通道 0.061106 mm²，分散未分配余量 0.245837 mm²。主 SRAM 605×200 µm，外圈及银行间各留 8 µm 后，每个 4096×20 银行最多 290.5×88 µm。实际宏含译码与读写外围，形状和面积须同时通过；四个银行已计入该窗。

## ISSCC 转换区与产品外围的归属

ISSCC 9.8 讲稿第 17 页将低段/高段扰动、SAR 粗码与 DEM 的连接画在 RDAC 前，第 29–31 页给出三维选元。第 40 页 Digital 红框按两轴比例折合约 0.060 mm²，原图提供的是整体功能区轮廓。数字控制的面积、模拟开关阵列的面积、逐算法的门级面积需要不同的证据。后端只向功能组收带自身局部存储与时序约束的同版黑箱。此次物理几何未重新定尺寸，GDS 重新分层以便核对责任。[量测回执](../evidence/isscc_digital_area.json) · [功能归属](../interfaces/function_ownership.csv)

本项目外围的三个有名功能窗口是 CTRL、DIO 与 FIFO，合计 0.183226 mm²。另有 OTP、用途未定的小 SRAM，共预留 0.103140 mm²。合计 0.286366 mm²。芯片公共基础设施、模拟单元和功能组 IP 各自入账。`area_by_scope.csv` 根据统一几何和归属表生成，小计行只用于阅读。[按范围汇总的面积账](area_by_scope.csv)

## 布线与供电通道

| 路径 | 工程措施与验收 |
| --- | --- |
| IP 南沿至 RDAC、量化器和 ADC2 | 原 553 根合束会在前级量化支路遇到 30 根容量而需 31 根。落图后南口寄送 522 根 RDAC 写门/片选，西侧另开 Q_RETURN。该端口与两个相连通道将 31 根双 SADC 预置与判决引到 Q 西边，最窄 24 µm。在两层同向有效层、轨距 0.64 µm、各端保留 2 µm、器件引脚利用率 60% 的算例中可过 36 根。东侧 IO_EAST 通道也已直接接触 DIO 窗。 |
| RDAC 至 RA、RA 至 ADC2 | `RESIDUE`、`RA_ADC2` 是短模拟互连通道。用实际负载、走线和 PEX 核对建立时间。 |
| IP 北沿至结果 SRAM | `SRAM_BUS` 对准银行地址/数据面；功能与 BIST 共用一个受仲裁的 1RW 口。 |
| 参考与采样时钟 | `REF_FEED` 优先给参考去回通路。采样与高速接口时钟单独布树，需联合评估关断沿、偏斜和供电耦合。 |
| VDD11 | 左上较大 LDO 向保持域、结果存储和相应 ADC 低压负载分支供电。阵列和大数字负载的供电回路按实际电流分配，保留模拟域走线。 |
| IOVDD | 左下较小 LDO 通过更外侧 Pad 电源环或独立 PG 层送至上端数字 I/O，避免高速驱动电流穿过 RDAC、RA 和参考区域。x=121…146 µm 的 Q 支路已占用信号层预算；PG 加回流均须从可用信号轨中扣除，不能重复计入。I/O 就地去耦并留接地回路。 |
| VDD33、参考、封装 | 模拟端从模拟侧引入，数字端从数字侧引出。原型若取 QFN-64 且每边 16 Pad，并在两端各留 120 µm，平均可分配 78.75 µm/单元。电源、角单元、ESD、实际 pitch 和键合角度须和封装设计联合核对。 |

现阶段只预留通道。若取 1.1 V 的 1%（11 mV）作为总直流压降算例，32 mA、7.5 mA 的供电加回流等效电阻上限分别为 0.344 Ω、1.47 Ω；封装、焊线和片内金属还需细分。瞬态误差需用频率相关的电源到输入传递函数换算，不能把轨上 mV 直接等同于 ADC 输入 LSB。[手册第 6 页](https://www.analog.com/media/en/technical-documentation/data-sheets/ad4080.pdf#page=6) · [手册第 72 页板级回流指导](https://www.analog.com/media/en/technical-documentation/data-sheets/ad4080.pdf#page=72)

图版第 1 页为工程分区，第 2 页为商品裸片及外围面积，第 3 页并排给出 ISSCC 讲稿第 40 页原型裸片与第 17 页线路。原件与绘图依赖齐备时，从交付根用 `python3 figures/render_floorplan.py --slides "$ADC_FUNCTION_REPO/references/ISSCC2024_SLIDES.pdf"` 复生成。脚本核对讲稿和量测表的文件身份。[芯片规划图](../figures/floorplan.png)

## 交换文件

- 用 KLayout 打开 `chip.gds` 后，从 File → Load Layer Properties 载入 `chip.lyp`；命令行可用 `klayout -l floorplan/chip.lyp floorplan/chip.gds`。
- `chip.gds` 顶层为 `AD4080_AREA_STUDY`，数据库单位 1 nm。规划图层 1 裸片、2 Pad 环、10 转换功能 IP、11 产品外围 CTRL、20 存储、21 银行、22 OTP、30 I/O、31 时钟、40 模拟、41 参考、42 电源或电容、50 行禁放、51 通道、52 端口窗口、90 标签。只看外围五窗时，可打开 11/0、20/0、22/0、30/0，按需要叠加 21/0 的四个银行。21/0 描画 FIFO 窗内的银行，已经计入 20/0。
- `planning.lef` 为尺寸抽象，`chip.def` 保存固定位置、FENCE 与禁放。先载入 LEF 再导入 DEF。正式集成时替换授权 LEF、补 SITE/ROW、轨道、实例归属、实际引脚、PG 和网络；当前窗口不带制造层或物理引脚。
- `area.csv` 是排除重复计数的面积账。从交付根运行 `python3 -B floorplan/build.py` 可复生成。独立检查器从 GDS、LEF、DEF 读回比较。
