A. US10511316B2 — DEM 的关键、与现有源码直接冲突的证据

全文检索词：FIG. 11、S4、not included in sampling、FIG. 14、FIG. 16、FIG. 17、FIG. 19、FIG. 20、shuffler 350、shuffler 352、signal gate 362、reserved column。

  1. Fig.11的主子阵列描述中，主段采用 0–14 号 2C 单元（15个），再有 B4 单元1C和额外 S4 单元1C。S4是被第二组信息控制的物理单元，不是没有数字位就可以删掉的电容。
  2. 该专利实施例的sub-DAC 74不参与输入采样，因此不能在采样期直接给所有sub底板无条件填VIN；需看具体端点与初始电位。
  3. Fig.14/15给出把低权重位用各片 S4 的开关分布表示的例子。具体DS片号/分布属于该示例，不是所有Fig.16/20版本的固定接法。
  4. Fig.16/17是两级shuffle方案：先水平一元编码/打乱主阵列部分列，后纵向结合B4/B5/B6及B3两个2C列、B4和S4两列（不同重量需守恒）。不能把“轮转物理片号”冒充跨边界权重搬移。
  5. Fig.19/20是另一个排列顺序的实施例：350低位shuffle、352主位shuffle；352有用于保留列的常0输入。控制器353与MX开关把350的输出切换到该保留物理列。362是signal gate，可用布尔门/MUX，不是强制大型crossbar。
  6. reserved column的真实功能不是把phase15映射phase0。保留列仍可承载来自其他shuffler的片间信息。
  7. 不能把Fig.14、Fig.17、Fig.20所有控制逐句合并为同一个没有对应原图的编码器。

建议必须跑的代码反例：S4开关指令从0→1时，相同主物理电容的两节点KCL变化；mask和实际C数不一致时必须拒绝；低码下轮转须观察跨片/跨列，而非只看满码。

B. US10505561B2 — Dither Fig.19：位组和数值来源

全文检索词：FIG. 19、A=6、Seven slices、D5、D6、fractional part、subtracted from the digital output、FIG. 20。

  1. Fig.19举六位第一dither字的例子，A可以不等于6。示例七个slice共同采样；低三位 D3、D2、D1 通过设置七片相邻整数电平来产生分数值（例如5/7）。
  2. 第一dither值（全字）参与采样residue DAC；第二值使用D5、D3、D2、D1进入第一量化侧；第三值使用D6和D4，数字上取0、1、4、5之一区间，从第一ADC输出减去以决定RDAC控制。
  3. 剩余的第二值形成后级余差中的残留dither，随后在第二级转换结果中抵消；不能只改前级码后忽略后级数字减扰。
  4. Fig.20给出不同实施例，可省略第一ADC输出的224修正，改为后级一次性处理；这不是与Fig.19等价的器件位置图。
  5. 七片分数4:2:1/7来自该具名例子。论文八片活动RDAC的实际dither分路可按论文指出的两位range扩展进行行为研究，但不得无需证明把分母7写成八片实际DAC物理事实。

建议必须跑的代码反例：至少一个upper/lower都非零的6位dither字；按原图方向和工程坐标方向各自记账；关闭数字去扰时残留、开启后抵消，余差/参考范围可量化。

C. US10516408B2 — Slice Stage / Follower

全文检索词：FIG. 7、FIG. 16、slice、sampling DAC stages may be set bit by bit、31 unit cells、63 unit cells。

  1. 一个slice执行SAR试探，其余相似slice采样相同VIN并组成低噪声残差DAC；残差DAC根据量化结果进行更新，自身不必重演试探与撤销开关。
  2. 专利给过31或63单元的不同例子，它们是示范的候选DAC几何，不是ISSCC实测芯片必然选用的同一阵列。
  3. 采样slice的RC、开关位置、器件几何及时间偏差很重要；共享ADC时需要明确是否在同一采样边沿更新。

D. US10707889B1 — TRACK预置

关键词：TRACK、interleaving、conversion information、precharge、phase。

建模取向：若使用已知先前量化信息对未来采集RDAC预置，必须证明信息在预置截止时间前已就绪；lookback不是专利给出的普遍固定数值。此专利是独立的工程可选机制，不能从专利存在推断ISSCC芯片已全部实现。

E. US10541702B1 — AUX输入

关键词：auxiliary input、boost、parasitic、input charge、switch node。

建模取向：辅助路径必须连接到明确的寄生电容或开关相关节点、产生实际电荷转移；不能只输出“输入电流下降x倍”的数字后处理。芯片是否使用该具体实例需单独由ISSCC资料验证。
