# 倒数替换可行性：算法层已验证，RTL 层未完成

时间：2026-11-16　基线：`42e4bf7`
对象：`I = RND(2^60, G)` 的除法器替换（选项 A）

## 1. 为什么做这件事

`docs/v21/CHECKPOINT_I5_SYNTH_v4.md` 的对照实验证明：

| 版本 | 综合行为 |
|:---|:---|
| 除数可配置（真实） | >10 min 不收敛 |
| 除数换常数 | 秒级完成，4575 cells / 3468 µm² / +17.14 ns |

所以 `I = RND(2^60, G)` 的 64 位除法器是综合不收敛的唯一瓶颈。
本轮验证能否用 `rtl/recip_q60.sv` 的 Newton 倒数精确替代它。

## 2. 本轮先纠正两次自己的复现错误

**这两次都必须记下来，否则结论不可信。**

### 错误 1：把 64 位乘积按 33 位有符号处理

第一版复现算出 `u2 = u0`（Newton 没收敛），误差达 `-520224`。
原因是我对 `m*u0` 这个 60 位乘积套用了 33 位掩码，
把有效数据截掉了。RTL 里 `p1` 是 `signed [63:0]`，
只有 `e1` 才是 `signed [32:0]`。

修正后 `u2 = 2^30 - 4`，`inv` 与精确值差 `-1`，与 RTL 注释吻合。

### 错误 2：以为 `recip_q60` 误差达 1e5 量级

修好复现前，我用错误的脚本得出"误差 `[-54476591, +115871710]`，
只有 49.4% 正确"，并据此写了"不能用于精确 RND"。
**该结论是错的**，源于错误 1。

修正后真实误差分布（50013 个样本）：

```
-1: 107
 0: 48989
+1: 917
超出 ±1: 0
```

与 `recip_q60.sv` 注释"最多差 1 个最低位"一致。

## 3. 算法层结论：可精确修正

`tools/check_recip_correction.py`（从 RTL 原地抽取 LUT，不手抄）：

```
样本数: 50013（合同域 [2^34, 2^36]）
1. 原始近似倒数误差: {-1: 107, 0: 48989, +1: 917}，超出 ±1 的 0 个
2. 余数修正后与精确 RND(2^60,G) 的失配: 0

RESULT: RECIP_CORRECTION_EXACT
```

**修正方法**：

```
u = recip_q60(G)                     # 误差 ∈ {-1, 0, +1}
q = u
while q*G > 2^60:      q -= 1        # 向下夹逼
while (q+1)*G <= 2^60: q += 1        # 向上夹逼
r = 2^60 - q*G
I = q + (2*r >= G ? 1 : 0)           # 按 §9.3 做最近舍入
```

即"近似商 + 用真实 G 算余数 + 一步修正 + 最近舍入"。
这与方案 §9.3 提出的路径一致："若近似商与精确商只差至多 1，
就可以研究用真实 G 计算余数、修正商，再做最近舍入"。

## 4. 这条结论的边界（严格区分）

**证明了**：
- 算法层：给定 `recip_q60` 的输出，修正后与 `RND(2^60,G)` 逐点一致
- 误差界：`|u - floor(2^60/G)| <= 1`，在 50013 个合同域样本上无例外

**没有证明**：
- **RTL 层**：`recip_q60.sv` 的 RTL 是否与该 Python 模型逐位一致 ——
  尚未做门级或形式化对拍。`tb_recip_q60.sv` 目前有 3 个 `valid_o`
  握手错误未定位，不能作为该证据
- **修正逻辑的 RTL**：上面的 `while` 循环是行为描述，
  硬件要实现成"比较器 + 一次加减"，需要重新验证
- **PPA**：修正后是否真的比除法器小、时序是否收敛 ——
  必须在同库同约束下综合对比，本轮没有做

所以现在的状态是：**算法可行，RTL 未实现，PPA 未测**。
不能据此说"已经可以替换除法器"。

## 5. 修正逻辑的硬件代价（初步估算，未实测）

`while` 循环在硬件里是两次比较 + 两个条件加减：

| 操作 | 位宽 | 说明 |
|:---|:---|:---|
| `q*G` | 27×36 = 63 位乘法 | 与 `e1` 那级类似，不是 64/64 除法 |
| 比较 `q*G` vs `2^60` | 63 位比较 | |
| `q±1` | 27 位 | |
| `r = 2^60 - q*G` | 63 位减法 | |
| `2r >= G` | 64 位比较 | 最近舍入判据 |

关键：**没有除法器**，只有乘法 + 比较。这是它可能收敛的原因。
但 27×36 乘法在 25 ns 内是否够快、面积是否更小，必须实测定论。
