# ADR 0020 — 共用采样 dither 列归约，减少校准组合算术

- 日期：2026-09-30
- 状态：RTL 已实现；有限仿真等价及集成回归分别记录，映射后的 PPA 尚待同约束比较
- 前置：ADR 0014、0018；保持端口、定点格式、16 相位与重构延迟
- 修改范围：`rtl/core/cal_weight_reduce.sv` 内部组合结构

## 问题

旧结构对所有物理单元分别归约 `total`、`gain`、`on_sum`，并对采样 dither 单元
逐个选择正负后归约。默认几何是 18 个物理 slice、每 slice 71 个单位，其中
4 个单位可作采样 dither。相同物理列的 `dither_rail[j]` 被所有 slice 共用，
因此 72 次条件取负并非必要。

不能根据源码中三棵树就声称硬件中存在三套完全独立的加法器。`total` 和 `gain`
的无 dither 子树相同，综合工具能够共享；声明为 64/66 bit 也不代表每个加法器
最终保留全部位。本决策只对明确可消除的重复算术作结构变换。

## 决策与算式

沿用物理行 `active[s]` 及开关掩码的映射。令 `D` 为实际落在单位数组内的
采样 dither 单元索引集合，`r[j]=2*dither_rail[j]-1`：

```text
C[j]  = Σ_s active[s] * W[s,j]           （每个 dither 物理列合计）
M     = Σ_{j∈D} C[j]                    （所有采样 dither 权重合计）
total = Σ_s Σ_u active[s] * W[s,u]       （沿用原树）
on    = Σ_s Σ_u physical_on[s,u] * active[s] * W[s,u] （沿用原树）
gain  = sampling_mask_en ? total - M : total
Wr    = sampling_mask_en ? Σ_{j∈D} r[j] * C[j] : 0
rails = total - 2*on + Wr
```

列求和直接引用原物理叶子的 `extended` 线网，避免建立另一份权重选择逻辑。
只在列和上选择正负，因此默认条件取负从 72 处变为 4 处。`M` 同时用于
`gain`，取消原先独立传播采样掩码的 gain 子树。没有新增寄存器、周期、配置状态，
没有缩窄系数或乘法，也没有改变除法器参数。

## 等价与位宽证明

1. 同一列的 `r[j]` 与 slice 无关，因此整数分配律给出
   `Σ_s r[j]*W[s,j] = r[j]*Σ_s W[s,j]`。如果以后把端口改成逐 slice 独立
   dither 轨，此变换必须重新审查，不能直接沿用。
2. 非 dither 权重和等于全部权重和减去 dither 权重和，故新 `gain` 等于旧式。
3. 端口权重按无符号整数解释。原守卫要求
   `SUM_BITS >= W_BITS + ceil(log2(P_N_SLICES * N_U))`，于是全部物理权重之和
   严格小于 `2^SUM_BITS`。列和与 `M` 都是其子集，且 `0 <= M <= total`，
   因而中间加法不回绕、`total-M` 不借位。这个证明覆盖任意 48-bit 输入位型，
   包括配置写入器本来拒绝的最高位为 1 的位型。
4. `|Wr| <= M <= total < 2^SUM_BITS`，
   `|rails| <= total+M < 2^(SUM_BITS+1)`；`W_RAIL=SUM_BITS+2` 的有符号位宽
   足够容纳每次取负、归约及最终 rails。
5. 越界 slice 和重复 slice 的判定保持原样；物理行选择仍只按 `active` 合并，
   逻辑位重复时的开关掩码仍按原规则 OR。即使输入非法，新旧数据项及错误标志也相同。
   `P_DIT_END > N_U` 时越过数组的列贡献为零，保持旧模块对部分相交掩码的计算与报错。

这改变实现结构，不改变 ADR 0014 的输出算式、溢出边界或每样本 flags。

## 源级算术计数与 PPA 边界

以下计数模型先删除补零子树的加法，再共享 `total/gain` 完全相同的子表达式；
只比较这次修改影响的区域，默认参数为 18×71、末尾 4 个 dither 单元。

| 项目 | 旧结构 | 新结构 |
|---|---:|---:|
| 除去与 total 相同子树后的 gain 加法 | 178 | 0 |
| 旧式 dither 归约加法 | 71 | 0 |
| dither 列和加法 | 0 | 4×17 = 68 |
| M 归约加法 | 0 | 3 |
| 列和取符号后的 Wr 归约加法 | 0 | 3 |
| gain 最终减法 | 0 | 1 |
| 上述二元加/减表达式总数 | 249 | 75 |
| 条件取负表达式 | 72 | 4 |

该模型减少 174 个二元加/减表达式、68 个条件取负表达式。**这些是可复核的
表达式计数，既不是标准单元数量，也不是面积、功耗、频率的百分比。** 工具可能在
旧结构中进行更深的代数化简，也可能对新结构使用不同的资源共享和进位实现。

新 gain 从原并行树改为 `total-M`，会在该支路增加一次最终减法。原 rails 的
`total-2*on+Wr` 路径保持原式，但扇出、布线与实际关键路径仍可能改变。因此不能
仅靠逻辑层数声明时序更快。必须用相同器件/库、工具版本、顶层、参数、输入输出
约束与时钟约束分别综合旧/新 RTL，比较完整资源表及最差路径；功耗比较还需要
相同活动率或同一输入轨迹的开关活动。Vivado 结果只证明该 FPGA 映射结果，
不能直接作为目标 ASIC 面积或 640 MHz 收敛结论。

## 验证入口

`sim/tb/cal_weight_reduce_ppa_tb.sv` 内嵌提交
`2de928066508e2cfd009df3e7c6b2936bec6837c` 的旧 reducer 作为 reference，
比较 total、gain、rails、invalid_slice 全部输出：

- 生产几何全部 43,758 个无序 8-of-18 集合，交叉全部 16 种轨模式和两种采样模式；
- 每个逻辑 slot 的所有 32 个地址编码，包含重复和越界地址，并交叉全部轨模式；
- 零、1、最大合法权重、负数编码位型、全 1 与交错位型，且覆盖全开/全关开关；
- 固定种子的随机合法 slice 排列、非法地址、开关掩码与全位宽权重；
- 1/32 个 slice、1/32 个 active、128 个单位、单叶归约、跨主子阵列及越界掩码参数。

这是有限仿真 miter，不是对全部时序状态的形式证明。生产模块仍需通过现有
`calibration_physical_tb`、`calibration_recovery_tb`、`calibration_fit_tb`、
`p2_oracle_tb` 和顶层协议回归，确认本次组合变换未改变系统采样、校准和 flags。

## 本轮不采用的改动

- `weight_store` 的 18×71 系数被并行读取。仅将寄存器声明改成 RAM 不会自动获得
  单/双端口 SRAM 的面积优势；真正串行化还会改变调度与读取带宽，需另行设计。
- `cal_residue_mac` 的 130-bit 中间结果不等于一个 130×130 硬件乘法器。
  实际有效操作数、常量高位、溢出检查和映射后的乘法结构需从综合网表确认。
  本轮保留完整有符号注入域及合法极端的溢出分类，不以直接截位换面积。
