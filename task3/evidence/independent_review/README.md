# CAAZ 配对前的 dither 绑定复核

使用归档的 3% 固定失配、Fig.21 DEM 和冻结 Q28 LMS 数据。4,096 笔原始转换组成 2,048 对，2,014 对的 dither 字不同，相邻两笔选中的八片均互斥。正确路径按同笔物理片号和转换位图重构，并扣除同笔采样子阵列位图，再用偶减奇配对。重打包的 4,096 笔事务和系数配置与 Verilator 夹具的 SHA-256 一致。重构码及配对码也逐笔等于归档数组。

负对照只把奇笔用于数字去扰的采样子掩码替换为上一偶笔的掩码。ADC2 码、物理片号及转换位图保留为奇笔原值。这是故意注入的绑定错误，当前 RTL 使用同笔掩码。

| 逐笔去扰用的掩码 | 配对后去直流 RMS | 配对后绝对峰值 | 重构拒样 |
| :--- | ---: | ---: | ---: |
| 正确样本 ID | 11.81 µV | 35.95 µV | 0 |
| 奇笔误用上一偶笔掩码 | 29.995 mV | 70.887 mV | 0 |

两组使用同一批合格的 ADC2 码。误配改变 2,014 对输出，即使没有越界拒样也会产生上述误差。去扰的归属由样本 ID 决定，CAAZ 的 AZ 代号只用于验证相邻两笔共用哪次自归零。

归档夹具的 +80 µV 是在输入换相之后、SADC 粗量化之前加入的人工偏移。去掉该激励后，4,096 笔中有 12 笔粗码改变，每笔最多差一个粗码。它验证该激励下的数字抵消，RA 的 CBIAS 噪声需要在残差量化前独立建模。
