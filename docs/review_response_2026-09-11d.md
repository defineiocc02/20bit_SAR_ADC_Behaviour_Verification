## 2. 逐条核验（关键条目的自测数字）

### D1 — 节点方程闭合

带 1e-3 失配虚拟芯片（`build_split_chip(Config(mismatch_enable=True, mismatch_sigma0=1e-3))`），
4096 组随机 (k_m ∈ [0,64), k_s ∈ [0,8), x ∈ ±v_fs)：

- 节点矩阵解 vs 闭式解（折电压）：最大 **7.946e-14 V**，中位 4.97e-15 V；
- 理想芯片：最大 5.959e-14 V。

与复核报的 5.7e-14 V 同量级（随机实现不同，数字不期望相同）。结论一致：
**该相位假设下代数闭合，fV 级**。它证明的是理想节点模型本身，不是物理 slice
接线（那是 D6）。

### D5 — DEM 排列空间（本轮最重要的一条）

独立枚举 512 个 sid（无随机性，可精确复现）：

| 量 | 自测值 |
|:---|:---|
| 输入 sid 标签数 | 512 |
| 不同联合排列 (r_m, r_s) | **64** |
| 联合排列周期 | **64** |
| 每个主排列对应的子排列数 | **1**（全部） |
| 主排列个数 / 子排列个数 | 64 / 8 |
| lcm(64, 8) | 64 |

结构原因：331 与 64 互素、173 与 8 互素，两个旋转各自都是满周期的，但**联合**
周期是 lcm 而非乘积。`mapper.N_DEM_STATES = 8·8·8 = 512` 这个名字邀请读者把
数字状态计数当成三维 DEM 多样性——标签数 ≠ 物理排列数。裁定为**passing 钉子**
而非 xfail：选真实三维机制（8/18 选择 + 横/纵洗牌 + binary-to-unary bridging）
是会移动已发布数值的架构决策；钉子保证这个数字不能悄悄漂移，也保证本仓库任何
DEM 扫描结果不会被引用为论文三维机制的收益。

### D8 — τ 拓扑

复核的星形网络公式 `τ_common = (N·R_s + R_on)·C_slice = R_s·C_total + R_on·C_slice`
代数恒等（自验）。数值（N=8, C_total=20.5 pF, R_s=30 Ω, R_on=20 Ω）：

| 口径 | 自测值 |
|:---|:---|
| 聚合式 (R_s+R_on)·C_total | 1.025 ns |
| 星形公共模式 | **0.666 ns**（仅 1.54×，不是 8×） |
| 全部按单 slice | 0.128 ns |

原表述"本口径偏保守，不偏乐观"在 R_s 主导时**失效**。已改写为精确表述并钉住算术。
**加限定**：若 R_on·C_slice 项主导（支路开关远慢于源阻抗），"~8 倍、偏保守"仍然
成立——复核没有否认这一点，裁定按限定记。

### D16/F1 — κ_opt 的内部不一致（Found while verifying，比复核更进一步）

复核 §11 给出含观测噪声的最优系数公式。**顺着这条指控核仓库代码时发现**：
`noise_phase.kappa_optimal` 返回 `aᵀΣb / bᵀΣb`——只最小化**采样噪声残余**；
而同一模块的 `sigma_res_analytic(st, κ, σ_eN)` 报告的总量含 `κ²·σ_eN²`。
**最小化一个目标、报告另一个目标**——两者在 σ_eN = 0 时一致，σ_eN > 0 时矛盾。
这正是复核"最深地消掉原采样噪声，不一定等于最小的最终总噪声"的代码级实锤，
且是复核没有点名（只给了正确公式）的内部缺陷。

**修复**：`kappa_optimal(st, sigma_eN=0.0)` —— 新可选参数，默认 0 保持历史行为；
`σ_eN > 0` 时返回联合最优 `aᵀΣb / (bᵀΣb + σ_eN²)`，与 `sigma_res_analytic`
口径一致。数值验证：对 4 个 σ_eN 取值，κ* 处的总残差 ≤ 2001 点网格最小值（容差
1e-12）；且 κ*(σ_eN) 单调向 0 收缩。生产调用点仅 `experiments.py:2797`
（默认参数），**参考输出不受影响**。

### D14/D4 等算术条目

以下全部自算吻合，不逐条展开：0.15/32 = 4.6875 mV；2π·5 MHz·3 V·50 ps =
4.7124 mV（且与仓库 stage19 正文 4.69 mV 同源）；Δ2 = 109.86 µV、步长
Δ2/32 = 3.433 µV、σ_q2,in = 0.991 µV；8.8 nV/√Hz·√20 MHz = 39.35 µV →
94.63 dB；Δt = 97.66 ps、建立 0.1% 需 f_BW ≥ 11.26 GHz；40e6/32768 = 1220.7 Hz。
仓库 `config.py` 注释中"折回输入 3.43 µV = 0.6 LSB20"是**步长对步长**的比较，
未把步长当 RMS——复核的提醒在此处不构成实际错误。

   这是 model_scope §4.9 / audit A06 登记的最大缺口，未变。
4. **tracking / 辅助输入**（D7/D9）：主链路无对应端口与电荷结算，model_scope
   §4.12 已声明"不能据此选型"。
