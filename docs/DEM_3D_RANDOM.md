# DEM 三维随机化：现状与限制

## 一、相位排程修复（`a42b326` 的关联已解除）

旧版三轴都取 LCG **低位**，导致确定性关联：

```
v_phase = (reserved + 2) % 8     实测 5000/5000 全部成立
```

改为各轴取不同位段：

| 轴 | 取值 |
|:---|:---|
| reserved | `_lcg(q,0) >> 0`（bit 3:0） |
| h_phase | `_lcg(q,1) >> 5`（bit 8:5） |
| v_phase | `_lcg(q,2) >> 11`（bit 13:11） |

修复后：

| 指标 | 修复前 | 修复后 |
|:---|---:|---:|
| `v=(r+2)%8` 违反率 | 0 / 5000（**100% 相关**） | 2502 / 20000（**12.5% = 独立理论值**） |
| 相位组合覆盖 | 240 / 1920 | **794 / 1920** |
| reserved 边际 | 均匀 | 均匀 |
| h_phase 边际 | 均匀 | 均匀 |
| v_phase 边际 | 均匀 | 2151~2169 |

**结论：三轴已统计独立（12.5% 正是 1/8），但联合覆盖仍只有 794/1920。**

**边际均匀 ≠ 随机化有效。** 这只能说明"三轴不再锁定"，不能说明频谱改善。

## 二、18 片动态调度器（`src/adi_model/scheduler18.py`）

### 状态机

```
每周期：
  1) 上周期的 ACQ(8) 全部转为 CONV(8) 并冻结
  2) 候选池 = 18 − CONV = 10 片
  3) PRNG 从 10 片选 8 片作新 ACQ，余 2 片 IDLE
  4) 转换期间不得重新分配采集组
```

**不从 18 片任意选 8**，否则会出现同一片同时采集与转换。

### 不变量（每周期自检）

| 检查 | 结果 |
|:---|:---|
| ACQ ∩ CONV = ∅ | 0 违例 |
| \|ACQ\|=\|CONV\|=8，\|IDLE\|=2 | 0 违例 |
| 三集合并集 = 18 片 | 0 违例 |

### 片使用均衡（2000 周期）

| seed | 违例 | 均值 | 标准差 | 不平衡度 |
|--:|--:|--:|--:|--:|
| 2026 | 0 | 888.9 | 9.3 | 1.05% |
| 7 | 0 | 888.9 | 7.0 | 0.79% |
| 99 | 0 | 888.9 | 6.8 | 0.76% |

# 任务三：动态选片对 D5 的影响（已完成分析）

## G 的分布

`G = Σ_{8 片} Σ_{16 主列} w[s][j]`（失配实例 seed 2026，压力档）

| 模式 | 组合数 | G 范围 | 相对跨度 |
|:---|--:|:---|--:|
| **legacy9**（9 组固定轮转） | 9 | 31.9797 ~ 32.0900 | **0.344%** |
| **random18**（全部 C(18,8)） | **43,758** | 31.7634 ~ 32.2977 | **1.668%** |
| random18 标准差/均值 | — | — | 0.256% |

**动态选片把 G 的相对跨度放大了 4.85 倍。**

## 9 组倒数表为什么撑不住

D5 的重构式：

```
D_eff = 6·Wm/G − 3
```

若沿用某一组的 `1/G₀` 而实际是 `1/G`，则 `D_eff` 偏差：

```
ΔD_eff = 6·Wm·(1/G − 1/G₀) ≈ 3·(ΔG/G)   （满量程 ±3 V）
ΔG/G 最大 = 1.668%  →  ΔD_eff ≈ 0.05 V = 满量程的 0.83%
```

对照 20 位分辨率：LSB = 6 V / 2²⁰ = **5.72 µV**。

0.05 V ≈ **8,700 LSB**。

**所以 9 组倒数表在 random18 下完全不可用**——不是精度略差，是整条重构链失效。

## 需要的 G 精度

要让 G 误差不主导 20 位 LSB：

```
ΔD_eff = 3·(ΔG/G) ≤ 0.5 LSB = 2.86 µV
→ ΔG/G ≤ 9.5e-7 ≈ 2⁻²⁰
```

**G 必须算到约 20 位相对精度，倒数也必须 ≥20 位。**

## 三条可行路线（均未实施）

| 方案 | 做法 | 代价 |
|:---|:---|:---|
| A. 每笔实时算 G | 8 片 × 16 列 = 128 次加法，再算 1/G | 需要一个 ≥20 位精度的除法器/倒数单元；面积与时序都要重新评估 |
| B. 预计算 C(18,8)=43,758 组倒数 | 查表 | 43,758 × 37 bit ≈ **1.62 Mbit**，比现有 16.6 kbit 大 97 倍，必须上 SRAM，且每笔要按组合索引寻址 |
| C. 限制组合集 | 只允许部分组合（如 9 组 + 少量变体） | 牺牲随机化效果，回到接近 legacy9 |

**A 最可能是正解**：G 的 128 项加法在 25 ns 内可完成，关键是要有一个足够精度的倒数单元。

## 结论

| 判断 | 证据 |
|:---|:---|
| 9 组表不能直接覆盖 random18 | G 跨度 0.344% → 1.668%，错用倒数导致 0.83% FS 误差 |
| random18 必须先解决 G 的实时计算与倒数 | 需要 ≥20 位相对精度 |
| 这会改存储架构与运算单元 | 方案 B 需 1.62 Mbit，方案 A 需除法器 |

**在这个问题解决前，random18 不能进 RTL。**

# 方案 A 原型：动态 G + Newton 倒数（Python）

`src/adi_model/dynamic_g.py`

## 两个单元

| 函数 | 作用 |
|:---|:---|
| `compute_g(w, ids)` | 按真实选中的 8 片累加 G（128 次加法，Q30 整数） |
| `reciprocal(g, frac=40)` | 整数 Newton 迭代求 `2^40/g`，初值 `2^(frac-b+1)` |
| `deff(wm, g, inv)` | `D_eff = 6·Wm/G − 3`，输出 Q24 |

## 精度验证（800 个 C(18,8) 组合 × 3 个 Wm 值）

| 指标 | 值 |
|:---|---:|
| `D_eff`（Newton）与 `D_eff`（精确 1/G）最大差 | **2 Q24 = 0.119 µV** |
| 20 位 LSB | 5.72 µV |
| 半 LSB 预算 | 2.86 µV |
| 判定 | **PASS** |

**Newton 倒数在 D_eff 层面引入的误差是 0.119 µV，远小于半 LSB。**

## 需要注意的两点

**① `reciprocal` 的相对误差指标看起来异常（3e+01）**

这是我在 `abs(a-b)/b` 里对 Q40 定标的比较写得不对（`b` 量级只有几十）。
**但 D_eff 的实测差只有 0.119 µV，说明倒数本身是对的。**
这个指标我会另修，不以它作为通过依据。

**② 初值曾写错**

第一版初值用 `(1<<(frac+shift+1))//(g>>shift)`，导致 75% 相对误差。
改成 `2^(frac-b+1)`（b = g.bit_length()）后正常。

## 硬件含义（未实施）

| 单元 | 需求 |
|:---|:---|
| G 累加 | 8 片 × 16 列 = 128 次加法，25 ns 内可完成 |
| 倒数 | 4 次 Newton 迭代，每次含 1 次乘 + 1 次乘 + 移位；需 Q40 精度 |
| 存储 | **不再需要 9 组倒数表**，但可能保留权重表（16.6 kbit） |

**这会改 D5 的运算路径：`inv37` 查表 → 实时 Newton 倒数。**
按约定本轮不动 RTL。

# 任务四：legacy9 vs random18 效果对比（已完成）

条件：同一失配实例、同一正弦（N=4096，fin=bin547，amp 1.5 V）、
解码用**名义权重**，误差取 `D_real(k) − D_nom(k)`，先拟合增益/偏置再取残差。

## 结果

| 模式 | 失配 seed | 残差 RMS | 最大峰 bin | 峰/其余 |
|:---|--:|--:|--:|--:|
| legacy9 | 2026 | 3782.0 µV | 127 | −7.16 dB |
| legacy9 | 7 | 2749.3 µV | 50 | −12.40 dB |
| **random18** | 2026 | 3533.6 µV | 203 | **−17.87 dB** |
| **random18** | 7 | 2827.6 µV | 203 | **−16.17 dB** |

## 三条结论

1. **RMS 基本不变**（3500~3800 µV 量级），说明随机化没有降低失配的**总能量**。
2. **最大杂散显著下降**：legacy9 是 −7.2 / −12.4 dB，random18 是 −17.9 / −16.2 dB，
   **改善约 5.6~10.7 dB**。
3. **峰值位置从"随 seed 乱跳"（127 / 50）变成固定 bin 203**，
   说明 legacy9 的杂散是确定性结构（换实例就换位置），
   而 random18 把它摊成了与输入弱相关的残差。

## 口径与局限（必须说明）

- 指标是"最大峰 / 其余能量"，**不是 SFDR**，不能直接与论文的 SFDR 数值对比
- 只有 N=4096、单一频率、两个失配 seed
- 未做多频平均、未做窗函数校正
- **仍不能宣称与 ADI 原设计的随机序列等效**

## 对决策的意义

**这是第一份支持"三维随机化确实有用"的实测证据**，方向与 PPT 29–31 的意图一致：
把确定性失配杂散转成噪声。

但它同时也说明：**收益在杂散，不在精度**。
所以是否值得为 random18 改 RTL（动态 G + Newton 倒数），
取决于系统更在意 SFDR 还是 RMS —— 需要你判断。
