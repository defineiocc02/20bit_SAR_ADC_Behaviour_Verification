# 当前工程合同

**生产顶层为 adc_digital_ip_v21，ADC2 为 13 位，输入窗口跨度 0.75 V。** 本页是数字接口的阅读入口。查电压、物理单元和重构推导读[物理接口](v21/PHYSICAL_INTERFACE.md)；查开关位序、保护码和哪个沿写入读[开关与事务规则](v21/SWITCHING_RULES.md)；查系数装载与切换读[配置接口](v21/CONFIG_CONTRACT.md)。

| 主题 | 工程口径 |
| --- | --- |
| Python 事务验收 | 包和命令行默认使用 `adc_digital_ip_v21`。固定字、片内字与加载表通过同一条数据通路，逐事件和开关的实际对照见[算法复核](audit/AUDIT_ALGO_VS_SOURCE.md)。 |
| 码域 | SADC 粗码 `c=0…519`，RDAC 命令 `k=c+U`，合法域 `0…520`。普通区用 `k=64H+8V+L`，512–520 使用保护区开关表。 |
| DEM 和桥接 | H、V 各在 0…7，保留列 `(7+h_phase)%8`。仅 `coin=1` 时，按 `v_phase` 和 `half` 交换选定主半单元与八片对应子支路。 |
| 定点权重 | 按同一笔 `pre` 和最终 `post` 计算 `Wp`、`Wm` 和实际 `G`。`Wp` 对置位的子支路加权求和，权重已经包含 `β` 与 `1/Cf`。 |
| 名义电容与增益 | 8 片主阵列共 `512 Cu`，`Cf=16 Cu`，名义 `G=32`。该值用于名义算例，逐笔重构使用实际权重。 |
| ADC2 | `13 bit`，差分窗口 `[-0.1875, +0.5625) V`，跨度 `0.75 V`。Q24 码箱中心为 `Y=-3145728+1536·raw+768`。 |
| 扰动字 | 复位种子 `0xC001D00D`，xorshift32(13,17,5)，每次受理取新状态低六位。生产接 `dither_force_i=0`。强制模式下 `prepare_word/U` 必须一致，强制字也推进一次状态。 |
| SADC 预置 | `sadc_pre_state_o[7*qid +: 7]` 按高位到低位为 `0,D5,0,D3,D2,D1,0`。接受沿后 `sadc_pre_wr_o[qid]` 高一拍，两套 bank 各自保持。普通采样位 1/0 按 B1 的正向差分参考极性解释。 |
| 事务 | qid 从 0 起按接受顺序交替，编号不符或强制 U 矛盾使本次请求 ready=0、err_o=1。启动沿分配转换上下文，普通区分拍接受 Flash 和六次 SAR。可提前提供有效 Flash。若准备码只是占位，本 qid 的真实结果须在采样沿至第一次提交同沿之间返回。 |
| 物理片权交接 | CONV 占用直到释放上升沿。三笔同沿交接时，ACQ 片选、预置数据及写门在沿前仍属旧 ACQ，沿后一起切到新 ACQ。CONV 空闲时允许受理请求提前预置。排空后空槽关闭片选；冷启动保留初始八片预选、写门为零。[端口对照](audit/ISSUE_10.md) |
| 持续采样率 | 目标为每 25 ns 收一笔。现有 25 ns 主时钟下普通事件级至多 5 MS/s。提高理想内部时钟并按规定时刻给出宏响应后，顶层已连续交付 192 笔 40 MS/s 数据。实际宏和物理时序仍待验收。[条件与实测](STATUS.md#持续采样率) |

完整掩码、位序、数据格式及合法域以合同正文为准。v21 配置寄存器与生命周期见[配置合同](v21/CONFIG_CONTRACT.md)，实现和验证范围见 [RTL 导航](../rtl/README.md)和[状态表](STATUS.md)。
