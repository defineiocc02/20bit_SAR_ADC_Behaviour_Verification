# 联合 AZ 噪声的整体 RTL 复演

用同一颗 **3% 固定电容失配**虚拟芯片的四组归档数据驱动 `sar20_digital_lms_top`。各组逐笔核对实际 ADC2 握手、选片顺序、八片采样和转换位图、粗码命令、重构 ID 与有符号 Q28 结果。四组共有 **16,384 笔 20 位重构码**及 **8,192 对 20 位结果**与归档逐码一致，其中 **4,096 对**由 RTL CAAZ 直接发布。每组 ADC2 交接相隔 16 拍，重构握手在其后第 23 拍，最多两笔重构在途。 [噪声模型与归档](../../../task3/evidence/joint_noise/README.md)

| 对照 | RTL 运行模式 | 两笔结果来源 | 对拍计数 |
| :--- | :--- | :--- | ---: |
| 不斩波，独立 AZ | CAAZ 关，逐笔旁路 | 台架对实际旁路输出做 `floor((even+odd+1)/2)` | 4096 笔／2048 对 |
| 仅斩波，独立 AZ | CAAZ 关，外部激励施加斩波 | 台架对实际旁路输出做 `floor((even−odd)/2)` | 4096 笔／2048 对 |
| CAAZ 共享，理想保持 | CAAZ 开，验证宏代理的 ID／极性／AZ 代 | RTL 偶减奇，同时核对完整 21 位差码 | 4096 笔／2048 对 |
| CAAZ 共享，保持受损 | CAAZ 开，验证宏代理的 ID／极性／AZ 代 | RTL 偶减奇，同时核对完整 21 位差码 | 4096 笔／2048 对 |

外接斩波对照使用模拟模型提供的换相信号样本，独立 AZ 两组不向 RTL 申报共享保持。共享两组的确认由测试台在转换 ID 对齐后回送，仅表示模型夹具中执行了对应操作。RA 偏移、独立噪声和 AZ 噪声由行为模型在 ADC2 量化前注入；真实模拟宏的噪声、保持与后仿仍需独立验收。
