# 20-bit SAR ADC design reproduction

This repository implements v21 digital control and reconstruction based on the public ISSCC 2024 9.8 architecture, with a Python model for mechanism studies. The engineering design point is 20-bit output, 40 MS/s and a ±3 V differential input. Actual verification scope and implementation limits are recorded in the project status.
