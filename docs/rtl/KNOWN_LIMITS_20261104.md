# 2026-11-04 RTL 与模型已知限制

本清单保留合并基线 `2cbd359` 及其审计记录，并在结构合同更新后标明已经解决的范围。项目一致性不等于原文公开了唯一晶体管实现。[ADR 0021](../adr/0021-structural-contract-calibration.md) 是当前合同与校准验证入口。

| 项 | 当前证据与影响 | 后续条件 |
|---|---|---|
| Python / RTL bridge mask | 历史全局 bridge 参考与基线 DUT 有 130560/262144 组不同。现以 `sid[8]` 门控的工程候选为合同，真实结构 RTL 与独立参考对全部 262144 组物理掩码一致 | 讲稿的 `P=50%` 没有完整真值表；不能由此声称复现其晶体管电路 |
| 参考切换事件 | 结构对照采用 Flash 前缀加已决位，7 个事件；三种 dither 模式的 10752 个 RTL 事件和 Python 码、相位及样本一致 | 外部真实比较器完成时刻、模拟参考网络及参考电流仍需电路/后仿验证；旧 trial/reject 函数仅供历史假设 |
| 片外校准观测 | 可选 748 位观测口、逐结果模拟异常；静态 plant 的训练/冻结/装载/留出 DUT 闭环已运行 | 无 ready/FIFO/实际传输，40 MS/s 名义调试量 29.92 Gbit/s；外部参考、epoch 对齐、动态误差与实现代价仍需解决 |
| 两点系数方向 | `cal_two_point` 是固定横坐标的仿射拟合。固定输入、测得原始码的常见流程若直接应用该正向系数，指定反例误差由 3100 LSB 增至 6234 LSB | 增加以测得原始码差为分母的逆向估计，完成量化、异常、接口和独立 RTL 闭环验证 |
| 单 lane 串行输出 | 20 次使能/帧、16 时钟/原始样本时，单缓冲会丢码；`bit_en` 恒高时 `dco` 恒高；FIFO 读出未接串行器 | 明确目标数据接口、位时钟/DDR PHY、缓冲和反压，并验证持续吞吐及读出协议 |
| 模拟异常归因 | SAR 新增与结果 ID 对齐的 `dout_analog_bad`；DSP 接入层仍使用独立模拟溢出粘滞位做保守停流 | 按选定输出协议传播逐样本位、滤波窗口和 FIFO 元数据，验证恢复合同 |
| dither 与动态模拟 | 结构对照三种离散模式已对拍；片外有效权重拟合不能分解所有物理误差源 | 双端口 dither 范围增强、真实参考/RA 建立、ADC2 自身非线性与漂移未闭合 |
| 工艺时序与跨域 | 无目标工艺完整库、可核对 SDC、形式 SEC、CDC/RDC 和多角 setup/hold | 在目标环境按相同源、约束、角及工具记录完成各项检查 |

两个**按需运行的反例诊断**如下。退出成功和对应 marker 表示已知限制仍可复现，不表示算法或接口满足产品要求；后续修复改变反例时必须重新裁定。

```bash
python tools/run_open_rtl.py --tops two_point_direction_tb lvds_cadence_tb
```

两点反例只适用于“固定已知输入、变化的测得原始码直接送入当前正向拟合器”这一调用方式；若调用方提供固定未校正码对应的目标码，应按该不同协议另行验证。串行反例使用单 lane、`bit_en` 恒高、12 个相隔 16 时钟的输入，不代表其他速率、双 lane 或真实 DDR 电路已被验证。`bridge_mask_audit_tb` 现在是正向合同测试，参考事件的回归也不再是预期失败。
