# 2026-11-04 RTL 与模型已知限制

本清单针对合并基线 `2cbd359` 及随后模拟异常保护修订。它记录功能限制，
不把测试完成标记当成设计通过；论文和专利有多个实施例，项目一致性问题
也不等于断言原文存在唯一可复现的晶体管实现。

| 项 | 当前证据与影响 | 解除条件 |
|---|---|---|
| Python / RTL bridge mask | 结构 DUT 对项目“全局 bridge”参考，262144 种码/状态中 130560 组物理 mask 不同；等值电容可掩盖差异 | 定义实际物理合同，用非均匀单元权重和独立参考逐状态一致验证 |
| 参考切换事件 | Python 的 trial/reject 序列与结构 DUT 的 Flash 前缀加已决位更新不一致 | 明确事件、rail、电荷、时间，按真实开关序列比较 |
| 两点系数方向 | `cal_two_point` 是固定横坐标的仿射拟合。固定输入、测得原始码的常见流程若直接应用该正向系数，指定反例误差由 3100 LSB 增至 6234 LSB | 增加以测得原始码差为分母的逆向估计，完成量化、异常、接口和独立 RTL 闭环验证 |
| 单 lane 串行输出 | 20 次使能/帧、16 时钟/原始样本时，单缓冲会丢码；`bit_en` 恒高时 `dco` 恒高；FIFO 读出未接串行器 | 明确目标数据接口、位时钟/DDR PHY、缓冲和反压，并验证持续吞吐及读出协议 |
| 模拟异常归因 | 接入层对 SAR 独立模拟溢出粘滞位做保守停流；该位没有逐样本 ID | 在 SAR 重构事务中传递与 sample ID 对齐的模拟异常及恢复合同 |
| 工艺时序与跨域 | 无目标工艺完整库、可核对 SDC、形式 SEC、CDC/RDC 和多角 setup/hold | 在目标环境按相同源、约束、角及工具记录完成各项检查 |

三个**按需运行的反例诊断**如下。退出成功和对应 marker 表示已知限制仍可
复现，不表示算法或接口满足产品要求；如果后续修复改变反例，测试会失败，
要求重新检查并更新此清单。

```bash
python tools/run_open_rtl.py --tops bridge_mask_audit_tb two_point_direction_tb lvds_cadence_tb
```

两点反例只适用于“固定已知输入、变化的测得原始码直接送入当前正向拟合器”
这一调用方式；若调用方能提供固定未校正码对应的目标码，则应按该不同协议
另行验证。串行反例使用单 lane、`bit_en` 恒高、12 个相隔 16 时钟的输入，
不代表其他速率、双 lane 或真实 DDR 电路已被验证。

参考事件差异另由 `tests/regression/test_reference_event_known_limit.py` 以
`xfail(strict=True)` 登记。测试用固定目标粗码 173 的已记录结构 DUT 事件；
若 RTL 事件变化，必须重新采集结构 trace 后更新该合同，不能仅凭此夹具断言
新的 DUT 时序。
