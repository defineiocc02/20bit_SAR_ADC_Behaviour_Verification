# ADC2 余差裕量审计（修正版，物理量口径已纠正）

基线 `26b2aca`。工具 `tools/residue_margin.py`。

## 0. 此前定义错误（已更正）

| 量 | 定义 | 之前是否用对 |
|:---|:---|:---|
| `δ(k)` | `D_real(k) − D_ideal(k)`，失配偏移 | ✅ 测了 |
| `r_ideal` | `x − D_ideal(k)`，9 位粗量化的理想余差 | ❌ 漏了 |
| `r_real` | `x − D_real(k) = r_ideal − δ(k)` | ❌ 之前拿 δ 当余差 |

**真实余差包络 = `[0 − δ_max, 2Δ − δ_min]`，不是 `[δ_min, δ_max]`。**
之前报的 19.775 mV 只是 δ 跨度，**遗漏了前级粗量化本身的 11.72 mV 台阶**。

## 1. 两种失配场景，各逐笔 17280 次实际转换

不再预计算全状态 512 码；每笔只按自己的 `(x, group, phase, k)` 算一次。

### 压力失配（片增益 1% / 主单元 1.5% / 子单元 2.5%）

| 指标 | 值 |
|:---|---:|
| 失配偏移 δ | −11.430 ~ +11.679 mV（跨度 23.109） |
| **真实余差 r** | **−10.039 ~ +22.137 mV（跨度 32.176）** |
| 理论包络 | [−11.679, +23.149] mV（跨度 34.828） |
| 负向溢出 | **2373 笔（13.73%）** |
| 正向溢出 | **964 笔（5.58%）** |
| 有效转换 | **13943 笔（80.69%）** |

### 目标失配（片增益 0.1% / 主单元 0.15% / 子单元 0.25%，**假设值**）

| 指标 | 值 |
|:---|---:|
| 失配偏移 δ | −1.143 ~ +1.168 mV（跨度 2.311） |
| **真实余差 r** | **−0.832 ~ +12.568 mV（跨度 13.400）** |
| 理论包络 | [−1.168, +12.862] mV（跨度 14.029） |
| 负向溢出 | **299 笔（1.73%）** |
| 正向溢出 | **0 笔（0.00%）** |
| 有效转换 | **16981 笔（98.27%）** |

> 「目标失配」的数值是**假设**，论文未公开实际单元匹配水平。
> 本轮只用来演示"失配量级如何影响余差需求"，不能当作论文实际水平。

## 2. 结论

1. **压力失配下，单边窗口只有 80.7% 的有效转换率**，负向溢出 13.7% 是主要来源。
2. **把失配压到 1/10 量级后，有效转换率升到 98.3%，正向溢出为 0**，
   但仍有 1.7% 负向溢出——因为 δ 的负向部分（−1.17 mV）依然落在窗口下界之外。
3. **所以单边窗口即使面对很小的失配也需要一点负向余量**；
   具体需要多少，取决于真实匹配水平，而后者论文未公开。

## 3. 仍然不能说的

- 不能给出"需要几 mV 负向余量"的定论——取决于失配假设
- 不能据此选架构（双极窗口 / 余差平移 / 前级冗余），三项均**未批准**
- 未做多 seed（本轮单一 seed 2026）
- 单频（bin 691），未多频

**能支持的结论**：在现有单边 ADC2 窗口下，
压力失配几乎不可用（80.7%），目标失配接近可用（98.3%）但仍需少量负向余量。
