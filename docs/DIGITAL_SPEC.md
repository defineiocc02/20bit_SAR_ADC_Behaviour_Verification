## 2. D1 调度与样本身份

**输入**：`clk`, `reset_n`, `sample_valid_in`
**输出**：`acq_ids[8]`, `conv_ids[8]`, `spare_ids[2]`, `sample_id`, `ready`

**状态更新**：接受事务 → 分配 `sample_id` → 生成采集组 → 下一周期该组转为转换组 → 采集组前进 8。
**数学**：`acq(k) = {(8k + i) mod 18}`；`conv(k) = acq(k−1)`（因果）`[工程]`。
**异常**：`reset_n=0` 清空在途、`sample_id` 归零；`stall=1` 保持全部状态，只停推进。

**位序**：`physical_slice_id` 为 5 位无符号，合法 `0..17`。
**验收**：相邻窗互斥、每笔 8 个不同 ID、reset/stall 身份不变、整周期使用差 ≤1。

## 3. D2 Follower

**输入**：逐事件已决信息 `{prefix_value, prefix_valid_bits}`，**不是最终粗码**
**输出**：每事件一个 RDAC 命令 `cmd_mask[17]`

**事件**：一笔 7 个事件（3b flash + 6b SAR 累计），`event_index = 0..6` `[工程]`。
**冻结时机**：`sample_id` 接受时冻结物理片归属、DEM 状态、dither 字、系数版本；**事件中只更新前缀**。
**数学**：事件 `i` 的命令只依赖 `prefix[0..i]`。前缀截断不变性：改 `prefix[j], j>i` 不得改命令 `i`。
**异常**：`prefix_valid_bits` 超范围报 `ERR_PREFIX`，不得静默截断。

**验收**：改未来判决 → 过去命令逐位不变；末事件命令 == 该粗码的全 mask；命令实际送入 D3/D5。

## 4. D3 Fig.19–21 DEM

**输入**：`k`（RDAC 控制码，9 位）、`reserved_index`（0..15，controller353 定）、置换状态
**输出**：`m[s][j]`，`s=0..7` 活动片、`j=0..15` 逻辑列

**编码分解** `[推导]`：

```
H = k >> 5        M = (k >> 2) & 7        L = k & 3
h[r] = 0          Σh = H                  Σy = M
m[s][j] = y[s] if j == r else h[j]
```

**恒等式**（数字编码检查，**不等于**物理电荷方程）：

```
Σ_{s,j} m = 8H + M          4·Σ m + L = k
```

**位序**：`h` 16 列，其中 15 个有效 2C 逻辑列 + 1 个固定零位（保留列身份随置换移动）。
**置换**：横向/纵向均用满足控制关系的循环移位 `[工程]`；不引入任意置换网络。
**逻辑列 → 物理开关位**：15 个 2C 对应物理 2C 单元，剩余低位 `L` 进子阵列 4 位；
**`main[17]` 是 17 个物理开关命令，不是 17 个等权单元**（15×2C + B4 1C + S4 1C）。
**补偿项**：无。保留列是预留零位，不从有效数据挖走，故不设补偿。
**异常**：`Σh ≠ H`、`h[r] ≠ 0`、`Σy ≠ M` 任一成立 → `ERR_DEM`。

**验收**：512 码 × 16 保留位 = 8192 组，五条恒等式零违反（已实测）。

## 5. D4 Dither

**输入**：`dither_word[6]`（D6..D1，D6 为 MSB）、`c`（粗码）
**输出**：`upper`(int)、`lower_q`(定点)、`total_q`(定点)、`k`

**数学** `[原文]`（US10505561B2 Fig.19，七片示例）：

```
U = 4·D6 + D4                L = 2·D5 + (4·D3 + 2·D2 + D1)/7
T = U + L                    k = c − U（RDAC 控制码）
```

**身份分离**：`/7` 属**七片专利示例**；八片主工作组采用同一分子 `4:2:1`、分母改为**工程冻结值 8**，
并标注为工程选择——`[工程]`，未证明与硅片等效。
**去扰**：最终输出减去 `ŵ·T`（与重构同一电压坐标、同一增益），只减一次；`U` 不得重复减。
**异常**：`dither_word > 63` → `ERR_DITHER`；`k` 越界 `[0,511]` → `ERR_RANGE` 并置 overflow。

**验收**：64 字全遍历；两路同时非零的实例；去扰后残差 ≤ 声明量化误差界；非法组合报错不夹紧。

## 6. D5 权重重构

**输入**：`y`（ADC2 原码解码）、`m[s][j]`、`a[s][j]`、`t[s][j]`、`w[s][j]`、`b`
**输出**：`x̂`、`code20`、`valid`、`overflow`

**观测关系与反解** `[推导]`：

```
y   = b + Σ_{s∈A,j} w·(a·x + t)
x̂  = (y − b − Σ w·t) / (Σ w·a)
```

**三个符号不可混**：

| 符号 | 含义 | 影响 |
|:---|:---|:---|
| `m` | 转换开关命令 | 决定转换连接与已知项 `t`；`m=0` **不等于**无参考贡献 |
| `a` | 采样信号连接 | 决定输入系数与**分母** |
| `A` | 本笔活动物理片集合 | 决定用哪些物理系数 |

**权重合同**：`w = C_eff/Cf`（无量纲），Q30 小数位；8 片一起求和，**不额外除 8**。
**系数地址**：`w[(slice_id, column)]`，按真实物理 ID 寻址，不按下标。
**加载协议 v1**：只允许在**无在途事务**时更新系数；不做运行中热切换。
**异常**：`Σw·a == 0` → `ERR_NO_SIGNAL`；累加溢出 → `overflow=1` 且输出饱和。

**验收**：名义 512 码全扫；改被用单元系数 → 按参考变化；改未活动片系数 → 输出不变。

## 7. D6 顶层与定点格式

**数据流**：

```
接收事务 → 冻结(片/DEM状态/dither字/系数版本) → 逐事件前缀
        → RDAC 码修正 + DEM mask → ADC2 原码 → 定点重构 + 去扰 → 20 bit + 状态
```

**握手**：`valid_in/ready`、`valid_out/ready_out`；reset 清空在途，stall 保持状态。
**时序**：目标采样率 40 MS/s 与数字时钟分别定义；**未做工艺时序验证前不宣称 40 MS/s 物理实现**。

**定点格式表**（`[工程]`，v1 冻结）：

| 字段 | 总位宽 | 小数位 | 符号 | 范围 | 舍入/溢出 |
|:---|---:|---:|:---|:---|:---|
| 权重 `w` | 32 | 30 | 有 | ±2 | 静态载入 |
| ADC2 解码量 `y` | 32 | 12 | 有 | ±2²⁰ | 静态 |
| 已知项 `t` | 32 | 18 | 有 | ±2¹⁴ | 截断 |
| 偏置 `b` | 32 | 18 | 有 | ±2¹⁴ | 静态 |
| 累加器 | 96 | — | 有 | 由最坏情况定界 | 溢出置标志 |
| 输出码 | 20 | — | 无符号 | 0..2²⁰−1 | 就近舍入 + 饱和 |

**误差归属**（三层分开，不合并成"≤½ LSB20"）：

| 比较 | 判据 |
|:---|:---|
| 无量化前向 vs 反解 | 浮点容限内闭合（已实测 0.0 V） |
| Python 整数参考 vs RTL | **同输入同系数逐位一致** |
| 数字输出 vs 连续输入 | 按各级量化规则推导累计界限，不含饱和 |
