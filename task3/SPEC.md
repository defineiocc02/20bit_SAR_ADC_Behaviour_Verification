# 模块三数字合同 v1.0

数字单元 `caaz20_pair` 接受模块二已调度的采样 ID，产生前端换相和 CBIAS 更新／保持意图，验收同笔已重构码并做非重叠配对。源机制见 [Wang 等论文 Fig.5／6](../references/PKU_VLSI2025_C32_1_PAPER.pdf#page=2) 和 [讲稿第 33～34 页](../references/PKU_VLSI2025_C32_1_SLIDES.pdf#page=34)。本工程采用 10 MS/s 原始输入和 5 MS/s 配对输出。

## 接口

所有事务和配置属于 `clk_i` 上升沿。`rst_ni` 同步低有效；系统负责同步复位释放，并在时钟域边界同步控制与整笔数据。仿真和数字物理实现采用一个时钟域。数字后端按共同的 6.25 ns、SKY130HD TT 25 °C／1.80 V 工程条件评估。

| 端口 | 方向、位宽 | 约定 |
| :--- | :--- | :--- |
| `clk_i`, `rst_ni`, `clear_i`, `enable_i`, `caaz_enable_i` | 输入，各 1 | 复位、clear 或总 disable 清空 epoch。首次受理 acquisition 时冻结 CAAZ 模式。 |
| `acq_valid_i`, `acq_sample_id_i` | 输入，1、32 | 来自已受理的采样描述符。epoch 从 ID 0 开始，模 2³² 逐笔递增。 |
| `acq_ctrl_valid_o`, `acq_ctrl_sample_id_o` | 输出，1、32 | 受理沿后发布同笔控制。valid 为事件，字段保持至下次受理或清空。 |
| `acq_chop_neg_o`, `acq_az_capture_o`, `acq_az_hold_o`, `acq_az_pair_id_o` | 输出，1、1、1、31 | 正相全差分直通，偶数 ID 对其 CBIAS 代 capture；奇数 ID 全差分交换，保持前笔同代。关闭时四字段全零。 |
| `raw_valid_i`, `raw_sample_id_i`, `raw_code_i` | 输入，1、32、signed 20 | 已发布采样的同笔结果，按采样 ID 顺序提交，至少晚一沿。`raw_code_i` 是偏移二进制码减 `2^19`，并已完成同笔位权重构、ADC2 合并及去 dither。 |
| `raw_bad_i`, `raw_chop_neg_i`, `raw_az_pair_id_i`, `raw_az_ok_i` | 输入，1、1、31、1 | `raw_bad_i` 包括模拟异常、饱和、补偿不可用。其余字段回报模拟实际换相、AZ 代及捕获／保持资格，CAAZ 关闭时忽略。 |
| `out_valid_o`, `out_code_o`, `out_pair_o` | 输出，1、signed 20、1 | 关闭时逐笔旁路；开启时每个合格奇数 ID 提交一组。与提交沿后的字段同时有效。 |
| `out_sample_id_o`, `out_first_sample_id_o`, `out_az_pair_id_o` | 输出，32、32、31 | pair 标记尾 ID、首 ID、AZ 代；旁路两 ID 相同、AZ 代为 0。 |
| `out_difference_o` | 输出，signed 21 | 开启时为 `even−odd` 的精确差，以半 LSB 解释；旁路保留 `2×raw_code` 的同单位表示。 |
| `fault_o`, `fault_pulse_o`, `fault_code_o` | 输出，1、1、3 | 故障 sticky 至清空，进入时脉冲一拍。编号见下表。 |

## 事务规则

采样和结果可在同沿分别受理不同 ID。上游必须保留已发布的采样控制和 dither 描述符至其模拟采样完成，并在模拟孔径之前留出开关建立时间。返回结果必须先有对应的已发布 ID，暂停期间保持归属。流水中未完成笔数须小于 `2^32`。输入与输出均为脉冲协议，上游负责节流，输出消费者每拍采收。连续脉冲表示每沿各一笔。

| 优先级 | 条件 | 沿后动作 |
| :--- | :--- | :--- |
| 1 | reset、clear 或总 disable | 取消同沿两路事务和未完 pair，清状态，下一 epoch 从 ID 0 开始。 |
| 2 | 已故障 | 两路 valid 为 0，保持首个故障号。 |
| 3 | 模式改变 `1`、采样 ID 跳号 `2`、结果 ID 非预期或未发布 `3`、坏码 `4`、极性不符 `5`、AZ 代或确认不符 `6` | 按表内从左至右优先。首次错误沿取消两路事务并置 fault；上游应停流，清空时同步丢弃未回报的旧 epoch 结果。 |
| 4 | 合法事务 | 受理采样并发布控制，或接收一笔结果。空拍保持计数和 pending 偶数结果。 |

CAAZ 使能时 ID `2n` 请求正相和新 AZ 代 `n`，ID `2n+1` 请求反相并保持代 `n`。capture／hold 是随采样 ID 提前发布的宏控制意图，模拟相位机必须将其按同一 ID 对齐到该样本进入共用 RA 的实际转换时窗，不能将发布脉冲直接当作 CBIAS 开关时钟。即使停顿，当前样本标签也保持。AZ `ok` 必须归属于实际采集或保持该代的结果。多个周期无结果允许继续等待；后续 ID 跳号即报错。关断和模式转换只能在 clear／disable 后开始新的 epoch。

令 `e`、`o` 为居中的合法 20 位整码，`d=e−o` 的范围是 `[-1,048,575,+1,048,575]`，用 21 位有符号数表示。最终码为 `floor(d/2)`，21 位差的算术右移自然落入 `[-524,288,+524,287]`，不需饱和。−0.5 LSB 取 −1；保留 `d` 可无损表达半 LSB。已实现的是码中心对应的 `(even−odd)/2`，20 位再次量化有至多半 LSB 误差。

同一 raw 结果必须使用同笔独立 PRNG 字和 LMS 系数在**斩波后的码域**完成去 dither，再提交本模块。偶奇可以有不同 dither 字。模拟 chopper 须在完整 ADC 输入端，参考极性与采样扰动路由须由模拟宏合同确认。CBIAS 存储共享、保持漏失、宏间真实时序、两相噪声传递系数与抗混叠由模拟和系统验证负责。

## 验收

| 要求 | 证据 |
| :--- | :--- |
| `REQ-CAAZ-01` | 连续与间断采样、重叠返回、控制标签和复位逐拍对拍。 |
| `REQ-CAAZ-02` | 有符号码边界、奇数负差、非重叠配对、旁路逐拍对拍。 |
| `REQ-CAAZ-03` | 六类异常、故障优先级、同沿清空、再启动逐拍对拍。 |
| `REQ-CAAZ-04` | 共用同一输入带宽的理想共享 AZ 样本模型，报告噪声收益与保持误差。 |
| `REQ-CAAZ-05` | 实际宏捕获、保持、换相建立、LMS 与去 dither 联合验证，待模拟宏／系统供数。 |
| `REQ-CAAZ-06` | 综合、约束校验、整顶层布线及抽取后 STA，按项目物理报告单独记录。 |

冻结依据为学生交付树当前用户授权，数字合同由本文件和独立逐拍向量固化。模拟验收参数在整机接口冻结前保留为未闭合。
