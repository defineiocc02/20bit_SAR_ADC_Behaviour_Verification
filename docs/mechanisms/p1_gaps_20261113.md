## 1. 保留列（US10511316B2 FIG.20）→ `control/reserved_column.py`

### 图面计数（300 dpi 原件逐档读出）

| 元件 | 输入 | 输出 |
|:---|:---|:---|
| shuffler **350** | `D6:2x`、`D5:2x`、`D4:4x`、`D3:8x`、**保留:0** | `16x` |
| shuffler **352** | `D2:16x`、`D1:32x`、来自 350 的 `16x` | `8x2` 与 `8x30` |

### 计数自洽（可复算）

* 350 输入权重和 `2+2+4+8+0 = 16` **恰等于**输出 16 ⇒ 标 `0` 的方框**不承载权重**；
* 352 输出 `8×2 + 8×30 = 256 = 8 片 × 32C` ⇒ 正好**一个完整主阵列**。

**结论**：保留列是"16 个槽位里常驻一个哑位"的填充项（16 选 15），不是数据位。
`verify_figure20_counts()` 就是这条自洽性检查——若把 `0` 误读成数据位，输入和会与输出不等，立刻失败。

### 明确未定的

图上只有一个 `0` 方框、**没有编号**，因此"保留位随相位轮转"是本实现的
**工程假设 `ASSUMED_ROTATING`**，不是披露。`reserved_slot_mask()` 的 docstring 已标注。

## 2. AUX 输入（US10541702B1 FIG.1/FIG.2）→ `control/aux_input.py`

### 图面结构

```
V_IN ──[2]──┬──[4]──[6 自举开关]── 采样节点 16 ──[8]──[10]── (后端)
            │
V_IN_AUX ──[2]──[开关 22]── 同一节点
AUX 支路另有：[14 辅助电容] + [18/20 开关]  ——自举/预充
```

**关键结构事实**：AUX 不是第二条独立采样通路，而是**与主输入在采样节点并联的第二个源**；
两者各有一路开关（22），AUX 支路另有自己的辅助电容与复位开关。

### 三条核算不变式（由 `tests/unit/test_aux_input.py` 钉住）

1. 开关 22 断开 ⇒ AUX 源电荷与支路电荷**严格为 0**（不是"很小"）；
2. AUX 与主输入同电位 ⇒ 辅助电容两端无压差 ⇒ **支路搬运电荷为 0**；
3. 复位阶段放掉的电荷**不进信号**，节点净电荷要减去它。

## 6. 本轮对 ADC2 量程的新证据与一次被推翻的推测（2026-11-13 深夜）

### 6.1 新证据：PPT 第 9 页 ">12b AC matching (SADC to RDAC)"

逐字："Matched slice DAC structure **>12b AC matching (SADC to RDAC)**"。
含义：SADC 与 RDAC 的匹配度超过 12 bit，即**两者对同一码的解读差 ≤ 1/4096 满幅
（= 0.125 LSB9）**。

### 6.2 由此得到的定量结论（可复算）

残差的定义是 `residue = x − vd0(k) = 量化误差 + U·Δ`，其中 `U = 4·D6 + D4 ∈ {0,1,4,5}`：

| U | 残差范围 [LSB1] |
|:---:|:---|
| 0 | [−0.5, +0.5] |
| 1 | [−0.5, +1.5] |
| 4 | [−0.5, +4.5] |
| **5** | **[−0.5, +5.5]** |

⇒ **ADC2 必须覆盖 5.5 LSB1 的窗口**。当前窗口 0.45 V 只覆盖 1.24 LSB1（G=32）。
这不是实现选择，是结构性的。

### 6.3 被推翻的推测（记录在案，避免重复）

我曾推测 "`U ∈ {0,1,4,5}` 缺 2,3，说明 D6 是'范围增强使能'、两组互斥，
因此单次只需覆盖 4.5 LSB"。**该推测被推导推翻**：

```
残差 = x − vd0(k) = x − (c − U)·Δ = (x − c·Δ) + U·Δ ≈ 量化误差 + U·Δ
```

U 是**累积**提前量，不是二选一；D6=1 且 D4=1 时残差确实到 5.5 LSB。
相应代码已逐行删除，未留在仓库里。

### 6.4 与 20 bit 目标的自洽性扫描（纯参数运算，不修改任何配置）

要求：① 覆盖 ≥5.5 LSB1；② 二级量化 LSB 折到输入 ≤0.5 LSB20。

| 窗口 | n | G | 覆盖 LSB1 | 二级 LSB [LSB20] | 自洽 |
|:---:|:--:|:--:|:---:|:---:|:---:|
| 0.45 V | 12 | 32 | 1.20 | 0.60 | ✗（现状） |
| 0.75 V | 13 | 32 | 2.00 | 0.50 | ✗ |
| 1.31 V | 14 | 32 | 3.49 | 0.44 | ✗ |
| 2.06 V | 15 | 32 | 5.49 | 0.34 | ✗（差 0.01） |
| 2.25 V | 15 | 32 | 6.00 | 0.37 | **✓** |

结论：要同时满足 dither 幅度与 20 bit，G=32 时窗口需 **≥2.1 V、ADC2 需 ≥15 位**。
而论文/PPT/六份专利**均未给出 ADC2 位数或窗口**，因此该配置属**未定项**，
不写入默认参数——只在 `inference_table()["stage2_capacity_vs_dither"]` 里如实报告缺口。

## 7. 本轮重跑矩阵暴露的三个真实缺陷（2026-11-13）

用新模型跑 `tools/run_p4_ablation.py`（1024 点）得到：

```
A0_ideal         INL= 28.6 LSB20  SNDR=86.13 dB  DR=96.45 dB
A1_mismatch      INL= 56.7 LSB20  SNDR=81.36 dB
A6_dither_in_loop           SNDR=39.44 dB   ← dither 一开就崩
```

理想配置（零失配、零噪声）本应 INL=0、SNDR 接近量化极限，实际不是。逐层定位到三个缺陷：

### 7.1 SADC 阈值与码本不同源（本轮已修）

阈值原本是 `linspace(-v_fs, +v_fs, 513)` 的等距表，而码本是 Fig.11 实测的
（每步 31.9375/512 C）。两者在中间码相差近 **2 个一级 LSB**，于是粗码判决
与 RDAC 电荷不同源。现已改为 `thresholds[:512] = codebook.voltage_v`，
末位补上边界。实测阈值与码本逐点相同、严格递增。

### 7.2 定点重构被 ADC2 饱和拖低（未修，根因已定位）

`x = +1 V` 时 `adc2_code = 4095`（饱和），`fine_v` 被钳在窗口上界，
定点输出 0.769 V 而浮点输出 0.999 V。直接原因：
残差实测 ±0.013 V × G32 = ±0.42 V，超窗口半宽 0.225 V。

### 7.3 采样侧与转换侧的归一化仍有 3% 的差（未修，两条路都有代价）

| 口径 | 值 |
|:---|:---|
| 采样侧 `C_norm`（全列） | 32.9437 C |
| 转换侧 `c_slice`（16 列 + 4 子单元） | 31.9416 C |
| 比例 | **1.0314** |

实测佐证：`x = ±2 V` 时 `q_free/C = ±2.003569`（应 ±2.000000），
偏差 0.0036 正比于输入 —— 这正是 3% 口径差在采样侧的表现。

**两条自洽路线都走不通**：

* 路线 A（都用全列 32.94C）：端点 `v(511) = 2.8166 V`，与论文 "±3V" 矛盾；
* 路线 B（都只用 31.94C）：采样时 S4 与子阵列哑位**实际接信号**
  （`_all_signal` 把它们设为 SIGNAL），排除它们会漏掉真实电荷。

⇒ 这条需要先回答"采样阶段 S4/哑位接什么"，而原件没有给。

### 7.4 本轮的做法

只提交 7.1（有明确原件依据、且 1437 passed 不变）；
7.2/7.3 记录在此，不改代码 —— 它们都是"改一处就会在另一处出现
相等量级偏差"的类型，反复试参数只会得到互相矛盾的中间态。

## 8. 试图修 7.2/7.3 的两次失败尝试（2026-11-13，均已回退）

### 8.1 第一次尝试：只改归一化

把 `charge_from_sampling_connections` 的 `normalization` 从固定的 `c_signal`（全列 32.94C）
改为按连接算的 `input_cap`（31.94C）。

**结果**：增益比从 1.0315 降到 **0.99835**（口径差基本消除），传输函数误差从
0.17 V 量级降到 0.003–0.011 V。**但同时 `adc2_over` 从 41/100 恶化到 100/100**，
残差从 0.0153 V 涨到 0.1034 V，并新增 1 个失败用例（`test_simulate_ordinary_az`）。

诊断：`q_free / C_norm = 0.9017`（应为 1.0）——**`q_free` 与 `normalization` 不同源**。
`q_free` 走 `held_effective_node_charge`，与采样连接无关。

### 8.2 第二次尝试：归一化 + 采样连接一起改

假设"S4 与哑位在采样期接低轨"能让两者同源，同时改 `_all_signal` 与 `normalization`。

**结果**：`q_free/C` 仍是 0.9017（不变）。实测确认：`C_norm` 在两种连接下**完全相同**
（32.944C），因为它取的是固定全列；而 `q_free` 确实随连接变化（2.49e-12 → 2.18e-12）
—— 两者对连接的敏感度不同，改连接不足以让它们对齐。

### 8.3 结论与纪律

当前采样/转换链路上有**三套电容口径**同时存在：

| # | 量 | 值 |
|:--:|:---|:---|
| 1 | `normalization_capacitance_f`（采样侧归一化） | 32.9437 C |
| 2 | `signal_capacitance_f`（转换侧归一化） | 31.9398 C |
| 3 | `nominal_gain` 用的 `c_slice` | 31.9375 C |

要让 #1 与 #2/#3 对齐，必须同时改动 `q_free` 的产生路径（`held_effective_node_charge`）
——那是另一条独立链路，改动面比前两次更大。

**本轮两次尝试都造成了净负面（测试变多、饱和变多），已逐字节回退，未提交。**
在拿到"采样阶段 S4/哑位到底接什么"的原件依据之前，不再尝试这条链。

## 9. 第三轮尝试（2026-11-13）：把 β 统一到 1/17 —— 失败，但缩小了问题范围

### 9.1 已确认的事实（本轮实测）

| 量 | 值 | 说明 |
|:---|:---|:---|
| `q_free / x / 8` | **33.0025 C** | 与失配无关，零失配时同样是 33.0025 |
| 器件 `c_slice`（全列） | **32.9445 C** | `32.0043 + 0.0588×15.9825` |
| 两者差 | **0.058 C** | **不是 β 造成的**（见 9.3）|
| `nominal_beta` | 1/16 = 0.062500 | 名义分母用 ΣB=15C |
| 器件 `beta` | 0.058822 | 器件 ΣB=15.98C（含哑位） |

### 9.2 尝试

把名义 β 的分母改成含哑位的 16C（使 `nominal_beta` 与器件 β 一致，都 ≈1/17）。

**结果**：`nominal_beta` 变成 0.058824、与器件 0.058822 一致 ✓，
但 **`q_free/C` 仍是 1.0018（无改善）**，且码本端点从 3.000 掉到 **2.989**
（因为 `drive(511)` 里的 β 也一起变小），导致 2 个 v1 用例失败。

**判定：净负面，已逐字节回退。**

### 9.3 由此得到的结论

`q_free` 的 33.0025C 与器件 `c_slice` 的 32.9445C 之间的 0.058C 差，
**不是 β 差异**（把 β 改成一致后仍然存在）。它只能来自 `held_node_charge()`
—— `q_free = Σ(Q主 + β·Q子)` 里 `node` 本身的算法。

这把排查范围缩小到**唯一一个函数**：`slice_pool.held_node_charge()`。
下一轮应直接读这个函数的两个返回值（主/子节点电荷）与 `c_slice` 的定义逐项对比，
而不是再动 β 或归一化。

### 9.4 纪律记录

本轮是连续第三次尝试同一处（口径差）失败。三次分别是：
1. 只改 `normalization` → 饱和恶化；
2. `normalization` + 采样连接 → 无改善；
3. 统一 β → 无改善 + 端点回归。

三次都逐字节回退。**在读完 `held_node_charge()` 之前不再动这条链。**

## 10. 口径差的最终定位（2026-11-13，读到 `held_node_charge` 之后）

### 10.1 精确分解（可复算）

零失配、x = 1 V 时：

| 量 | 实测（8 片合计） | 单片 |
|:---|:---:|:---:|
| `Q_main / x` | 256.026 C | **32.003 C** ✓ 与器件 `C_main=32.004` 一致 |
| `Q_sub / x` | 127.921 C | **15.990 C** ✓ 与器件 `C_sub=15.983` 一致 |
| `β`（pool 用的） | — | **1/16 = 0.062499** |
| `q_free / x` | 264.021 C | **33.000 C** |
| 器件 `c_slice` | — | 32.944 C |

`q_free = Q_main + β·Q_sub = 256.026 + 0.0625×127.921 = 264.02` —— 完全对上。

### 10.2 根因：两个 β 并存

| β | 值 | 用在哪 |
|:---|:---:|:---|
| `β_phys = Cb/(Cb + ΣB_含哑位)` | **1/17 = 0.0588** | 器件电容 `c_slice`、`split_capacitance_coefficients` 直接调用 |
| `β_pool = Cb/(Cb + ΣB_可切换)` | **1/16 = 0.0625** | `pool.split_coefficients`（`_switched_sub_units = 4`）→ `q_free`、RA 增益 |

`0.058 C` 的差 = `哑位 1C × (β_phys − β_pool)` 的一阶效应，与实测完全吻合。

**注意历史**：`_switched_sub_units=4` 是我在早前轮次为让 `drive(511) == cn`
（端点闭合）**刻意引入**的。所以这不是"某处写错"，而是**当时为解决端点问题
而引入的口径分叉**，现在以 0.17% 的形式浮到 `q_free` 上。

### 10.3 二元判断（这是唯一剩下的岔路）

```
若哑位**不接** sub 节点（两端接低轨）：
    ΣB = 15C ⇒ β = 1/16 ⇒ β_pool == β_phys ✓ 两处自动一致，q_free 正确
若哑位**接** sub 节点（一端 sub、一端低轨）：
    ΣB = 16C ⇒ β = 1/17 ⇒ 码本端点需重新推导，drive(511) ≠ cn
```

两条互斥，且**决定性信息原件没有给**：子阵列第 5 个单元在原件 FIG.11/19 上
画了（每片 8C/4C/2C/1C/1C 五列），但没有说明第 5 个 1C 接在哪两个节点之间。

### 10.4 本轮不再尝试

前三次尝试均已回退。在 §10.3 的那个二元判断有依据之前，
继续改 β / normalization / 采样连接都只会在这两个错误之间来回跳。

## 11. 新原件证据：FIG.11 第 5 个 C 在**虚线框**内（2026-11-13）

把 `[11]` Sheet 10 of 29 的 FIG.11 子阵列区域放大到 300 dpi 逐个数电容：

* 每片子阵列画了 **5 个电容**：`8C / 4C / 2C / C / C`，**全部上板共接同一条竖线**（并联到 sub 节点）；
* 前 4 个是实线框，**第 5 个 `C` 画在虚线框内**，并与第 4 个并列；
* 左侧另有一个独立的 `C`（桥接电容）接到主阵列节点。

**读法**：虚线在专利图里的常规含义是"可选/未装配的占位"。这与三条独立事实吻合：

1. 该单元**从未被任何码选中**（编码规则图上没给）；
2. 若把它算进 β 分母（ΣB=16C ⇒ β=1/17），与码本/端点闭合要求的 1/16 冲突，
   实测表现为 `q_free/C = 1.0018`（§10.2）；
3. 只算 4 列（ΣB=15C）时 β_phys = β_pool = 1/16，三处同时自洽。

### 11.1 据此做的实现尝试（已回退，未提交）

按"器件只装配 4 列"改：`C_sub` 建 4 列、几何仍用端口宽度 5、采样/转换掩码截到 4 列。

**结果**：`q_free/C` 从 1.0018 变成 **1.00000000**（口径真正对齐 ✓），
但：

* 主链**没有改善**：`adc2_over` 仍 8/20、传输误差仍是 0.17 V 量级
  （说明 0.17% 的口径差不是那 0.17 V 误差的主因）；
* 38 个测试失败（8 个文件里的测试桩直接构造 `SplitChip(C_sub=(18,5))`，假设 5 列）。

**判定**：收益（口径对齐）没有转化为主链改善，代价（38 个测试 + 接口变更）过大。
**已逐字节回退。**

### 11.2 结论

`q_free/C = 1.0018` 是**真实存在但量级很小**（0.17%）的口径差；
把它归零后主链误差不变 ⇒ **A0 理想配置的 966 LSB20 INL 另有主因**，
不是这 0.17%。下一轮应直接测 A0 配置下的 INL 分解（是哪几个码贡献了 966 LSB20），
而不是继续追这条 0.17% 的线。

## 12. 本轮负结论：β 必须为 1/16，这一点由码本律**唯一确定**（2026-11-13）

§10–§11 反复出现"名义 β=1/16、器件 β=1/17"的分歧。本轮把 β=1/17 各处统一后得到：

| 检查 | β=1/17 结果 |
|:---|:---|
| `q_free/C` | **1.00000000** ✓（同源了）|
| 码本端点 | ±3.000000 ✓ |
| **码本步长** | **极差 1.11e-2 = 整 1 个 LSB9** ✗ |

步长异常出现在**每 16 个码**（c=15,31,47…），即主码 `c>>4` 的进位处。

### 12.1 为什么必然如此（可复算）

9 位码 = 主段 5 位（0..31）+ 子阵列 4 位，共 512 码 = **511 个步进**。

```
主段 31 档 × 每档 16 码步 = 496 码步
子阵列满量程             =  15 码步
合计                     = 511 ✓
```

因此**主段每档必须恰好值 16 个码步**；而主阵列 31C 分 31 档 ⇒ **每档 = 1C = 16 码步**
⇒ **每码步长 = 1C/16**，`cn = 512 × 1C/16 = 32C` 的等价量，即
`cn = 31 + β·15` 且要求 `β·15 = 15/16` ⇒ **β = 1/16**。

换 β=1/17 后 `β·15 = 15/17 ≠ 15/16`，子阵列满量程只剩 14.14 码步（应 15），
主段进位处就缺了 `β·15/16` 的贡献 —— 实测步长在 c=15→16 处为 0.1176（应为 0.0625）。

### 12.2 结论

**β = 1/16 是码本律的硬约束，不是可调参数。** 这同时意味着：

* 子阵列的等效电容必须是 **15C**（8+4+2+1），与 MAIN 的 31C 一起使 `cn = 31.9375`；
* 器件 `C_sub` 只应装配 **4 列**（8/4/2/1）——第 5 个 C 是 FIG.11 虚线框里的占位（§11），
  若装配它，物理 β 就变成 1/17，与码本律冲突；
* §10 的"β_phys 应等于 β_pool"这个方向是对的，但**解决办法是让器件的 ΣB=15C**，
  而不是把码本的 β 改成 1/17。

这条与 §11.1 的尝试一致（当时 `C_sub` 改 4 列后 `q_free/C` 确实变成 1.00000000），
但那次的代价是 38 个测试失败（测试桩直接构造 `C_sub=(18,5)`）。
**正确的下一步**是：把测试桩改成按几何构造，再落 `C_sub` 只装 4 列。

## 13. ADC2 位数 12 → 14（依 ADR-0003 修一处参数错配）

### 13.1 错配

ADR-0003 的三读数表里，`paper_literal` 行写的是：

```
| paper_literal | 9 | 1 | 0b | 14 bit，[-0.0375, +0.4125] V |
```

而代码里 `adc2_n_bits = 12` 却沿用了同一个窗口。两者是**被错误组合**的：
窗口与位数在 ADR 里是配套给出的。

### 13.2 后果（可复算）

二级量化 LSB 折到输入 = `窗口 / (2^n · G)`：

| n | LSB 折到输入 | 折到 LSB20 | 是否满足 20 bit（≤0.5） |
|:--:|:---:|:---:|:---:|
| 12 | 3.433 µV | **0.60** | ✗ 单这一项就吃不满 20 bit |
| **14** | 0.858 µV | **0.15** | ✓ |

已改为 14 bit。

### 13.3 但要如实说明：当前看不见收益

修完实测 12b 与 14b 的**定点 RMS 都是 37.1 LSB20**（完全相同）。
原因：

| n | 二级量化 RMS 折到输入 |
|:--:|:---:|
| 12 | **0.2 LSB20** |
| 14 | 0.0 LSB20 |

即 **12 bit 的二级量化噪声本来就远小于当前 37 LSB20 的误差地板**，
所以提高位数不会改善眼前的结果。误差地板由残差链路里的其他因素决定。

**结论**：14 bit 是"与窗口配套的正确参数"，但**不是**让模型达到 20 bit 的手段。
要真正接近 20 bit，需要先把 37 LSB20 的地板压下去；
而一旦压下去，12 bit 就会立刻暴露成瓶颈（0.6 LSB20 > 0.5）。

### 13.4 与 dither 的关系：互不影响

窗口覆盖仍是 **1.238 LSB1**，而 dither 需要 5.50 LSB1。
`parameter_consistency.check_dither_fits_stage2()` 仍返回 `sufficient=False`。
提高位数不改变窗口宽度 ⇒ 这是**两个独立缺陷**：

* 位数不足（本轮已修，依 ADR）；
* 窗口不足以容纳 dither 的 5 码提前量（未修，缺原件依据）。

## 14. 剩余 37 LSB20 误差地板的来源：三方口径不可能同时相等（2026-11-13）

### 14.1 分解（零失配也测过）

| 量 | 值 |
|:---|:---|
| 浮点 `out`（`vd0 + residue`） | **精确**（x=1 时 = 1.00000011） |
| 定点 `code` | 偏 **42.8 LSB20**（x=1 时 = 1.00024509） |
| 残差 vs 理想量化误差 | **零失配时误差精确为 0 LSB20** |

⇒ 误差不在物理模型，在**浮点→定点的换算**。

### 14.2 三个必须相等的量

| 量 | 当前值 |
|:---|:---|
| A. 采样电荷口径 `q_free/C` | 1.00000 |
| B. RA 增益口径 `C_norm/Cf` | **32.9397 C/片** |
| C. 定点权重和 ×Cf/uc | **31.9375 C/片** |

B 与 C 差 **1.0022 C = S4 的 1C**，导致定点输出偏 3.14%（x=1 时 42.8 LSB20）。

### 14.3 为什么三者不可能同时相等（本轮两次尝试证伪）

* 约束 1：`q_free/C = 1.0` 要求 `C_norm` **等于采样电荷的口径**。
* 约束 2：定点分母 = 权重和 = 31.9375C 要求 RA 增益 = 31.9375/Cf。

若 S4 采样时接信号 ⇒ 采样口径 = 32.94C ≠ 31.9375C，约束 1 与 2 冲突。
若 S4 采样时不接信号 ⇒ 采样电荷本身少 1C，`q_free/C` 掉到 **0.906**
（本轮实测），约束 1 自己就破了。

两次尝试分别是：
1. 归一化改 31.94C、连接不变 → `q_free/C = 1.0313`、RMS 恶化到 1258 LSB20；
2. 归一化 + 连接一起改 → `q_free/C = 0.9060`、RMS 1365 LSB20。

两次均逐字节回退。

### 14.4 结论与含义

**S4 必须在"采样电荷"里出现，但绝不能在"权重和"里出现。**
这意味着定点重建的归一口径（权重和）与物理采样口径在设计上**本就不一致**，
需要一个显式的 S4 补偿项 —— 而原件没有给出 S4 的编码规则
（`capacitors.py` 已记录"S4 的编码规则图上未给"）。

⇒ 当前 37 LSB20 的误差地板是**已知且已定位**的，不是神秘噪声。
它要解开，必须先回答"S4 的码是什么"，这与 dither 的 ADC2 窗口一样属于缺原件依据的项。

## 15. 新线索：37 LSB20 地板可能与 RA 增益的**相间差异**同源（2026-11-13）

### 15.1 原件的新一句

PPT 第 11 页（逐字）：

> **Shared residue amplifier**
> 40% of ADC power consumption
> **Matched offset and gain error**
> Shared ADC2

含义：RA 与 ADC2 被 RDAC1/RDAC2 两相**共享**，所以它带来的失调与增益误差
对两相是**同一个**误差（共模）—— 这正是"共享"的代价与收益。

与论文正文"8 sDACs converting + 8 sDACs acquiring"一致：
两相交错，但放大器只有一份。

### 15.2 模型实测：两相增益并不完全相同

```
64 笔的 g_vec：p2p = 9.55e-3  （相对 2.98e-2 %）
两相平均增益：even 31.99959 / odd 32.00194，差 -2.35e-3（-7.3e-3 %）
```

原因：`ra.gain_vector` 逐笔按**实际片电容**算 `G = C_signal/C_feedback`，
而两相选到的片不同（片间失配 1e-3）⇒ 两相增益不同。

### 15.3 量级与已知误差地板吻合

- 相间增益差 7.3e-3 % ⇒ 满幅时 **≈38.5 LSB20**
- 已知未解释的定点误差地板：**≈37 LSB20**（§14）

两个数字同量级，**很可能是同一个现象**：此前记为"三方口径不可能同时相等"的
37 LSB20，可能主要来自"两相选到不同片 ⇒ 增益略不同"，而不是 S4 的归一口径。

### 15.4 判据

新增 `control/reference_buffer.shared_amplifier_error_is_common_mode()`：
给定各相误差，检查是否可视为共模（最大差为 0）。

```python
shared_amplifier_error_is_common_mode(per_phase_error_v=[1e-3, 1e-3])  # True
shared_amplifier_error_is_common_mode(per_phase_error_v=[1e-3, 2e-3])  # False
```

当前模型返回 **False** —— 即模型里的 RA 误差**不是**严格共模。

### 15.5 但这不一定说明模型错了

需要分清两种情形：

| 情形 | 是否符合原件 |
|:---|:---|
| RA 本身的失调/增益误差逐相独立 | ✗ 与 "Shared ... Matched" 冲突 |
| RA 共享，但**各相选到的片**不同，导致等效 C_signal 不同 | ✓ 这是物理事实（片间失配） |

模型当前属于**后一种**：RA 是同一份（同一个 `gain_vector` 公式、同一个 `C_feedback`），
差异来自各相选片的电容和不同。

所以这两条要分开记：
* "RA 误差是否共模" —— 结构层面，模型符合（没有给每相独立的 RA 失调）；
* "两相增益是否数值相同" —— 数值层面，模型不同（因为选片不同）。

**下一步**应把这两者拆成两个字段分别报告，
并用一个受控实验（固定两相选同一组片）验证"差异确实只来自选片"。

## 16. 37 LSB20 地板的**最终定位**：定点增益与 RA 增益不同源（2026-11-13）

§14–§15 我先后把地板归因于"S4 归一口径"和"两相增益差异"。本轮用受控实验逐个排除，
最终定位到**一个具体的比值**。

### 16.1 排除过程（全部可复算）

| 候选原因 | 实测 | 是否主因 |
|:---|:---|:---:|
| 器件失配 | 零失配 RMS 36.9 vs 带失配 37.0 LSB20 | ✗ |
| RA 输出噪声 | 关掉后 RMS 37.4 LSB20 | ✗ |
| ADC2 量化（14 bit） | 折到 x 仅 **0.0 LSB20** | ✗ |
| 权重 Q30 量化 | 相对 1.27e-9 | ✗ |
| `term` 量化 | 误差**精确为 0** | ✗ |
| 最终 word 取整 | 步长 1.00 LSB20 | ✗ |
| **定点增益 vs RA 增益** | **比值 1.0314** | ✅ |

关键对照（零失配、零噪声、x=0）：

```
fine_v / g_vec  = 0.0056791885   ← 等于 residue(实际) = 0.0056789532  ✓
fine_v / G_fixed = 0.0058573933   ← 偏离 1.78e-4 V = 31 LSB20        ✗
其中 G_fixed = 31.028463（8 片权重和），g_vec = 32.002092（RA 物理增益）
比值 g_vec / G_fixed = 1.031379
```

### 16.2 与 §14 的关系

§14 说过"三个口径不可能同时相等"，当时没能指出**到底是哪一处**在起作用。
现在清楚了：**定点重建把 `fine_v` 除以权重和，而 `fine_v` 是 RA 用物理增益产生的**。

* `G_fixed` 对应 **31.9375 C**（= cn，不含 S4）
* `g_vec` 对应 **32.94 C**（采样口径，含 S4）
* 差 = S4 的 1C

### 16.3 为什么它表现为"近乎恒定的偏移"而不是纯增益误差

因为定点式是 `x = (fine − S)/G`，其中 `S` 项（约 −10.26）**比 `fine` 项（约 0.06）
大两个数量级**。`S/G` 精确给出 `vd0`（实测差 2.8e-9），所以误差几乎全部来自
`fine/G` 这一小项 —— 它在 x=0 处最大（相对 residue 的占比最高），
表现为 20–43 LSB20 的近似恒定量。

### 16.4 受控实验：零失配下逐笔完全相同

```
零失配：4 笔输出 = [-2.89980984 ×4]   散布 = 0.0 LSB20
带失配：4 笔散布 ≈ 1e-4 V ≈ 17 LSB20
```

⇒ **逐笔散布**来自"片池轮换 + 片间失配"（这是真实物理）；
**系统性偏移**来自增益不同源（这是口径问题）。两者必须分开记。

### 16.5 已固化的判据

`tests/unit/test_reconstruction_gain_pairing.py`（4 条）：

1. 浮点路径在零失配零噪声下**精确**（基准）；
2. **记录** `g_vec/G_fixed = 1.0314`（若将来对齐，该测试会失败并要求更新文档）；
3. 零失配下逐笔输出**完全相同**（证明散布来自失配而非缺陷）；
4. 定点偏差在零失配零噪声下**仍存在**（证明它是结构性的）。

第 2 条是"故意写成会失败"的断言：它把当前不一致钉住，避免"已经修好却仍写着有 bug"
或"引入回归却没人发现"两种都发生。

### 16.6 结论

37 LSB20 地板**不是未解之谜**，是 `fine_v` 的除数（权重和）与它的产生端（RA 增益）
不同源，差恰好是 S4 的 1C。要修它需要让二者同源，而这就是 §14.3 证明的
"三口径不可能同时相等" —— 仍缺 S4 的编码规则这一条原件信息。

**变化在于**：现在这条阻塞有了唯一且精确的表达式 `ratio = g_vec/G_fixed = 1.0314`，
而不是三个口径互相牵扯的模糊描述。

## 17. 修复：定点重建按物理增益换算 fine（2026-11-13，§16 的收尾）

### 17.1 修改

`FixedPointReconstructor.reconstruct(data, *, physical_gain=None)`：

```python
scale_q = round(G_phys · 2^weight_fraction_bits)
fine_q  = round_even_divide(fine_q · gain, scale_q)   # fine 换算到 Σw 口径
```

pipeline 传 `physical_gain = raw.state.estimated_gain`；缺值时传 `None`
（保持旧行为，**不猜**默认值）。换算全程整数运算，保持确定性。

### 17.2 效果

| 指标 | 修复前 | 修复后 |
|:---|:---:|:---:|
| 定点 RMS（零失配零噪声） | 576 LSB20 | **18.54** |
| 浮点 RMS（同上） | 18.50 | 18.50 |
| 两者之差 | 巨大 | **0.04** |
| x=±2/±1/0 的定点误差 | 数千 µV | **−9.5 ~ −131.6 µV** |
| A0 的 DR | 120.40 dB | **121.88 dB** |

**定点与浮点终于同源**：此前 37 LSB20 的"误差地板"不是物理误差，
而是两条重建路径用了不同的除数。

### 17.3 与 §14–§16 的关系

* §14 说"三个口径不可能同时相等"——它描述的是**参数层面**的事实，
  该事实仍然存在（`g_vec/Σw = 1.0314`，S4 的 1C）；
* §16 把地板精确定位到这个比值；
* §17 **不再试图让三个口径相等**，而是让解码器**显式补偿**这个比值。

这是正确解法：口径差异源于 S4 的编码规则未披露（那是物理事实），
但"用哪把尺子读 fine"是**实现选择**，可以也应该显式统一。

### 17.4 残留

修复后仍有 ~18.5 LSB20 的误差（与浮点一致）。它来自：
* 器件失配（A1 的 INL 60.3 LSB20）；
* ADC2 量化与残差量化；
* 以及 A0 里仍可见的 32.9 LSB20 INL —— 这才是**物理层面**的剩余误差，
与定点/浮点的口径问题无关。

## 19. 动态转换路径的参考电荷缺陷（§18.3 的收尾）

### 19.1 真正原因（不是 §18.3 猜的 dtype）

`physical_reference_program` 的校验失败，实际原因是**子阵列列数不匹配**：

| 量 | 值 |
|:---|:---|
| `sub_on`（按端口位宽） | **(7, 8, 5)** |
| `chip.C_sub[converting]`（装配列数） | **(8, 4)** |

校验要求 `high_s.shape == (len(times), *cs.shape)` ⇒ `(7,8,5) != (7,8,4)` 失败。

这是第 23 轮"子阵列只装配 4 列"改动的**遗漏点**：`dac_arch` 里对掩码做了截断，
但动态转换路径自建 `physical_reference_program` 调用，没有走那条截断。

### 19.2 修法

在调用前把 `sub_on` 截到 `chip.C_sub.shape[-1]`，与 `dac_arch` 的处理一致。

### 19.3 效果

* 图生成恢复，13 张图全部产出；
* **F12（定点 vs 浮点）：RMS 0.29 LSB20、max 0.50 LSB20**
  （此前 36997 / 60716 —— 差 10 万倍）。

### 19.4 错误信息本身也改掉了

原报错把六种原因统一报成
`"reference program needs actual Boolean masks and ordered event times [s]"`，
导致"列数不匹配"也被读成"需要 bool 掩码"，误导了整轮排查。

现在逐项检查并指名：

```
reference program rejected: sub_on shape (7, 8, 5) != expected (7, 8, 4)
```

### 19.5 教训

一类错误信息同时覆盖多种失败原因时，**排查成本会转移到使用者身上**。
本轮为此多花了约十余次探测。凡校验多处条件的函数，报错应指出具体哪一项不满足。

## 20. 重新定性：dither 是**专利的可选增强**，不是论文描述的机制（2026-11-13）

### 20.1 关键证据

对论文 [00] 正文做全文检索：

```
"dither" 出现次数：0
```

而 dither 的机制全部来自专利 **[10] US10505561B2（Dither Method and ADC）**
与 **[10] FIG.19 的 300/222/224 三个加法器**。

### 20.2 由此得到的定性

| 项 | 结论 |
|:---|:---|
| 论文描述的芯片 | ±3 V、20 b、94.2 dB DR —— **未提及 dither** |
| dither | 专利提供的**可选增强手段**，芯片是否启用未披露 |
| 当前默认配置（A0–A5） | **本来就不带 dither** |
| A6 / C2 / C3 | "若启用 dither 会怎样"的**探索配置** |

### 20.3 所以 A6/C2/C3 的 ~4100 LSB20 不构成模型缺陷

它是"**在窗口不足的参数下强行启用 dither**"的必然结果：

* dither 的 U 段让残差从 `[0,1]` 扩到 `[0, 5.5]` LSB1；
* 论文给的窗口 0.45 V 只覆盖 1.24 LSB1；
* 两者不相容 ⇒ 饱和。

**要同时支持 dither，窗口必须 ≥ 2.06 V**（G=32 时 ADC2 还需 ≥15 位）。
而 0.45 V 这个值在论文/PPT/专利里都没有解释，
但从 `0.45 = 1 LSB1·G + 2×0.0375` 看，它明显是为**无 dither 的残差**设计的。

### 20.4 这改变了对"未完成项"的定性

原先记为"dither 一路仍有缺陷"。现在应改为：

> **dither 是专利的可选增强，其幅度与本芯片的 ADC2 窗口不兼容；
> 论文描述的配置不启用 dither，因此默认路径（A0–A5）是完整且自洽的。
> A6/C2/C3 保留为"启用 dither 需要什么条件"的定量记录。**

`parameter_consistency.check_dither_fits_stage2()` 仍返回 `sufficient=False`，
这是**正确**的报告：它指出"当前参数下 dither 装不下"，而不是"模型有 bug"。

### 20.5 本轮的另一处修正：ra_clip_v

ADR-0003 的 paper_literal 行写 `ra_v_clip=0.45`，代码是 `0.5`。已改为 0.45。

`0.45` **恰好等于窗口宽度** `0.4125-(-0.0375)` ⇒ "RA 摆幅 = ADC2 满窗"是一个
有意的设计关系。代码里 0.5 比窗口还大，使 clip 判据形同虚设。
