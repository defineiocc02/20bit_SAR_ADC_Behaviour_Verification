## T1. 电荷一致闭环：同一组物理电容决定三件事

**原理。** RA 的增益不是常数 32，而是逐样本由**当次采样实际用到的那组
物理电容**决定：

```
G[n] = C_active[n] / C_F_true,    C_active[n] = Σ_{u∈S[n]} C_true[u]
```

同一组 `C_active[n]` 同时决定：

1. **采样噪声** kT/C：σ = √(χ·k·T/C_active)，χ=2（差分两侧独立）；
2. **RA 增益** G[n]（上式）；
3. **KTC 观测的逐样本 β**（T7）。

**为什么关键。** 电容失配不再只是"DAC 输出错一点"，而是沿**两条通路**
进入系统：DAC 权重错（静态 INL）+ 增益错（每样本不同的 G 偏差）。
v2 之前固定增益模型里，这两条通路互不相干，失配预算被系统性低估；
v3 改成电荷一致后，"分母 sum_{act} C_true 的偏差 = 满幅增益误差、
DEM 消不掉、必须增益校准"才成为可推出的分水岭结论。

**代码落点**：`rdac.py`（LUT 一次构建、只读）、`ra.py`、`sim.py`
主循环注释"哪个物理量改变了、哪条通路受到影响、哪个指标因此变化"。
**钉子**：stage19 验收①的等价性依赖该口径在 `sim`/`pipeline` 两侧一致。

## T2. 分段 DAC 两浮动节点严格解 + 输入等效统一口径

**原理。** 主/子阵列经桥接电容 C_C 相连，放大相 P 虚地、Q 浮置。
记 A=ΣC_main、B=ΣC_sub、D=C_C+B+C_p_sub：

```
β     = C_C / D                      （子阵列衰减系数）
C_ser = C_C·(B + C_p_sub)/D          （桥接串联等效）
C_eff = A + C_p_main + C_ser
V_top = (S_M + β·S_S) / C_eff        （两浮动节点电荷守恒联立解，非近似）
```

放大相节点方程（`charge_ref.py` 独立推导）：

```
C_F · v_R = (A + β·B)·x − (S_M + β·S_S) = C_sig·x − Q_D
```

**关键的第二步——输入等效口径统一**：残差定义为
`r = x − v_D,in`，其中 `v_D,in = Q_D / C_sig`，而不是顶板口径
`V_top`。两者差 `C_sig/C_eff ≈ 0.9972`，混用曾制造出 **143 mV 的
假性非零残差**——且数字端自洽重构把它掩盖了（"理想重构正确"不能
证明中间节点正确）。这是 v5 第二轮审计的核心教训：**中间节点的口径
错误会被端到端正确性测试漏掉**。

**为什么关键。** β 把子阵列权重误差直接变成一阶系统性 INL
（`δw_S/w_S ≈ (1−β)·δC`，锯齿周期 = 主阵列一个 LSB），这是 DEM
**原理上**消不掉的项（DEM 置换单位、不改变 C_C）。

**代码落点**：`dac_arch.py`（严格解）、`charge_ref.py`（独立参考
求解器，禁止反向凑数）。
**钉子**：`SplitDAC` 与 `charge_ref` 一致性测试。

## T3. 名义/物理两套求值分离（数字可见性边界）

**原理。** 对同一组开关指令算两个值：

```
vD0    = DAC_nominal(b)          数字可见——重构唯一允许使用的 DAC 口径
vDtrue = DAC_physical(b, chip)   物理真值——只用于模拟电路与事后评分
```

**两条铁律**（验收强制）：
1. `DAC_nominal(M(c, state)) = V_target(c)` 对任意 DEM state 成立
   （等权置换的结构性质，`mapper.verify_nominal`）；
2. `dac_error` 出现在任何**算法路径**即为越界——校准算法读不到
   `chip.C_true`，否则"校准成功"只是代码抄了答案。

**为什么关键。** 一切"校准/DEM/dither 收益"的数字之所以可信，
都 because 数字侧被关在名义口径的笼子里。违反一次，整个误差预算
的解释权就没了。v3 的 `d_once` 事故（校准回归量漏 dither 名义项 →
G_hat 崩到 6.68）是正面教材：数字侧只用合法输入时，错的是**算法**，
不是边界。

**代码落点**：`rdac.py`、`digital_core.py`、`reconstruction.py`。
**钉子**：`TestF8EvidenceScope` 类文档/边界断言。

## T4. Dither：采样态电荷注入 + 三要素配对

**原理。** [10] 的物理实现是**采样态**注入：2D 个单位不接输入而接
±V_FS，因此 dither **不占输入量程**，代价是恒定信号衰减：

```
α = (N − 2D) / N            （reconstruction.py 由同一份掩码推导）
```

三要素**成对出现**（`DitherState`，缺一即配置错误）：

1. 模拟注入（掩码单位接 ±V_FS，`sampler.sampling_dither_injection`）；
2. 码修改（dither 只改 RDAC 码，**不进粗码**，[10] §2.6）；
3. 数字扣除 `d_corr`（α 同源推导，重构式里除掉）。

**为什么关键。** dither 的价值是把单位权重的静态误差**线性化**
（误差从"码的确定性函数"变成"码+随机状态的函数"，再被平均）。
但只有三要素严格配对，扣除后剩下的才是"被随机化了的误差"，否则
扣除项本身成为新的误差源。`dither_changes_in_window=True` 显式
`NotImplemented`——窗口内变化的 dither 是开放问题，不静默走错口径。

**代码落点**：`sampler.py`、`mapper.py`、`reconstruction.py`、stage9A
（两种注入方式的代价对比）。

## T5. DEM：它能修什么、不能修什么（含 64 排列空间）

**原理。** DEM = 等权单位的**位置置换**。横向（slice 轮转）⊗ 纵向
（slice 内 segment 轮转）：

```
主阵列轮转步：(sid·331) mod 64    纵向步：(sid·173) mod 8
联合物理排列空间 = lcm(64, 8) = 64   （主→子 1:1 映射，非 512！）
```

名义守恒是**结构性**的（选中单位数 = 逻辑码，与 state 无关）。

**DEM 的有效域**（谁被置换、谁就能被平均）：

| 误差项 | DEM 能否消 | 原因 |
|:---|:---:|:---|
| 单位电容失配的**码相关部分** | ✅ | 置换打散码↔单位绑定 |
| 整片总电容偏差（满幅增益） | ❌ | 分母 ΣC_act 与选择无关，增益校准管 |
| 桥接 C_C 比例误差 | ❌ | DEM 不触碰 C_C（T2） |
| 数字串扰的**共模部分** | ❌ | 只取决于翻转个数 A(k)，与"哪些"单位无关 |
| 主/子边界残差 | ❌ | 各自逼近各自平均（[11] 核心难点，做成可观测量） |

**64 ≠ 512 的教训**：`N_DEM_STATES = 8·8·8` 数的是数字标签；两个
轮转同源（同一个 `sid`），物理上只有 64 个联合排列。指标不害人，
**命名**害人——v7.0.5 把它钉成 passing 测试（R16），本仓库任何 DEM
扫描数字不得引用为 [11] 三维机制的定量收益。

**代码落点**：`mapper.py`、`dac_arch.py`（boundary_error）、
`experiments.py` stage12.3。
**钉子**：`TestR16DemPermutationSpace`。

## T6. Rank-aware 校准可观测性

**原理。** 单位权重估计的可行性由**使用矩阵的秩**决定：

```
U[n,u] = 第 n 次转换中单位 u 是否被选中（实数时为权重）
err[n] = −Σ_u w_u·U[n,u] + noise
rank(U) = r  ⇒  只有 r 个线性组合可辨识，其余 N−r 个方向给再多数据也估不出
```

实测：交织映射下 **rank = 64 / 512**——8 个 slice 的同位置单位随
同码值永远同时切换，观测只能看到它们的和。这不是数据量问题，是
**结构**问题；打破手段（DEM/随机置换/专门校准激励）各有数据量代价，
由 `required_samples` 量化。

**为什么关键。** 失配预算：PDK 估算 σ≈1117 ppm，93 dB SNDR 需要
≤300 ppm，差 3.7 倍；补面积要 14 倍电容（Pelgrom σ∝1/√C），不可行；
DEM 在大失配下反而变差（v2 结论）。所以**"能不能估出来"是架构成立
与否的判据**，而 rank 就是这个判据的数学形式。

**方法论细节**：`ridge_fit` 只在可辨识子空间做最小二乘（不假装估
全部）；必须 out-of-sample + 整数/分数码双口径（in-sample 自欺）。

**代码落点**：`calib.py`。
**钉子**：校准实验的 out-of-sample 断言。

## T7. 逐相位噪声传递与 KTC 相消（原创扩展）

**原理。** 把"采样噪声等效电容"从 [假设] 升级为相位声明下的推导值。
采样相每个电容保留独立噪声电荷（方差 kT·C）；放大相噪声状态
q=[q_M, q_S] 沿两条通路进入输出：

```
残差通路：n_path = (q_M + β·q_S)/C_sig           a = [1, β]/C_sig
观测通路：n_obs  = (q_M + γβ·q_S)/C_sig + e_N     b = [1, γβ]/C_sig
数字相消：n_res = (a − κb)ᵀq − κ·e_N
σ²_res = (a − κb)ᵀΣ_Q(a − κb) + κ²σ_eN²
κ_opt  = aᵀΣ_Q b / (bᵀΣ_Q b + σ_eN²)   （v7.0.5：含观测噪声的联合最优）
```

三个直接推论（stage16 逐项验证）：

1. **γ=1**（观测拿到正确组合）→ κ_opt=1，残余 = κ·σ_eN；
2. **γ=0**（观测只接主阵列）→ 子阵列噪声 β·q_S 结构性不可消，调 κ
   救不回来——**先问可观性，再谈最优系数**；
3. `C_n,eq = C_sig²/(A+β²B)` 与主循环口径一致——同一份噪声进入
   kT/C 预算与 KTC 相消两条账。

**为什么关键 + 边界**。这是仓库唯一**无文献源头**的分支（原创研究
扩展，不归属 ADI）。两个硬边界：①观测电压 `v_N` 是无量化器/无编码/
无延迟的 float 数组—— quoted 增益是**理想数字读出**的上界；②
`f_max = 134.45 MHz` 是**摆幅**判据（读在观测通路节点），0.1% 建立另需
`f_BW ≥ ln(1000)/(2π·Δt) ≈ 11.26 GHz`（条件性估算）——**摆幅 ≠ 建立**。

**代码落点**：`ktc.py`、`noise_phase.py`、`config.validate_ktc`。
**钉子**：`TestR18KappaOptimalWithObserverNoise`、`TestR12…ObservedNode`。

## T8. 码相关动态误差三件套（INL 缺口的主体）

**原理。** 论文实测 INL 2.2 LSB，v1–v4 静态模型只有 0.07 LSB——30 倍
缺口主要在这里。三项共同特征：**码相关**（确定性 INL 结构）+
**非静态**（加电容、DEM 都不管用）。

**(a) 输入建立**：τ 的码相关才是 INL 来源（τ 与码无关只是一阶 IIR）：

```
τ(k) = τ0·(1 + ρ·(2k/N − 1))    ⇒  eps(k) = exp(−T_s/τ(k))
x_saved = x − eps(k)·(x − V_prev)
```

口径边界（R17）：聚合单节点 RC 是保守上界**仅当支路开关项主导**；
星形网络公共模式 `τ = R_s·C_total + R_on·C_slice`，R_s 项不随划分缩小
（1.025 ns vs 0.666 ns，1.54× 非 8×）。

**(b) 参考建立**：静态分量 ∝(2k/N−1)（奇对称）产生 k² 项 →
**抛物线 INL（经典 bow）**；动态分量 ∝(k[n]−k[n−1])/N（与输入斜率
相关）；恢复因子 η_ref = 1−exp(−T_conv/τ_ref)。

**(c) 数字串扰**：单调切换一次的翻转数 A(k)=2·min(k, N−k)（三角形，
中码最大）；共模部分 DEM 无效（T5 表）。

**代码落点**：`dynamics.py`；进入位置与物理一致（输入建立改**采样值**，
参考/串扰改 **DAC 输出**——`sim_split.py` 头部契约）。
**数值等级**：`dyn_*` 全部 [假设]——用形状与趋势，不用值。

## T9. 物理 slice 池：跨周期因果

**原理。** 真实电容不能转换它没采过的电荷：

```
转换组(conv[n]) 必须 = 采集组(acq[n−1]) 的成员（一拍流水延迟）
```

v6.1 的 `ShuffledScheduler` 每周期独立抽 8/18：8191 次转换中只有
**1 次**满足上式，平均 3.56/8 个 slice 在转换"别人的"样本。更深的
问题：8/18 选择**没接到电容权重**——固定/洗牌两种调度输出逐位相同
（差 0.0 µV），"洗牌打散杂散"是在**误差系数**上演的，不在物理阵列上。

`PhysicalSlicePool` 把两条都修了（8191/8191、coverage 8.000/8），且
**把失配绑定到 slice**（带宽/时刻失配成为 slice 的属性而非全局系数）。

**为什么关键。** stage19 的 31 dB/42 dB 抑制数字，只有在"洗牌作用于
物理电容"的前提下才有物理意义。这也是 R1/R2（物理池上主路径）仍为
xfail 的原因：接入会移动已发布数值，必须附差异表。

**代码落点**：`slice_pool.py`、`scheduler.py`（Allocation 采样时确定
不可改——可归因性硬约束）。
**钉子**：`TestF2SliceCausality`。

## T10. 方法论：让"结论可信"本身可测试

这不是电路技术，但它是本仓库与其他行为模型的真正分界：

1. **双实现逐位等价**：`pipeline.py`（逐相位状态机）与 `sim_split.py`
   （向量化）在非理想全关时逐位一致——两套独立实现读同一个接口
   读出同样语义的最强校验（stage19①）。
2. **独立电荷真值**：`charge_ref.py` 不复用闭式解，逐相位节点方程
   另推一遍；两边不一致时先怀疑主循环口径，**禁止**反向修改凑数。
3. **参数来源运行时分级**：`DISCLOSED/DERIVED/FITTED/ASSUMED` 是
   运行时值不是注释；新增 Config 字段没写等级，测试直接红。
4. **验收记录门禁**：`REQUIRED_RECORDS` + 严格 bool 判定
   （`np.bool_` 归一化，v7.0.4 的教训：JSON 往返会掩盖内存路径差异），
   验收项不可静默消失。
5. **未闭合缺陷用 `xfail(strict=True)`**：修好变 XPASS 即失败，逼人
   摘标记，不留过期的"已完成"印象。
