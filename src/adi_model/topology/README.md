# 电容网络、码本与开关电荷

本目录提供电容池、开关电荷计算和明确的码表。实际拓扑、码本和权重由调用者绑定。此页说明 Fig.11 研究装配。生产权重为每片 16 主、4 子，见[默认事务模型](../defaults.py)。Fig.11 的建模选择及已知差异见 [推导记录](../../../docs/guide/decisions/20261112_fig11_unification.md)。

<a id="caps"></a>
## 采样、转换与等效电容

Fig.11 研究夹具选择 18 片物理池，每个活动组 8 片。主阵列每片 `15×2C + B4·C + S4·C = 32C`。四个装配的子阵列权重为 `8C、4C、2C、1C`，跨接 `Cb=C`，所以零寄生时名义 `β=1/16`。五位子连接形状另留一位占位。未把 Fig.19 的额外无位标端接装入本模型，电学实现属于工程选择，[E]。 [阵列常量](capacitors.py) · [端接边界](../../../docs/mechanisms/p1_gaps_20261113.md)

| 量 | 在 Fig.11 研究模型中的用途 |
| --- | --- |
| 采样电容 | 每片含 S4，名义值为 `(32+15/16)C`。8 片以 20.5 pF 为工程锚点，用于输入和 RA 物理增益。 |
| 码本转换电容 | 默认静态码本排除 S4，分母为 `(31+15/16)C`。生成 0–511 码的输入等效电压表，阈值和码本应保持同源。 |
| 噪声等效电容 | 求差分采样噪声时对子阵列使用 `β²` 权重。 |
| 反馈电容 | RA 物理增益的分母，由配置显式给定。 |

<a id="mismatch"></a>
## 失配与物理片

[SplitChip](dac_arch.py) 保存按物理片 ID 索引的主、子、桥接及反馈电容。研究制造实现按 `Fig11Parameters` 的相对标准差独立抽样，换逻辑 slot 时保留物理电容身份。该设定是模型输入，[E]。版图相关、边缘效应和工艺值需要额外来源。

## 码本和接口

[NominalCodebook](dac_arch.py) 与 [Mapper](mapper.py) 各自绑定名义电压表、粗码映射及可选的逐事件码表。数字端使用名义表，实际电荷由掩码、参考轨和物理片电容求得。v21 的 3+3+3 阵列和 guard 码由独立合同定义。 [控制模型](../control/README.md) · [v21 工程合同](../../../docs/CONTRACT_CURRENT.md)
