# 63+8 替代路径清除清单与专利模型统一方案

受测版本：`cf010db`（工作树干净）。本文是执行依据，不是完成报告。

---

## 1. 为什么不能"改默认值"了事

主链的 63+8 不是一处常量，而是**三条互锁的假设**：

| 位置 | 代码 | 含义 |
|:---|:---|:---|
| 几何守卫 | `defaults.py`: `if (n_main+1)*n_sub != 512: raise` | 64×8=512；17×5=90，直接拒绝 |
| 码本 | `drive_weight = Cu*(c//n_sub + beta*(c%n_sub))` | 把"码→权"写成除法取模 |
| 掩码 | `mask_binding=_segmented_mask` | 同一套 `//`、`%` 解码 |

换掉任一，另外两条就是错的。所以必须**同时**替换几何、码本、掩码绑定三处，再往下传导到校准权重与 RTL。

## 2. 图上的唯一模型（已核对原图）

来自 `US10511316B2` FIG.19/FIG.20（原件图见 `docs/mechanisms/figures/`），
数值常量已在 `topology/capacitors.py`：`MAIN_WEIGHTS`、`SUB_WEIGHTS`。

| 项 | 值 | 状态 |
|:---|:---|:---|
| 主阵列 | 15×2C + 2×1C = 32C | 原文明确（图） |
| 子阵列 | 8C/4C/2C/1C/1C，末位恒接低轨 | 原文明确（图）；"恒接低轨"是工程读法 |
| 桥接 | Cb = C | 原文明确（图） |
| β | 1/17 = C/(C+16C) | **由上述假设推出**，不是原件给的数 |
| 单位电容 | 77.79 fF | 由 20.5 pF 反推：`20.5p/[8×(32+16/17)]` |
| 反馈电容 | 640.6 fF | 20.5 pF / 32（G 保持 32） |
| 校验 | 8×(32+16/17)×77.79f = **20.500 pF** | 与论文锚点对齐 |

### 2.1 关键发现：b4 不是逐片位，是**跨片 1C 组**

图上的两个 1C 在 8 片之间组成 16 个 1C 单元，`b4=1` 时选其中 **8 个**：
`(2*slot + unit + vertical) % 16 < 8`。

所以名义驱动权重不是"每片独立"的：

```
group_drive(c) = 8·(2·thermal) + 8·b4 + 8·binary(c[3:0])
                 └ 15 个 2C ┘   └ 跨片 1C ┘   └ 8/4/2/1 ┘
```
其中 `thermal = c>>5`、`b4 = (c>>4)&1`、`binary` 权重 8/4/2/1。

这条决定了 `drive_weight` 必须重写，不能沿用 `c//n_sub + β·(c%n_sub)`。

### 2.2 逐单元权重不再是常数

旧链每片 63 个 2C 单元权重相同。图上不是：主单元有 2C 与 1C 两种，
子单元有 8/4/2/1/1 五种。因此

```
w[slice, main_unit] = MAIN_WEIGHTS[i]·Cu/Cf
w[slice, sub_unit]  = β·SUB_WEIGHTS[j]·Cu/Cf
```

这会传导到：`nominal_decoder` 的权重数组、`CalibrationSpec`、
`rtl_params.vh` 的 `N_UNIT_MAIN/N_UNIT_SUB`（71→22）、RTL 权重 ROM（18×71→18×22）、
`verification/` 的 recon_core 向量与 TB 位宽。

## 5.1 执行第 1 步时新发现的阻塞：两个 1C 的连接决定码本律

按图的字面读法算名义码本，会遇到 0.19 V 的端点不对称：

```
group_drive(511) = 8·(2·15) + 8(b4) + β·8·(8+4+2+1)
                 = 240 + 8 + 7.06 = 255.06
group_cnorm      = 8·(32 + β·16) = 263.53
```

比值 0.968，使码 511 只到 **+2.81 V** 而不是 +3.0 V；码 0 仍精确在 −3.0 V。
也就是说 **mid-rise 码本会整体左移约 33 LSB20**。

这不是数值误差，而是"两个 1C 到底怎么接"没有唯一读法：

* 若 16 个 1C 中未选中的 8 个**接 VIN**（采样时接信号），则它们计入 cnorm
  但永不计入 drive —— 就是上面 0.968 的结果；
* 若未选中的 8 个**接低轨**（不采 VIN），cnorm 应为 `8·(32 + β·15)`，比值仍 0.966；
* 若 2×1C 其实是"每片 1 个 1C、另一个是哑元"，则 8 片只有 8 个 1C，b4 全选即 8，
  此时 drive 上限 = 240 + 8 + β·120，cnorm = 8·(30+2+β·16) —— 仍 0.968。

三种读法都到不了 1.0，说明**图上的 15×2C 与 2×1C 之间存在冗余位或差分配对**，
仅凭 FIG.19 的方框看不出连接方式。这正是"专利未披露"的典型，
必须回原图逐条看，或者按论文的 512 码传输反解——**两者都不能靠我猜**。

所以第 1 步的验收条件要加一条：**码本端点必须 = ±v_fs（或显式声明不对称及其来源）**。
在这一点定下来之前，落码本就是把一个未确认的假设固化进主链。
