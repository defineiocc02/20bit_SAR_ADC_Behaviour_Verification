# 八片扰动控制微架构

`dither8_top` 把八片控制接入现有 `module1_bridge_top`。调度请求 N 和配置一并登记。模块一 N+1 发布有序采集组。扰动发生器在 N+2 使用该事件生成字，顶部同沿保存八个 ID。模块一旧采集组在后一次接受时晋升，转换侧通过样本号取其快照。连续接受时，每沿一个字仍可依次发布。

字发生器保存最新字和样本 ID。每次有新字时，历史寄存器复制旧最新快照。调度接受的发布沿从最新槽读取晋升组的扰动字，下一个时钟沿将该字移入历史槽。连续发布时每沿仍从最新槽读取刚晋升的一笔。stall、单纯种子载入和空拍中历史快照保持，两路样本 ID 匹配继续参与有效性判断。复位、清除和禁用清两级有效位。采集侧和转换侧各自解码同一个四位档位规则。

种子写入先统一校验，然后沿调度侧的判定与发布节拍递送到两套发生器。采集受理与种子载入在每个阶段互斥。非法种子写入不产生任何模式变化。

`code_i` 为无符号，九位扩展为十位后加高路整数码。高路整数码使用调度事件选出的扰动字，加法和 ID 校验并行。掩码命令送至既有桥接顶层，按当前冻结的 DEM、桥接模式和有序 slot 映射。所有字段含义按 SPEC，无效掩码或不匹配以显式错误返回。单时钟、同步清理路径，无内部 CDC。模拟采样使用在孔径前稳定的描述符，转换和重构使用同笔命令及采样掩码。
