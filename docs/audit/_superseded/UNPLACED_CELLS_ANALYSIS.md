# 未放置单元的核实结论

时间：2026-11-17　基线：`adc235a`

## 1. 事实核对

### 日志里的"42 个"是重复计数

```
grep -oE "Cell A[0-9]+ is not placed" | sort -u | wc -l
-> 7
```

**只有 7 个不同的单元编号**（A69、A507、A509~A513），
但被 25 个布线分区重复报告了 609 次。

### 真正的未放置实例名

```
INFO: Found unplaced instance ctmi_12252
```

`ctmi_` 前缀 = **Clock Tree Macro Instance**，
即 `clock_opt` 期间插入的**时钟树缓冲/反相单元**。

日志中 `ctmi_` 出现 **1063 次** —— 说明 CTS 插入了大量时钟树单元，
其中一部分在 `place_opt` 阶段还没被放置（因为 `place_opt` 在 `clock_opt` 之前执行）。

## 2. 时序上的解释

```
place_opt      ← 报 42 个单元未放置（此时 CTS 单元还不存在）
clock_opt      ← 插入 1063 个 ctmi_ 单元
route_auto     ← 对已放置的单元布线
```

**关键**：`place_opt` 报的"未放置单元"是它自己插入的优化 buffer（A69/A507 等），
而这些单元**不在初始网表里**（`get_cells A69` -> NOT_FOUND，已实测）。

它们可能是 `place_opt` 内部的临时优化候选，被计入统计但未落实到最终网表。

## 3. 对结果的影响评估

| 指标 | 值 | 评估 |
|:---|:---|:---|
| Routed Wires | 15,184 | ✅ 完整 |
| DRC | 0 | ✅ |
| open nets | 0 | ✅ |
| slack | +14.44 ns | ✅ |
| `place_opt` 返回 | 1 | ⚠️ 因上述未放置单元 |

**布线连通性数据（open nets = 0、DRC = 0）说明实际网表已完整布线。**

## 4. 我的判断与不确定性

**判断**：`place_opt` 的 `rc=1` 来自它内部优化过程中的统计口径
（插入了候选 buffer 但未全部落实），**不代表最终网表有缺失单元**。

**依据**：
- `open nets = 0`（所有网都连通）
- `DRC = 0`
- 15,184 条布线 = 与 1,594 条网的规模相符
- 未放置的单元名在网表里查不到

**不确定**：我没有做 `report_cells -unplaced` 或网表完整性对比，
**无法 100% 确认最终网表与 RTL 逻辑等价**。

## 5. 需要补的验证（未做）

| 项 | 目的 |
|:---|:---|
| `report_cells -hier -filter "is_placed==false"` | 确认最终网表是否有未放置单元 |
| 导出网表后与 RTL 做 Formality | 确认功能等价 |
| LVS | 确认版图与网表一致 |
| GDS 导出与 DRC | 确认可流片 |

**这四项都没做，所以不能宣称 signoff。**

## 6. 结论

**"42 个未放置" 需要修正为 "7 个不同的单元编号被重复报告 609 次"。**

它们不在初始网表中，是 `place_opt` 优化过程内部的候选。
最终网表的布线数据（open nets = 0、DRC = 0、15,184 条线）**表明布线完整**。

**但这不是 signoff 级证据** —— 需要 LVS 与功能等价验证。
