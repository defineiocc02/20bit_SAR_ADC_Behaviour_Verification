# D2 双模方案 A：过渡验证 + 收敛要求

## 定位（用户明确）

**方案 A 仅作过渡验证手段。不允许长期保留两套独立重构主链。
最终必须收敛到单一共享主链。**

## 已实现

### 1. E0 入口一次冻结（不读当拍值）

`ev_start_i` 那一拍锁存整笔事务的全部控制状态：

| 字段 | 位宽 |
|:---|:---|
| `ev_ids_q` 8 片物理 ID | **40 位（完整）** |
| `ev_res_q / ev_hp_q / ev_vp_q` | 4 / 4 / 3 |
| `ev_adc2_q / ev_dith_q / ev_tag_q` | 12 / 6 / 24 |

后续 9 个事件只读这些锁存值；`ev_ids_o` 输出的是冻结值，**不再取当拍 `slice_ids_o`**。

### 2. 无效事件的 mask 保持协议

```
ev_mask_o       = ev_mask_c（与 ev_k_o 同拍，组合）
ev_mask_valid_o = ev_valid_o && !ev_err_o
```

**非法事件（prefix < Upper）不产生 valid**，RDAC 侧只在 valid=1 时锁存，
因此物理开关不会被非法命令改写 —— 这就是"保持上次合法命令"的实现方式。

> 最初把 `ev_mask_o` 做成 register 实现保持，结果比 `ev_k_o` 晚一拍，
> 逐事件比对全部报 `MASK 不符`。改为组合 + valid 门控后对齐。

### 3. 最终 mask 提交给 E1

第 9 个有效事件落下时：

```
ev_final_mask_q  <= ev_mask_c        // 最终 mask
ev_final_valid_q <= 1'b1             // 一笔事务的提交脉冲
```

E1 在 `ev_mode_i=1` 时以这对信号为提交源。

### 4. E1–E4 与 recon_d5_w2 完全共享

```systemverilog
valid_a <= ev_mode_i ? ev_final_valid_q : (valid_i && in_ready_o);
mask_a[s] <= ev_mode_i ? ev_final_mask_q[s*20 +: 20] : mask_c[s];
slice_a[s] <= ev_mode_i ? ev_ids_q[s*5 +: 5] : slice_ids_o[s*5 +: 5];
adc2_a <= ev_mode_i ? ev_adc2_q : adc2_i;
...
```

**没有第二套 Wm/G，也没有第二个 recon_d5_w2。** 两种模式在 E1 之后汇合。

### 5. 验证结果

| 项 | 结果 |
|:---|:---|
| 两路等价（同 c/adc2/dither，64 组） | **0 不一致** |
| 事件级对拍（含逐事件 mask） | **5544 事件 0 错误** |
| 8509 笔整码回归 | **PASS** |

## 40 MS/s 吞吐率：**当前实现达不到**

采样周期 25 ns = 40 MS/s。若事件模式**每 25 ns 只接收一个判决位**，
9 个事件需 225 ns，单转换器吞吐率只有 **4.44 MS/s**，差 9 倍。

三条可选路径（**均未实施**）：

| 路径 | 做法 | 代价 |
|:---|:---|:---|
| A. 判决时钟 ×N | 事件时钟 = 采样时钟 × 9（~2.8 ns/位） | 需要高速比较器与判决电路，28 nm 下 2.8 ns 可行但要验时序 |
| B. 全并行比较 | 9 位一次性 Flash 式判决 | 与论文 3-bit Flash + SAR 更接近，但比较器数 ×9 |
| C. 流水交织 | 多转换器交替，各自 225 ns | 面积 ×9，与"共享 RA/ADC2"矛盾 |

**当前 RTL 是路径 A 的接口形态（逐位送入），但没有约束事件时钟频率**，
也没有做多位并行输入。**因此现在不能声称 40 MS/s。**

## 与 ADI AD4080 数字部分的差距（据所附 die 图）

| 项 | AD4080（据 die 图） | 本工程 |
|:---|:---|:---|
| 数字面积占比 | 数字区约占裸片 30%（含 SRAM、OTP） | 顶层 99,196 µm²，无 SRAM |
| 系数存储 | **有 SRAM 宏**（左上与左侧两块独立 SRAM） | 全触发器，占 27.9% 面积 |
| 一次性可编程 | **有 OTP 块**（右上） | 无 |
| 数据接口 | 独立 DATA INTERFACE 区 | 只有简单并行口 |
| 时钟 | 独立 Clock 区 | 无 CTS |
| 版图 | 数字/模拟/参考/电容分区隔离 | 未做 floorplan |

**差距结论：**

1. **存储架构差一个量级** —— AD4080 用 SRAM 宏，本工程 16.6 kbit 全用触发器
2. **缺 OTP** —— 校准系数在 AD4080 里可一次编程固化，本工程只能外部加载
3. **缺数据接口模块** —— 没有串行/并行输出协议、FIFO
4. **物理实现为零** —— 无 CTS、无布线、无 floorplan

**数字算法层面（D1–D5）已可对照；数字 IP 交付层面差距很大。**
