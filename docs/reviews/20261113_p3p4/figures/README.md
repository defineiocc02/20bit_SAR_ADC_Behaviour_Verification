## F02 `F02_dem_usage.png` — DEM 使用是否真的均匀

| 项 | 内容 |
|:---|:---|
| 问题 | 每个 (物理片, 主单元) 被选了多少次？低码是否也能覆盖 63 列？ |
| 配置 | 默认 63+8 池、18 片、8 活动；DEM 开；567 笔 = 63 列 × 9 计划周期 |
| 对照 | 修复前相位 `h=index%15` vs 修复后 `h=(index+7*(index//9))%63` |
| 读数 | 码 8：**32/63 → 63/63**；码 255：62/63 → 63/63；码 511：两者都 63/63（满码假通过） |
| 不能声称 | 热图均匀 ≠ 失配被平均；它只证明**选通次数**均匀，不含电容误差 |

## F03 `F03_inl_dnl.png` — INL/DNL：DEM、校准各改善什么

| 项 | 内容 |
|:---|:---|
| 问题 | 四条配置（理想/失配+噪声/+DEM/+逐码校准）的 INL 形状与 DNL 粒度 |
| 配置 | 256 电平 × **32 次**、±0.985 FS、seed 20261105 |
| 读数（max INL, LSB20） | 理想 **0.7**；失配+噪声 **24.5**；+DEM **6.2**；+DEM+轮转 **6.7**；+校准 **13.2**（矩阵里 10.5 是另一条留出网格，见下） |
| 关键 | **8 次重复时 +DEM 会读到 14.5——那是测量噪声，不是 INL**（见下节"噪声地板"）；32 次后是 6.2 |
| 不能声称 | 不是 20 位码密度 INL；256 点的拟合会吃掉一部分弯曲。另外**校准的 INL 依留出网格而变**（10.5 vs 13.2），因为逐码表的分辨率就是码宽，电平落在码边界附近时受益更大 |

### 噪声地板（本轮新增的口径）

每个电平的均值误差估计噪声为 `sigma_e / sqrt(R)`。8 次重复时：

| 配置 | sigma_e (LSB20) | 8 次的 INL 地板 | 32 次的 INL 地板 |
|:---|---:|---:|---:|
| 失配 σ=0.1% | 10.8 | 3.8 | **1.9** |
| 失配+噪声 | 12.6 | 4.4 | **2.2** |
| +DEM | 17.8 | 6.3 | **3.1** |

所以"8 次重复的 INL"里有一部分是噪声取最大值：256 个电平上取 max 会把 ~3σ 的
正尾挑出来，导致 +DEM 的 14.5 里有约 12 LSB20 是噪声。**本轮把静态点改成 32 次重复**，
并把地板单列——这正是审查"静态指标要用充分统计"的要求。
