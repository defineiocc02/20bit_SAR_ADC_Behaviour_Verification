# D3 两个问题的直接回答（基于 a50c891 + dem_ideal_sadc.py）

## Q1：D 组为何失效？

**不是非单调，是余差落出单边 ADC2 窗口。**

用理想单调 SADC 出码（解析式 `D_ideal(k) = -3 + 6k/512`），
真实失配 RDAC 生成余差，逐笔诊断 64 点：

```
溢出 14 笔
  其中 D(k+1) ≤ D(k)（非单调）： 0 笔
  其中 单调但窗口溢出：          14 笔   ← 全部
```

典型样本：

| n | 片组首片 | x | k | D(k) | D(k+1) | 码间 | 余差 |
|--:|--:|--:|--:|--:|--:|--:|--:|
| 0 | 8 | +0.0000 | 256 | +0.00412 | +0.01563 | +11.52 mV | **−4.117 mV** |
| 5 | 12 | +1.3599 | 372 | +1.36285 | +1.37447 | +11.63 mV | **−2.954 mV** |

**机理**：ADC2 是**单边**窗口 0 ~ 14.06 mV。理想 SADC 保证
`D_ideal(k) ≤ x < D_ideal(k+1)`，但真实失配使 `D_real(k) > D_ideal(k)`，
于是 `x − D_real(k) < 0`，落出窗口下界。

**所以问题出在"理想 SADC 的码边界与真实 RDAC 的码边界不重合"，
不是 SAR 搜索非单调。** 这与之前把 D 组归因为"非单调"的判断不同，予以更正。

## Q2：理想 SADC 驱动真实 RDAC 后，DEM 是否产生线性化效果？

**没有。四个组的有序关系是 A < B < C < D（误差递增）。**

N=1024，fin=bin37，amp=1.5 V，真实实例 seed 2026，解码用名义系数，宽窗口：

| 组 | 片组 | 相位 | 残差 RMS | 最大误差 |
|:--|:--|:--|---:|---:|
| A | 固定 | 固定 | **2042.1 µV** | 5011.4 µV |
| B | 固定 | 轮转 | 2817.1 µV | 8380.2 µV |
| C | 轮转 | 固定 | 3558.9 µV | 8529.6 µV |
| D | 轮转 | 轮转 | **3630.0 µV** | 10018.9 µV |

**放开轮转反而使误差单调上升 78%。**

### 为什么

解码用名义系数时，误差 = `D_nom(k) − D_real(k)`，主要由**片间平均增益差**决定。
- 固定片组（A/B）只用一组片，恰好那组增益偏差小 → 误差小；
- 轮转片组（C/D）把所有片的增益偏差都纳入，平均增益偏离名义值更多 → 误差大。

**这不是 DEM 的错，是这个实验的度量把"平均增益误差"和"非线性"混在一起了。**
真正的 DEM 效果应在**去除增益/偏置后**看残差谱——那是 `dem_abcd.py` 做的事，
其结论同样是"峰没有下降，只是搬到了别的频点"。

## 还有一个必须指出的实验缺陷

`dem_phases(sid)` 中 `q = sid // 9`，`h_phase = (q // 128) % 15`。

**N=1024 时 q ≤ 113，`q//128 = 0` 恒成立 → `h_phase` 从未推进过一次。**

也就是说：之前所有"横纵相位轮转"的实验，**只有纵向和保留列在变，
横向置换根本没动过**。要覆盖完整工程周期（17280 笔）才能让 h_phase 走完 15 个值。

**这是 D3 判 PARTIAL 的关键原因之一。**

## D3 为何仍是 PARTIAL

| 判断依据 | 现状 |
|:---|:---|
| DEM 是否降低最大杂散 | **否**（峰值不降，只搬频点） |
| 是否覆盖完整 DEM 周期 | **否**（1024 点，h_phase 恒为 0） |
| 是否多 seed / 多频 | **否** |
| 物理单元使用是否均衡 | 已验证（每片 16/16） |
| 码权守恒 | 已验证（8192 组 0 违反） |

**"码权守恒 + 覆盖均衡"成立，但"线性化收益"未被证明。**
这两件事必须分开：前者是结构正确性，后者才是 DEM 的目的。
