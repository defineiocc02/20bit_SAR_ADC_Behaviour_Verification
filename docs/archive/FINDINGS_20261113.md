## 一、可以复现的实验结果

### 1.1 基本 ADC 码域（理想条件，零失配零噪声）

命令：`_build_model(0.0, False)` + 斜坡，512 粗码 × 64 点 = 32768 点。

| 项 | 结果 |
|:---|:---|
| 单调性 | 逆序 0、重复 0 |
| 码范围 | 1747 … 1046828 |
| 相邻步长 | 31 … 32（期望 31.9） |
| 单粗 LSB 内细扫 | 输出跨度 2047 LSB20（理论 2048），步长 31/32/33 |
| INL（逐粗码分箱平均后去直线） | **2.778 LSB20**（默认参数含噪声）；0.573 是"逐点残差 + noise=False"，两种口径不可混用 |

**能说**：粗 9 位 + 后级细分确实拼成 20 位，单调、满量程、比例正确。
**不能说**：全 20 位 INL/DNL。只有 512 个粗码各 64 点的网格，不是 2²⁰ 个阈值。

### 1.2 失配与 DEM 的开/关对比

| 配置 | INL (LSB20) |
|:---|---:|
| `unit_mismatch_std=0` | 2.778 |
| `unit_mismatch_std=1e-4` | **4.731** |
| `=1e-4` + DEM 相位钉 0（关） | **4.731** |
| `=1e-4` + 真实相位（开） | **4.731** |

**失配使 INL 从 2.78 恶化到 4.73；但 DEM 开关对它没有任何影响，一位小数都不差。**

### 1.3 掩码层：DEM 是活的，但没传导到输出

同一 code、8 笔、σ=1e-4：

```
sample0 每片选中数 [9 9 9 9 9 9 9 9]  第0片前8位 1 1 1 1 1 1 1 1
sample1 每片选中数 [9 9 9 9 9 9 9 9]  第0片前8位 1 1 1 1 1 1 1 0
sample2 每片选中数 [9 9 9 9 9 9 9 9]  第0片前8位 0 0 0 1 1 1 1 1
```

掩码逐笔在变、每笔内 8 片各异 → 旋转不是死的。
但 INL 不变 → **掩码变化没有传导到电荷/输出**。

**这是当前最关键的未解点**，二选一：
- (a) 电荷不走掩码，仍按 code 闭式算；
- (b) 走了掩码，但 σ=1e-4 的收益被别的主导误差盖住（量级存疑：4.731 LSB20 ≈ 27 µV，而 1e-4 在 3 V 上约 300 µV）。

### 1.4 `dem_enable` 是死开关

```
A3 dem_enable=True →
ConfigError: the inferred basic decoder has no implemented source unit DEM binding
```

位置：`src/adi_model/defaults.py:251-254`，硬 `raise`。
`mask_binding=fig11_masks` 在 `defaults.py:861` **硬编码**，不可配置。
结论：主轴上的 DEM 只能靠相位状态隐含开关，没有配置入口。

### 1.5 独立数字主链已能跑（`src/adi_model/digital_chain.py`）

一笔：`sample_id=3, code=281, word=33, adc2=2049`

```
slice_ids = [14,15,16,17,0,1,2,3]
k = 277            (U = 4)
U/L/T = 4 / 0.142857 / 4.142857
Fig.21: b4=1,b5=0,b6=1 → count=5, 10C, 保留列 1 个
事件: 7 条，前缀 256,256,272,...
```

不读 plant 的增益/电荷/归一化。**这是目前唯一一条可独立运行的 D1–D5 数字链。**

### 1.6 Fig.19–21 两条不变式（模块级，11 passed）

- `2·Σy = 8B4+4B5+2B6`，`(1,1,0) → 6 → 12C`
- 保留列恰好一列、取 350；其余 15 列保持 352 共享码
- 定向测试：纵向=横向时拒绝（防止测试恒真）

## 二、我自己出过的错（已证伪，勿复用）

| 我说过 | 实际 |
|:---|:---|
| 桥后有 4 个电容，第 5 个是桥 | **错**。放大 7 倍看清：桥后 5 个（8/4/2/1/C），第 5 个无位标、实线、在网 |
| 端点比值 1.0 可当自洽证明 | **错**。那是删掉一个真实电容后才闭合的 |
| `x=0` 误差 < 1nV、`nominal_gain==g_vec` 是物理正确性判据 | **错**。错误模型也能同时满足 |
| `Q_DAC = -Q_free - Q_res` | **错**。漏了 `C_conv/C_samp`；正确值 5.9516 pC（不是 6.1383 pC） |
| 两项在 `r` 中系数都是 `−1/C_conv` | **错**。是 `−1/C_samp` 与 `−1/C_conv` |
| S4 不进码本是根因 | **未证实**。且主实施例已定 Fig.19–21，不能用 Fig.14 的编码去改主链 |
| DEM 是旋转不是置换 | **表述错**。旋转是置换的一种；问题是范围与控制律 |
| 32768 点单调 = 全码域正确 | **错**。只证明受测网格 |

## 四、下一步唯一该做的事

**判 1 号阻塞**：

```
固定 code、固定电容、固定输入，取两组不同 main_masks
charge(A) - charge(B) == 0 ?  → 掩码没进电荷方程
                          ≠ 0 ?  → 进了，只是被别的误差盖住
```

判完才能决定：是修电荷路径，还是 DEM 本来就有效只是指标不敏感。

在这一条判明之前，**不改电容、不改码本、不写 RTL**——否则又是拿一个未验证的前提去推下一步。
