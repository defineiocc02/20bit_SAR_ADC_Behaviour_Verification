# 数字 IP 的术语与单位

## 跟随一笔采样

| 名称 | 在波形和模型中怎样读 |
| --- | --- |
| SADC、RDAC、sDAC | SADC 是两套交替工作的前级量化器之一。RDAC 是产生余差的 DAC；一片 sDAC 是它的一个物理子阵列。18 片中每笔选 8 片采集、8 片转换。量化器编号 `qid` 与物理片号各自保存。[顶层信号流](../algorithms/digital.md#transaction) |
| 物理片号、槽位 | 片号 0…17 标识实际器件及其权重。槽位 0…7 只标识该片在本笔八片组中的位置。[调度](../algorithms/digital.md#schedule) |
| 样本、比较事件、事务 | 样本是一笔被受理的输入。普通转换含 7 个比较事件，最高区接受 512 试探时有 5 个事件；拒绝时有 8 个事件、7 次开关写入。Python 的 `event_count` 给出逐笔有效事件长度，`event_k` 在该长度内为 −1 表示关闭写门。整笔从受理到带 `out_tag` 输出称为一次事务。[逐位状态](../algorithms/digital.md#events) |
| 粗码 `c`、命令 `k` | `c` 是量化器最终判决，普通区 0…511，保护区可到 519。`k=c+U` 是含扰动上段的 RDAC 命令，工程合法域 0…520。[开关规则](../v21/SWITCHING_RULES.md) |
| `pre`、`post`、`Wp`、`Wm` | `pre` 是采样时的开关，`post` 是最后实际写入的转换开关。`Wp`、`Wm` 分别按两组开关选中的物理权重求和。重构加回转换贡献，扣一次采样贡献。[加权重构](../algorithms/digital.md#reconstruct) |
| ADC2 原码 | 13 位后级量化码，0…8191。工程电压窗为 `[-0.1875,+0.5625) V`，解码使用每个码箱的中心。[ADC2 换算](../CONTRACT_CURRENT.md) |
| 最终输出码、LSB20、ppm FS | 最终码为 20 位偏移二进制，`0x80000` 对应差分 0 V。电压换算为 `(code−2¹⁹)×6 V/2²⁰`。一 LSB20 约 5.722 µV；在 6 V 满幅下，1 ppm FS 等于 6 µV。[Python 出码](../../src/adi_model/defaults.py) |

`D1` 至 `D6` 依次指片选、逐位跟随、DEM、扰动、加权重构、事务归属。`B1` 至 `B9` 是开关和时序合同的条款编号。查软件版本和具体提交请读[版本记录](../meta/CHANGELOG.md)。

## 行为实验与性能指标

| 名称 | 物理含义与适用条件 |
| --- | --- |
| 输入折算电压、节点电压 | 前者将电荷按模型的 `C_norm` 折到输入端。节点电压由实际电容连接和电荷守恒求得。[电荷模型](ARCHITECTURE.md) |
| `C_norm`、`C_noise`、`β`、`Cf` | `C_norm` 是信号归一化电容。等效热噪声电容 `C_noise=C_norm²/Σ(Cm+β²Cs)`。桥接衰减 `β=Cb/(Cb+ΣCs+Cp_sub)`。`Cf` 是余差放大器的反馈电容，各值依所用网络而定。 |
| 名义值、器件真值、估计值 | 名义值用于设计；行为模型给每片生成的实际电容是该次实验的器件真值；校准系数由观测拟合，须在独立输入上评估。 |
| 普通自归零（AZ）、斩波辅助自归零（CAAZ） | AZ 是模拟放大器的消偏动作。Fig.11 行为研究有相位模型；CAAZ 的斩波与配对在独立研究模块中。生产 Python 只接收约定的宏响应。[CAAZ 实验](../caaz/README.md) |
| 平均传输非线性、DNL、INL | 行为图 F03 在 512 个输入电平测均值并去除直线。全码斜坡实验按输出码宽计算 DNL，按过渡点相对端点直线的偏移计算 INL。两种结果均有各自的激励、端点和误差单位。[F03](../figures/behavioral/README.md) · [全码静态线性度](../audit/TREE_AUDIT_REPORT.md#全码静态线性度) |
| SNR、SNDR | SNR 的分母为噪声功率，SNDR 的分母还包含失真。引用频谱结果时同时给出输入、采样率、带宽和数据来源。 |
