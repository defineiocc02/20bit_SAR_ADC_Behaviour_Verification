# 权重配置接口与生效条件

时间：2026-11-16　基线：`bb96361` + 本文件所述改动
性质：**工程约定**，不是论文披露值

## 0. 范围声明

本约定只覆盖**权重表配置的生命周期与范围验收**。它不宣称：

- 整个 IP 已通过验证（Formality 根因未定、无同版网表、无 P&R）
- `cfg_valid=1` 代表"所有可能片组的 G 都已被验证"——G 是每笔重构时
  由权重与片号组合出的量，只能在**每笔交易的 recon 入口**检查
- 复现 ADI 硅片（沿用工程假设）

## 1. 物理接口（52 位）

| 信号 | 宽 | 方向 | 含义 |
|:---|--:|:---|:---|
| `w_cfg_we` | 1 | in | 写一个 40 位字 |
| `w_cfg_sel` | 1 | in | 0 = 主阵列，1 = 子阵列 |
| `w_cfg_sid` | 5 | in | 片号 0..17 |
| `w_cfg_idx` | 5 | in | 主 0..15 / 子 0..3 |
| `w_cfg_data` | 40 | in | 权重值 |
| **合计** | **52** | | 1+1+5+5+40 |

新增控制（本约定引入）：

| 信号 | 宽 | 方向 | 含义 |
|:---|--:|:---|:---|
| `w_cfg_commit` | 1 | in | 原子生效请求 |
| `w_cfg_reload` | 1 | in | 请求重新配置（清 written、失效） |
| `w_cfg_valid` | 1 | out | 配置已生效且锁写 |
| `w_cfg_busy` | 1 | out | 装载中（written 非全 1 或未 commit） |

## 2. 状态机（三态 + 重配入口）

```
        复位
         |
         v
   +-----------+
   | IDLE      |  无效态：不接受交易；written=0；locked=0
   +-----------+
     |         ^
     | 装入     | reload（须先排空）
     v         |
   +-----------+     commit（written 全 1 且无非法写）
   | LOADING   | ------------------------------> +-----------+
   +-----------+                                 | ACTIVE    |
                                                 | locked=1  |
                                                 +-----------+
```

| 状态 | `cfg_valid` | 接受交易 | 可写 | 可 commit |
|:---|:--:|:--:|:--:|:--:|
| IDLE | 0 | ✗ | ✓ | ✗（written 未满）|
| LOADING | 0 | ✗ | ✓ | ✓（written 全 1）|
| ACTIVE | 1 | ✓ | ✗（locked）| ✗ |

## 3. 重配置序列（唯一入口）

```
1. 外部置 stop_i = 1                      -> 拒绝新 prepare
2. 等待 drain_done = 1                    -> ACQ/CONV/ADC2 owner/重构在途 全部排空
3. 置 w_cfg_reload = 1（一拍）
   -> written_q<=0, locked_q<=0, state<=IDLE
4. 按序写入 360 个字
5. 置 w_cfg_commit = 1（一拍）
   -> 校验 written 全 1；通过则 locked_q<=1, state<=ACTIVE
6. 解除 stop_i
```

**排空定义**（必须全部满足）：

```
drain_done = ~acq_valid & ~conv_valid & ~adc2_owner_valid & ~recon_inflight
```

其中 `recon_inflight` 覆盖 recon 流水里还有未退休的交易。

## 4. 同沿优先级

| 场景 | 处理 |
|:---|:---|
| 最后一字写入与 `commit` 同拍 | **拒绝 commit**（`cfg_commit_reject=1`），保持 LOADING |
| 两个写口同拍（不可能，单口）| — |
| `reload` 与 `commit` 同拍 | **拒绝**，优先 `reload` |
| `we` 在 ACTIVE（locked）时 | **静默丢弃**，不改 written、不改数据 |
| 重复写同一地址 | **不增加**已写计数（written 是位图，不是计数器）|

## 5. 非法写与非法数据

| 情况 | 处理 | 是否置 written |
|:---|:---|:--:|
| `cfg_sid > 17` | 丢弃 | **否** |
| `cfg_sel=0` 且 `cfg_idx > 15` | 丢弃 | **否** |
| `cfg_sel=1` 且 `cfg_idx > 3` | 丢弃 | **否** |
| 子权重 `w_sub > 32×2^30` | 丢弃 + 置 `cfg_range_err` | **否** |
| 主权重任意 40 位值 | 接受（G 范围在 recon 入口检查）| 是 |

## 6. 算术 profile（工程范围，非论文值）

配置提交时对**已写入的每个子权重**检查；交易时对每笔 G/Wm/Wp 检查：

```
Smax  = 32 × 4 × 2^30        // 32 片×... 的工程上界
Wp   <= Smax
Wm   <= G + Smax
16×2^30 <= G <= 64×2^30      // 每笔在 recon 入口检查
```

**注意**：`G` 只能在每笔重构时检查（它依赖 `ids`）。
所以 `cfg_valid=1` **不代表**所有片组组合的 G 都已验证。

## 7. 错误与退休语义

- **不静默丢交易**：配置无效期间的交易，带 tag 正常退休，`out_err=1`，
  `out_valid=1`（保持退休接口不变），`out_code` 不作为测量值。
- **拒绝非法写不等于旧配置失效**：ACTIVE 下拒绝一次非法写，仍用原配置正常测量。
- **排空计数**：`out_valid` 语义不变，排空逻辑可正常等到结果。

## 8. 复位值

| 寄存器 | 复位值 | 说明 |
|:---|:---|:---|
| `written_q[359:0]` | 0 | **控制状态必须复位** |
| `locked_q` | 0 | 同上 |
| `state` | IDLE | 同上 |
| `wt_main/wt_sub`（数据阵列）| **不复位** | 依赖 written 位图判定完整性 |

**TB 上电顺序**（本约定要求）：

```
1. 释放 rst_n
2. 写 360 个字
3. commit
4. 等待 cfg_valid=1
5. 才开始发交易
```

不能在 `written_q` 持续被复位时灌表——那样 written 永远记录不到完整性。

## 9. epoch 随事务走

- 捕获时把当时的 `cfg_epoch` **锁存进 ADC2 owner**
- 该锁存值随 raw 响应一起送入 recon（`in_epoch`）
- `cfg_epoch` 仍是实时输入，用于与锁存值比对
- **旧 raw 返回与新 capture 同沿**时，用锁存值判定，不用实时值
- 生效的 `cfg_epoch`、偏置等参数只在**合法 commit 时**切换

## 10. 验收用例（六类 + 三项边界）

| # | 用例 | 通过判据 |
|:--:|:---|:---|
| 1 | 完全不写 | 不产生正常有效测量（`out_err=1` 或 `cfg_valid=0` 拒绝受理）|
| 2 | 少写一个字 | commit 失败，`cfg_valid` 保持 0 |
| 3 | 非法地址 / 超范围数据 | 丢弃且不置 written；`cfg_range_err=1` |
| 4 | 完整合法加载 | 原两笔 + 连续输入基线保持 |
| 5 | 交易中尝试更新 | 被拒绝（locked），原配置继续可用 |
| 6 | 停收排空后合法换代 | 重配序列成功，epoch 正确切换 |
| B1 | 最后一字与 commit 同拍 | commit 被拒绝 |
| B2 | 重复写同一地址 | written 不增（不能冒充多写）|
| B3 | 旧 raw 与新 capture 同沿 | 用锁存 epoch 判定，不错配 |
