# recon 常数除法的形式化与数学证明

时间：2026-11-16　对象：`rtl/v21/recon_v21.sv` 的 `rnd96_const`
依据：方案 §9.3 的 `Q = RND(X, 96)`

## 1. 为什么需要证明

`rnd96_const` 用"乘魔数再右移"替代 96 位除法：

```
Q = RND(n, 96)  ->  |n|/3 = (|n| * ceil(2^34/3)) >> 34
                    再 >>5 得 |n|/96，最后按余数做一次最近舍入修正
```

这只有对**所有**合法 `n` 成立才算与方案等价。抽样仿真给不出全称结论 ——
本轮真实发生过一次常数写错（10769 个向量失配）。

**订正**：早前把事故归因写成"`ceil(2^34/3)` 需要 35 位、`[33:0]` 装不下"，
那是错的。`m = 0x1_5555_5556 = 5,726,623,062` 只需要 **33 位**，
`[33:0]`（34 位）完全装得下。真正写错的是**字面值漏了前导 1**：

```systemverilog
34'h5555_5556        // 少了最高位的 1，值变成 0x5555_5556 = 1,431,655,766
```

后果也不是"等效除数约 6"：`(a * 0x5555_5556) >> 34` 约等于 `a/11`，
再 `>>5` 约等于 `a/352`。所以故障表现是码值整体缩小而不是"偏小一半"。

**真正的教训是**：常数必须让工具从公式算出，或至少用
`tools/prove_rnd96.py` 这种不依赖手写的校验；而不是记住"要 35 位"。

## 2. 数学证明

设 `d = 3`，`K = 34`，`m = ceil(2^K/d) = 0x1_5555_5556 = 5,726,623,062`。

```
3m - 2^34 = 2
```

对任意 `a ≥ 0`，写 `a = 3q + r`（`0 ≤ r < 3`）：

```
a·m / 2^34 = (3q + r)·m / 2^34
           = q·(3m)/2^34 + r·m/2^34
           = q·(2^34 + 2)/2^34 + r·m/2^34
           = q + (2q + r·m) / 2^34
```

要 `floor(a·m/2^34) == q`，充分条件是：

```
0 ≤ 2q + r·m < 2^34
```

下界显然成立（各项非负）。上界：

```
2q + r·m ≤ 2·(|a|/3) + 2m
         < 2·2^31/3 + 2·5,726,623,062
         = 12,884,901,890
         < 17,179,869,184 = 2^34        ✓
```

**所以 `floor(|n|·m/2^34) == floor(|n|/3)` 对 `|n| < 2^31` 全域成立。**
再右移 5 位得到 `floor(|n|/96)`（因为 96 = 3×32），
最后按 `2·r96 ≥ 96` 加 1 即为最近舍入、恰半离零。

## 3. 机器校验

`tools/prove_rnd96.py` 可一条命令重跑：

```bash
python3 tools/prove_rnd96.py
```

实测输出：

```
1. 魔数除法充分条件
   m = ceil(2^34/3) = 5726623062 = 0x155555556
   3m - 2^34 = 2
   上界（|a| < 2^31）：qmax*2 + 2m = 12884901890 < 2^34 = 17179869184
   满足: True

2. 区间穷举（按商不变等价类压缩）
   qmax = 715827882
   等价类端点 + 均匀抽样：验证点 24610，失配 0
   单调性：q*err + r*m 对 q 单调递增，端点满足 => 全区间满足

3. 随机抽样
   抽样 200000，失配 0

RESULT: PROVEN  rnd96_const == RND(n, 96)  on |n| < 2^31
```

**用等价类压缩的理由**：`floor(a·m/2^K)` 只依赖 `a//3` 与 `a%3`，
而 `2q + r·m` 对 `q` 单调递增，所以端点满足即全区间满足。
这把 2^31 个点压到 24610 个代表性检查。

## 4. VC Formal 的状态（如实）

原因是**本模块没有时钟域**：

```
Design Unit Name: 'recon_rnd_equiv'

```

FPV 是"有时钟的状态机属性证明"，纯组合断言没有状态可展开，
所以它找不到任何 property。

已排除的命令问题来自当时的实测。参见 [VC Formal Tcl](../../flow/formal/v21/run_fv.tcl)。

但和上面的数学证明相比收益有限 —— 因为要证的是**无状态组合恒等式**，
数学证明 + 等价类穷举已经覆盖了全部输入空间。

## 5. 这条证明覆盖什么、不覆盖什么

**覆盖**：`rnd96_const` 与 §9.3 的 `RND(n,96)` 在 `|n| < 2^31` 上逐位一致。

**不覆盖**：
- `|n| ≥ 2^31` 的行为 —— 域外由 `bad_alpha`/`bad_g` 等 err 标志负责，
  不在等价性范围内（`|X| ≤ 353,632,160 < 2^29` 已由穷举边界给出）
- `I = RND(2^60, G)` 那一处除法 —— 仍是精确除法器，
  是当前综合超时的瓶颈，见 `docs/v21/CHECKPOINT_I5_SYNTH.md`
